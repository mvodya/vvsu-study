# Лабораторная 5 - Обработка изображений в OpenCV

Определить параметры изображений, выделить цветовые каналы, найти лица на групповой фотографии, наложить PNG с прозрачностью и заменить фон в видео

[Теория](THEORY.md) | [Рабочий ноутбук](lab5.ipynb) | [Презентация](lab5_theory_present.ipynb)

## Среда и данные

Библиотеки NumPy, Matplotlib, Pillow и OpenCV. Если cv2 отсутствует, установка отдельной ячейкой: `%pip install opencv-python-headless`. Отдельные окна cv2.imshow не используются

Для самостоятельной работы нужны:

- Фотография с участием автора (можно заменить на фото с участием  <s>воображаемого</s> друга)
- Групповая фотография с несколькими видимыми лицами
- Изображение для наложения в формате PNG с альфа-каналом (т.е. с прозрачностью)
- Короткое видео, примерно 3-10 секунд, с объектом на достаточно однородном зеленом или другом цветном фоне
- Изображение нового фона

Брать фото из примера для своей работы нельзя.

Файлы помещаются в папку mydata рядом с ноутбуком, пути задаются в первой ячейке настроек. В Colab файлы загружаются через панель Files. Простое переименование расширения не преобразует формат файла

Для ознакомления с форматом входа доступны [учебные примеры](lab5_data.zip). В архиве папка data с фотографиями, PNG с котом и исходным видео из курса 2025-S2. Роли файлов указаны в [описании данных](data/README.md). Длительность демонстрационного ролика около 17 секунд, для собственной работы достаточно примерно 3-10 секунд. Архив можно распаковать обычным архиватором и загрузить нужные файлы в Colab. Все функции обработки находятся в ноутбуке, дополнительные Python-файлы не нужны

## Требуется

1. Загрузить фотографию и указать высоту, ширину, число каналов, dtype, число пикселей H*W и число элементов массива H*W*C
2. Показать изображение двумя способами: через cv2_imshow в Colab и через Matplotlib. В локальном Jupyter первый способ заменяется показом через IPython. Отдельно показать B, G и R как изображения в градациях серого и объяснить значения светлых участков
3. На групповой фотографии сравнить не менее трех сочетаний scaleFactor и minNeighbors у каскада Haar. Указать фактическое число видимых лиц, число найденных рамок, пропуски и ложные срабатывания. Найти все лица желательно, но ограничение алгоритма допустимо при объяснении
4. Наложить PNG с прозрачностью на фотографию. Выбрать масштаб и положение, показать результат для двух вариантов размещения. Проверить, что вставка помещается внутри изображения
5. Выбрать кадр своего видео и сравнить не менее двух диапазонов HSV для выделения фона. Показать исходный кадр, обе маски, новый фон и результаты. Объяснить, какой диапазон выбран и какие ошибки остаются
6. Применить выбранный диапазон ко всем кадрам короткого видео. Сохранить исходный размер и FPS, проверить открытие выходного файла и число прочитанных кадров. Показать несколько кадров результата
7. Заполнить выводы по каналам, детекции, прозрачности и качеству замены фона

Ноутбук содержит готовые функции и основной код. Самостоятельно задаются входные файлы, параметры детекции, масштаб и положение вставки, диапазоны HSV и пояснения результатов

Выход записывается в outputs/result.avi с кодеком MJPG. Файл может не воспроизводиться прямо в браузере, поэтому в ноутбуке предусмотрен показ кадров. Сохраняется только видеоряд без звука. Используется короткий ролик с постоянной частотой кадров
