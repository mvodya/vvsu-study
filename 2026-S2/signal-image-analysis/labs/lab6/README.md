# Лабораторная 6 - Классификация изображений

Подготовить собственный набор изображений, обучить сверточную модель и оценить распознавание классов на изображениях, которые не использовались при обучении и выборе модели

[Теория](THEORY.md) | [Рабочий ноутбук](lab6.ipynb) | [Презентация](lab6_theory_present.ipynb)

## Среда

Библиотеки NumPy, Matplotlib, Pillow и PyTorch. Если нужных пакетов нет: `%pip install torch pillow` в отдельной ячейке

В Colab при наличии доступного GPU можно выбрать среду выполнения с GPU. Код использует CUDA, если она доступна, иначе CPU. Для небольшого набора CPU допустим, но обучение может занимать больше времени. Предобученные веса и torchvision не требуются

## Данные

Выбрать от двух до четырех различимых классов предметов, животных, растений или сцен. Например, кружки и бутылки. Подготовить не менее 30 разных изображений на класс, желательно 50-100 или больше, с приблизительно одинаковым количеством в каждом классе

Изображения должны отличаться ракурсом, масштабом и фоном. Несколько почти одинаковых кадров одной съемки не заменяют разнообразные примеры. В базовом варианте в каждом изображении один основной класс. Файлы берутся из собственных съемок или доступных для учебного использования источников, ссылки на источники указываются в ноутбуке

```text
dataset/
    mugs/
        image_001.jpg
        image_002.png
    bottles/
        image_001.jpg
        image_002.png
```

Названия папок задают классы. Допустимы JPG, JPEG, PNG и WEBP. Переименование расширения не преобразует формат. В папках не должно быть подписей правильного класса на самой картинке, водяных знаков или фона, однозначно выдающего класс

В Colab каталог dataset можно загрузить архивом dataset.zip через Files. В ноутбуке предусмотрена распаковка. Архив должен содержать папку dataset, внутри нее - папки классов

## Требуется

1. Указать классы, источники, количество изображений и принцип отбора. Проверить читаемость файлов и точные дубликаты. Почти одинаковые кадры одной серии исключить до разбиения
2. Разделить данные внутри каждого класса примерно на 70% train, 15% validation и 15% test с фиксированным seed. Зафиксировать списки файлов. Не менять разбиение ради улучшения итоговой оценки
3. Показать примеры изображений и их метки, проверить форму входного тензора и масштаб значений
4. Обучить приведенную CNN. Сохранить кривые loss и accuracy для train и validation. Лучшее состояние выбрать по validation loss
5. После выбора состояния вычислить test loss и accuracy. Сравнить accuracy с простым прогнозом наиболее частого класса обучающего набора. Построить матрицу ошибок и показать тестовые изображения с правильными и предсказанными метками
6. Разобрать не менее трех ошибочных предсказаний. Если ошибок меньше, разобрать все имеющиеся и указать размер test. Если ошибок нет, показать несколько правильных примеров и объяснить, почему маленький test еще не гарантирует надежность
7. Сохранить веса, порядок классов и параметры обработки изображений. Загрузить их в новый экземпляр модели и проверить совпадение прогнозов. Продемонстрировать прогноз на одном дополнительном изображении вне трех наборов
8. Сформулировать вывод о качестве, типичных ошибках, возможном переобучении и ограничениях данных

Ноутбук содержит готовую загрузку, разбиение, модель и цикл обучения. Самостоятельно подготавливаются данные, задаются пути и настройки, анализируются графики и ошибки. Дополнительное сравнение числа эпох или скорости обучения выполняется по validation, без подбора по test

Обязательного порога accuracy нет. Результат оценивается вместе с качеством данных, корректностью проверки и объяснением ошибок
