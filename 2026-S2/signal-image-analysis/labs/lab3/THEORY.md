# Цифровая фильтрация

## От спектра к фильтру

Частота дискретизации fs - число отсчетов в секунду. В примерах используется fs=1024 Гц. Промежуток между отсчетами равен 1/fs, время n-го отсчета - n/fs

Спектр показывает частоты в записи. Фильтр изменяет их вклад: например, сохраняет колебание около 80 Гц и ослабляет составляющую около 220 Гц

Цифровой фильтр - правило вычисления выходных отсчетов y по входным x. Выбор полезной составляющей определяется задачей, а не самим фильтром

## Взвешенная сумма

Пример правила для трех отсчетов:

`y[n] = 0.25*x[n] + 0.5*x[n-1] + 0.25*x[n-2]`

n - текущий номер, n-1 - предыдущий. Массив h=[0.25,0.5,0.25] содержит коэффициенты, то есть веса входных значений. Для текущего и двух прошлых значений [0,4,0] результат равен 2

```python
import numpy as np
from scipy.signal import lfilter

x = np.array([0., 0., 4., 0., 0., 0.])
h = np.array([0.25, 0.5, 0.25])
y = lfilter(h, [1.0], x)  # [0, 0, 1, 2, 1, 0]
```

Применение такой суммы ко всем позициям называется сверткой. Общая запись: `y[n] = sum(h[k]*x[n-k])`, где k перебирает коэффициенты. Это вычисление нового сигнала. Корреляция сравнивает записи при разных сдвигах

Причинный фильтр использует текущие и прошлые значения, без будущих. В начале записи отсутствующее прошлое здесь заменяется нулями

## Импульсная характеристика

Единичный импульс - последовательность [1,0,0,...]. Реакция фильтра на него называется импульсной характеристикой. Для приведенного фильтра реакция совпадает с h, затем продолжается нулями

КИХ, или FIR, - фильтр с конечной импульсной характеристикой. Если коэффициентов K, порядок равен K-1. У БИХ, или IIR, влияние импульса может продолжаться неограниченно благодаря использованию прошлых выходов. Пример: `y[n]=0.5*x[n]+0.5*y[n-1]`

В примерах используется КИХ-фильтр. У `lfilter(h,[1.0],x)` массив [1.0] означает отсутствие обратной связи по прошлым выходам. Функция возвращает столько отсчетов, сколько было на входе

## АЧХ и полосы

Амплитудно-частотная характеристика, АЧХ, показывает изменение амплитуды каждой частоты после начального переходного участка. Значение 1 означает сохранение амплитуды, 0.1 - уменьшение в десять раз

АЧХ относится к фильтру, спектр - к сигналу. Выходной спектр зависит от обоих: присутствовавшие на входе частоты усиливаются или ослабляются в соответствии с откликом фильтра

| Тип       | Какие частоты пропускает |
| --------- | ------------------------ |
| ФНЧ       | Ниже выбранной границы   |
| ФВЧ       | Выше выбранной границы   |
| Полосовой | Между двумя границами    |

Между полосами пропускания и подавления есть переходная область. Конечный короткий фильтр не имеет идеально вертикальных границ

## Расчет коэффициентов

```python
from scipy.signal import firwin, freqz

fs = 1024.0  # Гц
K = 65
h = firwin(K, [50, 110], pass_zero=False,
           fs=fs, window=('kaiser', 8))
f, H = freqz(h, fs=fs, worN=2048)
gain = np.abs(H)
```

`firwin` вычисляет коэффициенты по границам и длине. При двух границах `pass_zero=False` задает полосовой фильтр. `freqz` вычисляет частотный отклик, модуль которого дает АЧХ

Окно Кайзера плавно ограничивает коэффициенты конечной длиной. Его beta=8 в примере фиксирует один из вариантов баланса между шириной перехода и подавлением

Границы cutoff находятся строго между 0 и fs/2 и задаются в тех же единицах, что fs. Около cutoff передача обычно близка к половине амплитуды. Нужную частоту не стоит размещать прямо на границе. Реальное пропускание проверяется по АЧХ. [Описание firwin](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.firwin.html)

## Задержка и начальный участок

У симметричного КИХ с нечетным K задержка равна `(K-1)/2`. Для K=65 это 32 отсчета, или 32/1024=0.03125 с. На графике y[n] можно сопоставить времени (n-32)/fs исходного сигнала. Циклический `np.roll` для этого не подходит: он переносит конец записи в начало

Первые K-1 значений зависят от отсутствующего прошлого. Для оценки установившегося результата используется `y[K-1:]`. Длина исключаемого участка и задержка - разные величины

При росте K переходная область обычно сужается, но растут задержка и число операций. После исключения начала остается меньше данных: при N=1024 и K=257 остаются 768 отсчетов

## Спектр и близкие составляющие

Если частота не совпадает с сеткой FFT, ее вклад распределяется между соседними точками. Окно Hann уменьшает боковые следы пика, но расширяет его основную часть. Оно помогает анализу, но не гарантирует разделения близких частот

Для одностороннего амплитудного спектра с окном w модуль FFT делится на `sum(w)`, внутренние точки удваиваются, нулевая и точка Найквиста при четной длине не удваиваются. Это поправка амплитуды для гармоники на сетке, а не точное восстановление амплитуд любой смеси

Вход и выход сравниваются на участках одинаковой длины и с одинаковым окном. Малый соседний пик на выходе может означать недостаточное подавление: его частоту нужно проверить на АЧХ

## Временная и частотная шкала

При fs=1024 Гц и N=1024 промежуток между отсчетами равен dt=1/fs, время n-го отсчета - t=n/fs. Шаг спектра fs/N равен 1 Гц, частота Найквиста - 512 Гц. Последний отсчет находится в момент (N-1)/fs, а длительность блока N/fs равна 1 с

Для выделения заметного пика выбирается полоса и проверяется подавление соседних составляющих. Если близкие компоненты не разделяются, это ограничивает точность выделения даже при визуально более гладком выходе

## Один и два прохода фильтра

`lfilter` выполняет один причинный проход. `filtfilt` использует обработку вперед и назад, обращается к будущим значениям и дает другой итоговый отклик. Поэтому эти способы обработки нельзя считать взаимозаменяемыми. [Описание lfilter](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.lfilter.html)
