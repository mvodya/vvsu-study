Согласно номеру варианта загрузить сигнал из файла, выделить компоненты для всех явных частот на спектре и построить графики отфильтрованных сигналов. Параметры фильтров подобрать эмпирически

## Данные и среда

Библиотеки NumPy, SciPy и Matplotlib. Файлы содержат по 1024 значения без временной оси и частоты дискретизации. По условию работы задается fs=1024 Гц. Частоты и границы фильтров указываются в герцах, время - в секундах. Для 1024 отсчетов шаг спектра равен 1 Гц, частота Найквиста - 512 Гц (это допущение для данной лабораторной, поскольку частота измерений в исходном файле не указана)

Для всех вариантов доступен [архив данных](lab3_data.zip) с каталогом data. При локальном запуске рядом с ноутбуком уже находится каталог data

## Требуется

1. Загрузить массив, проверить длину, тип и отсутствие пропущенных значений
2. Построить временной график и односторонний амплитудный спектр. Для обнаружения близких пиков дополнительно допустимо окно Hann; нормировку оконного спектра указать отдельно
3. Составить таблицу заметных пиков и подобрать для каждого полосу пропускания. Границы полос должны находиться между 0 и fs/2
4. Рассчитать КИХ-фильтры через `scipy.signal.firwin`, построить их АЧХ через `freqz`. Начальный вариант - нечетное число коэффициентов, например 129, окно Kaiser с beta=8
5. Применить каждый фильтр через `lfilter(h, [1.0], x)`. Показать выходные сигналы и спектры после исключения начального переходного участка длиной len(h)-1
6. Сравнить не менее двух наборов параметров: число коэффициентов или ширину полосы. Указать, какие соседние пики подавлены, а какие остались
7. Для сравнения формы учесть задержку симметричного КИХ-фильтра `(len(h)-1)/2`. Причинный выход не заменяется циклическим сдвигом

У очень близких пиков короткий фильтр может не обеспечить разделение. Допустим результат с остаточной соседней компонентой, если ограничение подтверждено АЧХ и сравнением параметров
