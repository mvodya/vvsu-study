Смоделировать сигналы по формулам для 100 значений, вычислить автокорреляционную функцию для x и y и взаимную корреляционную функцию

Требуется:

1. Задать сигналы $x(t)$ и $y(t)$
2. Сгенерировать точки
3. Построить графики сигналов $x$ и $y$
4. Вычислить автокорреляцию для $x$ и $y$
5. Вычислить взаимную корреляцию для $x$ и $y$
6. Построить графики:
   1. Автокорреляции для $x$
   2. Автокорреляции для $y$
   3. Взаимной корреляции

## Уточнения и порядок выполнения

[Теория](THEORY.md) | [Презентация](lab2_theory_present.ipynb) | [Шаблон](lab2.ipynb)

Среда выполнения - Google Colab или Jupyter

1. Создайте ровно 100 точек `np.linspace(0, t_max, 100)` **с включенным концом**. Тогда `dt = t_max/99`
2. Перенесите формулы своего варианта: `**` - степень, `np.pi` - число π; не заменяйте аргумент синуса на частоту без коэффициента `2π`
3. Покажите первые значения, размеры и отдельные графики x и y (масштабы могут сильно различаться)
4. Сначала рассчитайте сырые `correlate(x,x)`, `correlate(y,y)`, `correlate(x,y)` с `mode='full'`. Для каждой функции должно получиться 199 значений
5. Получите лаги через `scipy.signal.correlation_lags`; покажите ось в отсчетах и переведите ее в единицы t через умножение на dt
6. Для основного сравнения вычтите среднее из каждого сигнала. Автокорреляцию разделите на энергию соответствующего центрированного сигнала, взаимную - на `norm(x0)*norm(y0)`. При нулевой энергии сообщите, что нормировка не определена
7. Сопоставьте сырую и центрированную нормированную корреляцию. Объясните вклад постоянной составляющей и уменьшение числа перекрывающихся отсчетов на краях
8. Укажите лаг максимума взаимной корреляции и порядок аргументов. Не называйте его физической задержкой автоматически: y в задании - нелинейная функция x, а не запись x с известным запаздыванием

Нормировка на энергию позволяет сравнивать величину корреляции. Деление на собственный максимум оставляет информацию о форме графика, но делает его пик равным единице по построению
