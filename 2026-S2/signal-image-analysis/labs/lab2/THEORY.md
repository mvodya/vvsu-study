# Корреляция сигналов

## Задача сравнения

Два микрофона могут записать один звук с разной задержкой. Чтобы оценить ее, записи сравниваются при разных сдвигах. Подобное сравнение используется для поиска эха, известного фрагмента в длинной записи и повторяющихся участков сигнала

Корреляция вычисляет сумму произведений значений при выбранном сдвиге. Набор результатов для всех сдвигов называется корреляционной функцией

## Сумма произведений и лаг

Для a=[1,2,0] и b=[0,1,2] при нулевом сдвиге:

```python
import numpy as np

a = np.array([1, 2, 0], dtype=float)
b = np.array([0, 1, 2], dtype=float)
products = a * b       # [0, 2, 0]
value = np.sum(products)  # 2
```

После сдвига b на одну позицию влево совпадают значения 1 и 2. Сумма становится 1*1+2*2=5

Лаг - сдвиг в отсчетах. В SciPy лаг k соответствует сравнению a[n] с b[n-k]. За пределами записей считаются нули. Циклический сдвиг `np.roll` имеет другую модель границ

```python
from scipy.signal import correlate, correlation_lags
r = correlate(a, b, mode='full')
lags = correlation_lags(len(a), len(b), mode='full')
```

Для примера лаги равны [-2,-1,0,1,2], результаты - [2,5,2,0,0]. Для равных длин N режим full дает 2N-1 значений

## Знак и единицы

Если y - копия импульса x с задержкой d, у `correlate(x,y)` максимум находится при -d, а у `correlate(y,x)` - при +d. Порядок аргументов определяет знак

Время сдвига равно `lag*dt`. В лабораторной 100 точек включают оба конца интервала, поэтому `dt=t_max/99`

У периодических записей может быть несколько похожих максимумов, поэтому задержка не всегда определяется однозначно

## Центрирование

Общий постоянный уровень может давать большую сырую корреляцию даже при разных колебаниях. Для сравнения отклонений от среднего применяется центрирование:

```python
x0 = x - x.mean()
y0 = y - y.mean()
```

Например, [9,10,11] превращается в [-1,0,1]. Форма изменений относительно среднего сохраняется

## Нормировка

Сумма произведений зависит от масштаба значений. Для его учета используется произведение норм полных записей. Норма - квадратный корень из суммы квадратов; сама сумма квадратов называется энергией записи в данной математической модели

```python
denominator = np.linalg.norm(x0) * np.linalg.norm(y0)
if denominator == 0:
    raise ValueError('Нулевая энергия: нормировка не определена')
rho = correlate(x0, y0, mode='full') / denominator
```

Значения rho находятся в [-1,1]. Знаменатель одинаков для всех лагов. При положительном масштабировании сигнала нормированный результат не меняется

Для постоянного сигнала после центрирования остаются нули, и такая нормировка не определена. Деление на максимум самого графика - другой способ масштабирования: его пик всегда становится единицей по построению

## Автокорреляция

Взаимная корреляция сравнивает два сигнала. Автокорреляция сравнивает сигнал с самим собой при разных сдвигах

При нулевом лаге нормированная автокорреляция ненулевой по энергии записи равна 1. У периодического сигнала похожесть повторяется на ненулевых лагах. Расстояние между повторяющимися пиками может указывать на период

Автокорреляция вещественного сигнала симметрична. Взаимная корреляция обычно несимметрична, но при перестановке аргументов отражается относительно нуля лагов

На крайних лагах перекрывается меньше отсчетов, что влияет на высоту значений. Центральный пик сам по себе не доказывает периодичности

## Ограничения интерпретации

При нулевом лаге для равных длин центрированная нормированная корреляция совпадает с коэффициентом Пирсона. Это мера линейной связи, а не любой зависимости

Для симметричных x от -1 до 1 и y=x² коэффициент близок к нулю, хотя y полностью определяется x. График зависимости - парабола. Высокая корреляция также не доказывает причинную связь

На других лагах используемая функция не является коэффициентом Пирсона, заново рассчитанным по перекрывающимся фрагментам: средние и нормы не пересчитываются

В вариантах лабораторной y вычисляется как функция x, а не как его задержанная запись. Поэтому лаг максимума нельзя автоматически назвать физическим временем задержки
