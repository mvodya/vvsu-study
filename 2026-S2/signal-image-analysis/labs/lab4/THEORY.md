# Обучаемый фильтр

## От коэффициентов к обучаемым весам

В цифровом фильтре выход вычисляется как взвешенная сумма входных отсчетов. Если веса неизвестны, их можно подобрать по примерам входа и правильного выхода

Обучаемая модель - функция с изменяемыми параметрами. Параметры называются весами. Обучение изменяет их так, чтобы прогноз модели приближался к цели

Простой пример: прогноз равен w*x, цель равна 0.5*x. При w=1.5 результат неправильный, а при w=0.5 цель достигается. У фильтра вместо одного веса используется несколько

## Пары входа и цели

В задаче имитации цифрового фильтра целевой выход вычисляется по известным коэффициентам h:

```python
y = lfilter(h, [1.0], x)
```

x - широкополосная случайная запись, y - выход цифрового фильтра. Широкополосный вход позволяет проверить много частот. Одна синусоида проверяет только одну

Модель учится повторять цифровой фильтр. Для задачи удаления шума потребовались бы другие пары: зашумленная запись на входе и известная чистая запись в качестве цели

## Разбиение данных

| Набор      | Для чего используется          |
| ---------- | ------------------------------ |
| Train      | Изменение весов                |
| Validation | Выбор состояния и настроек     |
| Test       | Итоговая проверка после выбора |

Наборы состоят из независимых записей. Разные фиксированные seed генератора позволяют воспроизвести это разбиение. Копии одной записи не являются независимой проверкой

Для реального аудио сначала разделяются исходные записи, затем создаются фрагменты. Иначе соседние похожие окна могут попасть одновременно в обучение и проверку

## Массивы и тензоры

Тензор - многомерный массив PyTorch. Вход Conv1d имеет форму `(число записей, число каналов, длина)`. Форма (32,1,512) означает 32 одноканальные записи по 512 отсчетов

```python
import numpy as np
import torch

x = np.zeros((32, 512), dtype=np.float32)
tensor = torch.from_numpy(x[:, None, :])
print(tensor.shape)  # (32, 1, 512)
```

`None` добавляет ось канала. Для небольших примеров достаточно float32 и CPU

## Сверточный слой

`nn.Conv1d(1,1,K,bias=False)` применяет одно и то же ядро из K весов во всех позициях записи. Один входной канал преобразуется в один выходной

Bias - дополнительное постоянное слагаемое. В этой модели он отключен. Без нелинейностей слой является линейным фильтром, который может представить КИХ-учитель такой же длины

Чтобы выход зависел только от текущего и прошлых значений, перед слоем добавляются K-1 нулей слева:

```python
padded = torch.nn.functional.pad(tensor, (K-1, 0))
```

После Conv1d длина выхода совпадает с исходной. Дополнение с двух сторон использует другую договоренность о времени

Conv1d умножает веса на окно слева направо, тогда как h[0] в lfilter относится к текущему отсчету. Для сопоставления обученные веса разворачиваются: `weight[0,0,::-1]` после перевода в NumPy. При обучении готовые коэффициенты учителя в модель не копируются. [Описание Conv1d](https://docs.pytorch.org/docs/2.14/generated/torch.nn.modules.conv.Conv1d.html)

## MSE и градиент

MSE - среднее квадратов разности прогноза и цели. Для ошибок [1,-1,0] получается `(1+1+0)/3=2/3`. Знаки не компенсируются, большие ошибки дают больший вклад

Градиент показывает, как небольшое изменение весов влияет на ошибку. Движение против градиента обычно уменьшает ее при достаточно малом шаге. Размер шага задается learning rate

Для входа 2, цели 1 и веса 1.5 прогноз равен 3, ошибка в квадрате равна 4, градиент равен 8. Один шаг с learning rate=0.1 дает вес 0.7, прогноз 1.4 и ошибку 0.16

PyTorch вычисляет производные автоматически:

```python
optimizer.zero_grad()
prediction = model(train_x)
loss = criterion(prediction, train_y)
loss.backward()
optimizer.step()
```

При оценке установившегося режима из расчета loss исключаются первые K-1 отсчетов у прогноза и цели. Перед каждым шагом градиенты обнуляются, потому что backward накапливает их. [Цикл обучения PyTorch](https://docs.pytorch.org/tutorials/beginner/basics/optimization_tutorial.html)

## Эпохи и выбор модели

Эпоха - проход по всей обучающей выборке. В маленьком примере она обрабатывается одним пакетом. После обновления вычисляется validation MSE и сохраняется независимая копия лучшего `state_dict`, словаря весов

`model.eval()` задает режим проверки, `torch.no_grad()` отключает подготовку производных. У единственного Conv1d режим train/eval не меняет вычисляемую функцию, но для более сложных сетей это различие важно

Если train улучшается, а validation ухудшается, хорошее запоминание обучающих примеров не переносится на новые данные. Состояние выбирается по validation, а не по test

## Оценка результата

На test сравниваются модель, нулевой выход и неизмененный вход. Для всех цель одна: выход цифрового фильтра. Маленькая абсолютная MSE сама по себе не доказывает успеха: у узкополосного учителя даже нулевой ответ может иметь небольшую ошибку

Временные графики и разность показывают локальные ошибки. Спектры характеризуют конкретные выходы. Сравнение АЧХ учителя и развернутых обученных весов характеризует линейную модель независимо от одной записи

Начальный участок исключается одинаково во всех оценках. Дополнительно сдвигать только прогноз нельзя: модель и учитель уже используют одну причинную договоренность

## Длина записи и сохранение

Одинаковое ядро применяется во всех позициях, поэтому модель может обработать запись другой длины. Проверяются и длина результата, и ошибка

Для повторного запуска нужны веса, длина ядра, частотная шкала и описание архитектуры. После загрузки результат на том же входе должен совпадать

Успешное обучение означает приближение заданного фильтра. Оно не делает модель лучше учителя и не доказывает пригодность для любого звука. Для известного линейного фильтра прямой расчет обычно проще


## Частотная и временная шкала

Модель и цифровой фильтр должны использовать одну временную шкалу. Например, при fs=1024 Гц блок из 512 отсчетов занимает 0.5 с. Временная ось задается как `t=np.arange(N)/fs`, частотная сетка - как `np.fft.rfftfreq(N,d=1/fs)`

Спектры и АЧХ показываются в герцах, временные графики - в секундах. Длина ядра и размеры массивов задаются числом отсчетов. Изменение fs без пересчета коэффициентов меняет физические частоты полосы фильтра
