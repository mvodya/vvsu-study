# Лабораторная 4 - Обработка звука с помощью нейросети

Применить один из цифровых фильтров лабораторной 3 к широкополосному сигналу, обучить модель воспроизводить его выход и сравнить результаты

[Теория](THEORY.md) | [Презентация](lab4_theory_present.ipynb) | [Шаблон](lab4.ipynb)

## Среда и данные

Библиотеки NumPy, SciPy, Matplotlib и PyTorch. Если torch отсутствует, установка в отдельной ячейке: `%pip install torch`

Для работы 4 выбирается один фильтр из работы 3. Код его расчета с теми же fs, числом коэффициентов, границами и окном переносится в новый ноутбук. Можно также перенести сам массив h без округления. Отдельный файл фильтра не требуется

Основная задача - имитация цифрового фильтра. Целевой сигнал вычисляется через `lfilter`. Исходный вход не считается чистым эталоном. Удаление добавленного шума с известным чистым эталоном - отдельная постановка

## Требуется

1. Перенести код расчета выбранного h и значение fs из лабораторной 3. Указать полосу, число коэффициентов и выбранный режим фильтрации
2. Сгенерировать независимые широкополосные записи для train, validation и test с фиксированными разными seed. Начальный размер: 32/8/8 записей длиной не менее `max(512, 4*len(h))`
3. Для каждой записи вычислить целевой выход того же фильтра. Подготовить тензоры float32 формы `(число записей, 1, длина)`
4. Создать обучаемый причинный `Conv1d` с одним входом и выходом, размером ядра len(h), без bias. Дополнение нулями только слева сохраняет длину и причинность
5. Обучить веса по MSE на train. По validation выбрать состояние с наименьшей ошибкой. Test не использовать для настройки числа эпох или параметров
6. Построить кривые train/validation loss. На test сравнить MSE модели, нулевого выхода и неизмененного входа относительно выхода цифрового фильтра
7. На одной новой записи показать вход, выход цифрового фильтра, выход модели и разность. Сравнить спектры и АЧХ обученных коэффициентов с исходным фильтром
8. Проверить применение модели к записи другой длины и сохранить веса с параметрами фильтра, загрузить их в новый экземпляр модели и проверить совпадение результатов. Для оценки установившегося режима исключить первые len(h)-1 отсчетов у всех сравниваемых выходов
9. Сформулировать вывод о точности воспроизведения и ограничениях
