# Лабораторная 1 - Преобразование Фурье

Построить **амплитудные** и **фазовые спектры** для последовательности из 5, 20, 50 повторяющихся сигналов

| Вариант | Значения сигнала           |
| ------- | -------------------------- |
| 1       | 0, 1, 2, 5, -1, -4, -1, 0  |
| 2       | 4, 4, 2, 2, 0, 0, -2, -2   |
| 3       | 0, 1, 2, 3, 4, 3, 2, 1, 0  |
| 4       | 0, 1, 2, -4, -2, 4, -1, 0  |
| 5       | -5, 5, 3, 5, 0, -5, 3, 1   |
| 6       | -1, -1, 4, 5, 4, -1, 1, 0  |
| 7       | -5, 4, -3, 2, -1, 0, 1, -2 |

Требуется:

1. Взять сигнал и повторить его много раз (5, 20, 50 раз)
2. Построить для каждого случая амплитудный и фазовый спектры
3. Проанализировать полученные результаты

## Как выполнять

[Теория](THEORY.md) | [Презентация](lab1_theory_present.ipynb) | [Шаблон](lab1.ipynb)

Среда выполнения - Google Colab или Jupyter

1. Запишите один период своего варианта как массив `float`. Используйте `np.tile`, чтобы получить 5, 20 и 50 повторений
2. Покажите значения и форму массива, постройте исходную последовательность. Для длинной записи показывайте первые два периода, но FFT считайте по всей записи
3. Условно примите `fs = 1` отсчет на единицу времени. Физическая частота дискретизации в задании не дана: подписывайте частоты **циклы/отсчет**, а не Гц
4. Вычислите `X = np.fft.rfft(x)`, частоты `np.fft.rfftfreq(len(x), d=1/fs)`
5. Постройте односторонний амплитудный спектр: `abs(X)/N`, затем удвойте внутренние частоты. Постоянную составляющую и частоту Найквиста (если N четно) не удваивайте. Если N нечетно, удваивайте все элементы после первого
6. Постройте фазовый спектр `np.angle(X)` в радианах. Скрывайте точки с амплитудой меньше `max(1e-12, A.max()*1e-10)`
7. Для каждого числа повторений укажите N, шаг частотной сетки `fs/N`, частоту повторения блока `fs/len(period)`; сравните спектры на общей шкале
8. Сформулируйте вывод о том, что меняется при повторении точно того же блока. Отдельно проверьте обратное преобразование `irfft(X, n=N)`

Допускается полный двусторонний спектр, если явно указаны другая нормировка и смысл отрицательных частот. В данной версии курса основной вариант - односторонний спектр выше

## Что сдать

Ноутбук с указанием варианта, тремя временными графиками, тремя амплитудными и тремя фазовыми спектрами, таблицей N и шага частот, проверкой восстановления и сравнением результатов. Не требуется реализовывать FFT самостоятельно
