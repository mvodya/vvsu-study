# Сигналы и преобразование Фурье

## Сигнал и его запись

Сигнал - величина, изменение которой несет информацию. Примеры: температура во времени, напряжение микрофона при записи звука, яркость пикселей изображения

Математически сигнал во времени описывается функцией x(t). Компьютер хранит отдельные измеренные значения - отсчеты. Их последовательность обозначается x[n], где n - номер отсчета

```python
import numpy as np

samples = np.array([0, 2, 0, -2], dtype=float)
```

Частота дискретизации fs - количество отсчетов за секунду. При равномерных измерениях промежуток между ними равен 1/fs, а время отсчета - n/fs

```python
fs = 8
n = np.arange(len(samples))
t = n / fs
```

На временном графике горизонтальная ось показывает время, вертикальная - значение сигнала

## Частота, амплитуда и фаза

Синусоида - плавное периодическое колебание. Синус и косинус описывают одну форму с разным положением начала. Пример:

```python
A, f, phi, b = 2, 2, 0, 0
x = A * np.cos(2 * np.pi * f * t + phi) + b
```

- A - амплитуда, отклонение от среднего уровня до максимума
- f - частота, количество колебаний за секунду, измеряется в Гц
- T=1/f - период, время одного полного колебания
- phi - фаза, положение внутри колебания при t=0
- b - постоянный уровень

При A=2 и b=0 значения лежат между -2 и +2, размах равен 4. Частота 2 Гц соответствует периоду 0.5 с. Фаза измеряется в радианах: полный цикл - 2\*pi, четверть - pi/2

Частота колебания f и частота измерений fs - разные параметры

## Сумма сигналов

При одновременном действии нескольких источников запись может содержать сумму их сигналов. В коде складываются элементы массивов, соответствующие одним моментам времени

```python
fs = 128
t = np.arange(128) / fs
x1 = 2 * np.cos(2 * np.pi * 5 * t)
x2 = 0.7 * np.cos(2 * np.pi * 12 * t + np.pi / 4)
x = 0.5 + x1 + x2
```

Сумма может иметь сложную форму. Добавляя синусоиды разных частот и амплитуд, можно приблизить даже прямоугольное колебание. Конечная сумма при этом сохраняет отличия около резких переходов

Любой конечный массив вещественных чисел допускает представление через синусоидальные составляющие на определенном наборе частот и постоянный уровень. Обратное преобразование восстанавливает исходные отсчеты с точностью вычислений

## Преобразование Фурье

Прямая задача - сложить известные составляющие. Обратная задача - определить составляющие по их сумме. Преобразование Фурье переводит запись из представления по времени в представление по частотам

DFT - дискретное преобразование Фурье для конечного массива. FFT - быстрый алгоритм его вычисления. Для вещественного массива в NumPy используется rFFT:

```python
N = len(x)
X = np.fft.rfft(x)
freq = np.fft.rfftfreq(N, d=1/fs)
```

Комплексные коэффициенты X хранят информацию об амплитудах и фазах. `np.abs(X)` дает модули, `np.angle(X)` - углы

## Амплитудный спектр

Амплитудный спектр показывает амплитуды составляющих на разных частотах. Для суммы из примера заметные пики находятся на 5 и 12 Гц. Нулевая частота соответствует постоянному уровню 0.5

Односторонний спектр вещественного сигнала нормируется так:

```python
A = np.abs(X) / N
if N % 2 == 0:
    A[1:-1] *= 2
else:
    A[1:] *= 2
```

Деление на N убирает зависимость масштаба от длины записи. Удвоение внутренних компонент объединяет вклад положительной и отрицательной частей полного спектра. Нулевая компонента и точка fs/2 при четном N не удваиваются

`X[0]/N` - среднее со знаком, `A[0]` - его модуль. Шаг частотной сетки равен fs/N. Точное совпадение высоты пика с амплитудой гармоники предполагает попадание частоты на сетку. Иначе вклад распределяется между соседними точками - возникает спектральная утечка

## Фазовый спектр и восстановление

Фазовый спектр показывает фазу каждой составляющей в радианах. `np.angle` возвращает угол от -pi до pi. Для косинуса из примера на 12 Гц получается pi/4

При почти нулевой амплитуде угол неинформативен, поэтому такие точки исключаются:

```python
threshold = max(1e-12, A.max() * 1e-10)
phase = np.where(A > threshold, np.angle(X), np.nan)
```

Обратное преобразование использует комплексный спектр:

```python
restored = np.fft.irfft(X, n=N)
```

Только амплитуд в общем случае недостаточно: потеряна информация о фазе. Малые ошибки восстановления из-за округления допустимы

## Повторение блока

`np.tile(block, R)` повторяет весь блок R раз. Если в блоке M отсчетов, длина записи N=M\*R, частота повторения fs/M, шаг сетки fs/N

При увеличении R шаг частотной сетки уменьшается, но частоты гармоник блока и их нормированные амплитуды не меняются

В вариантах лабораторной физическое fs не задано. Принимается fs=1, частотная ось подписывается в циклах/отсчет. Повторение блока и добавление нулей создают разные записи; нулевое дополнение не добавляет новых измерений

## Ограничение дискретизации

При слишком редких измерениях разные колебания могут дать одинаковые отсчеты. Например, косинусы 2 и 6 Гц при fs=8 Гц неразличимы по полученному массиву. Это наложение частот, или aliasing

Для сигнала с ограниченной полосой требуется fs больше удвоенной верхней частоты. Частота fs/2 называется частотой Найквиста. Фильтр перед измерением ограничивает полосу исходного сигнала
