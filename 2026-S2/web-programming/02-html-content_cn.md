# HTML：文档内容

## HTML 的作用

HTML 是一种标记语言，用于描述页面内容的结构和含义，包括标题、段落、列表、链接和图片。内容的外观由 CSS 控制

HTML 文件是扩展名为 `.html` 的普通文本文件。浏览器读取标记并据此构建页面

标签并不规定元素的具体外观。例如，浏览器通常将 `h1` 显示得比 `h2` 更大，但这只是浏览器的默认样式。标题级别应根据内容含义选择，而不是根据文字大小选择

HTML 文件名最好使用不含空格的拉丁字母。网站首页通常命名为 `index.html`

## 元素与标签

HTML 元素通常由开始标签、内容和结束标签组成：

```html
<p>一段文字</p>
```

在这个例子中，`<p>` 是开始标签，`一段文字` 是内容，`</p>` 是结束标签

结束标签中的名称前带有 `/`，并且必须与开始标签的名称一致

HTML 标签名的大小写不影响结果，但本课程材料统一使用小写

空元素没有内容，也没有结束标签：

```html
<img src="photo.jpg" alt="城市照片" />
<br />
<hr />
```

空元素的 `>` 前可以出现 `/`，但它并不是一个独立的结束标签

## 嵌套

元素可以嵌套在其他元素内部。嵌套元素按照与打开时相反的顺序关闭：

```html
<p>报名截止时间为 <strong>4 月 18 日</strong></p>
```

错误的嵌套会使文档难以阅读，并可能产生意料之外的结果：

```html
<p><strong>错误的嵌套</p></strong>
```

HTML 根据标签而不是缩进确定嵌套关系。缩进用于帮助阅读代码结构：

```html
<ul>
  <li>海报</li>
  <li>插画</li>
</ul>
```

源代码中的空行、连续空格和换行通常会显示为一个空格。因此，在编辑器中换行不能代替新的 `p` 元素或 `br` 元素

## 属性

属性用于设置元素的附加信息，写在开始标签中：

```html
<a href="https://example.com">打开网站</a>
<h2 id="program">活动日程</h2>
```

多个属性之间用空格分隔：

```html
<img src="assets/poster.jpg" alt="活动海报" width="720" />
```

`href` 保存链接地址，`src` 保存图片文件的路径，`id` 为页面中的元素设置唯一标识符

`id` 的值不能包含空格。每个标识符在页面中只能出现一次，否则页面内部链接就无法唯一确定目标元素

本课程材料使用双引号包裹属性值

## 文档结构

HTML 文档的基本结构：

```html
<!doctype html>
<html lang="zh-CN">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>页面名称</title>
  </head>
  <body>
    <h1>页面标题</h1>
    <p>页面内容</p>
  </body>
</html>
```

- `<!doctype html>` 位于第一行，用于启用 HTML 标准渲染模式
- `html` 是根元素，包含 `head` 和 `body`
- `lang="zh-CN"` 向浏览器和屏幕阅读器说明文本的语言
- `head` 包含文档信息，这些信息不属于页面正文
- `meta charset="UTF-8"` 设置字符编码，使中文等文字能够正确显示
- `viewport` 设置让视口宽度与设备宽度一致，并指定初始缩放比例
- `title` 设置浏览器标签页和保存的书签的名称
- `body` 包含页面的标题、文字、列表、链接和图片

`<!doctype html>` 不是 HTML 元素，也没有结束标签

## 标题与文字

HTML 提供从 `h1` 到 `h6` 的标题。`h1` 表示页面主标题，`h2` 表示各部分的标题，`h3` 表示这些部分内部的子标题

```html
<h1>活动名称</h1>
<h2>活动日程</h2>
<h3>讲座</h3>
```

级别反映文档结构，而不是文字大小。`h2` 内部的下一级标题使用 `h3`，而不是 `h4` 或 `h5`

本课程作业中，每个页面使用一个主标题 `h1`。同一级别的标题应表示页面中同等层级的部分

### 段落

每个独立段落都写在单独的 `p` 元素中：

```html
<p>展览开放时间为 10:00 至 20:00</p>
<p>主要场地免费入场</p>
```

不要在同一个 `p` 元素内用空行分隔段落：浏览器会合并这些空白字符

### 语义强调

`strong` 标记重要内容，`em` 表示语气上的强调：

```html
<p><strong>必须报名</strong></p>
<p>名额<em>有限</em></p>
```

这些元素可以放在段落、标题或列表项内部。它们表达文字的含义，而不只是改变外观

### 换行与分隔

`br` 在同一个文本块内部产生换行，例如用于邮寄地址：

```html
<p>
  示例路 10 号<br />
  城市名称
</p>
```

分隔段落时应使用独立的 `p` 元素，而不是多个 `br`

`hr` 元素表示内容不同部分之间的主题转换：

```html
<hr />
```

## 列表

无序列表使用 `ul` 元素，有序列表使用 `ol` 元素。每个列表项都写在 `li` 元素中：

```html
<ul>
  <li>海报</li>
  <li>插画</li>
</ul>

<ol>
  <li>报名</li>
  <li>领取门票</li>
</ol>
```

当各项的顺序不重要时，使用 `ul`。表示操作顺序、阶段或排名时，使用 `ol`

列表项不仅可以包含文字，还可以包含其他元素。例如，可以在列表项中加入语义强调：

```html
<ul>
  <li><strong>10:00</strong> - 展览开幕</li>
  <li><strong>12:00</strong> - 讲座</li>
</ul>
```

## 链接

链接使用 `a` 元素创建，地址写在 `href` 属性中。链接文本应说明其用途：`活动日程` 比 `点击这里` 更清楚

外部网站的完整地址包含协议方案和域名：

```html
<a href="https://example.com/" target="_blank" rel="noopener">场地网站</a>
```

`target="_blank"` 在新标签页中打开链接，`rel="noopener"` 防止新页面访问原页面

要在同一页面内跳转，需要为目标元素设置 `id`，并让链接地址以 `#` 开头：

```html
<a href="#program">查看活动日程</a>
<h2 id="program">活动日程</h2>
```

浏览器会将页面滚动到具有对应 `id` 的元素

地址 `#top` 指向具有 `id="top"` 的元素。如果该标识符不存在，或字母大小写不同，跳转就不会生效

链接不仅可以是文字。要让图片链接到页面中的某个部分，可以将 `img` 元素放入 `a` 元素内部：

```html
<a href="#program">
  <img src="assets/poster.jpg" alt="查看活动日程" width="720" />
</a>
```

## 图片与路径

如果 `index.html` 文件与 `assets` 文件夹位于同一目录，图片的相对路径应为 `assets/poster.jpg`：

```html
<img
  src="assets/poster.jpg"
  alt="活动于 4 月 20 日 10:00 开幕，免费入场"
  width="720"
/>
```

- `src` 指定文件路径
- `alt` 提供图片的替代文本
- `width` 以 CSS 像素为单位设置图片宽度

`width` 的值只填写数字，不加 `px`。如果只设置宽度，浏览器会保持图片的原始宽高比

文件夹和文件的名称必须与路径完全一致，包括字母大小写。网页路径使用 `/`，在 Windows 中也一样

替代文本传达图片中的重要信息，供屏幕阅读器使用。对于仅用于装饰的图片，使用 `alt=""`

`alt` 文本应说明图片在当前页面中的用途。无需以 `图像` 或 `图片` 开头，因为屏幕阅读器已经会告知元素类型

路径中的扩展名必须与文件的实际格式一致。仅将 `poster.png` 重命名为 `poster.jpg`，并不会把图片转换为 JPEG

## 在浏览器中检查

修改 HTML 后，需要保存文件并刷新页面。对于静态网站，无需重启服务器

即使文档存在错误，浏览器也会尝试显示，并可能自动修正未关闭或嵌套错误的标签。因此，页面看起来正常，并不一定代表标记正确

开发者工具的 `Elements` 标签页显示浏览器根据 HTML 构建的结构。在 `Network` 标签页中可以检查图片是否成功加载：文件请求不应返回 `404` 状态码
