# HTML: содержимое документа

## Назначение HTML

HTML - язык разметки, который описывает структуру и смысл содержимого страницы: заголовки, абзацы, списки, ссылки и изображения. Внешний вид содержимого задается с помощью CSS

HTML-файл - обычный текстовый файл с расширением `.html`. Браузер читает разметку и строит по ней страницу

## Элементы и теги

Обычно HTML-элемент состоит из открывающего тега, содержимого и закрывающего тега:

```html
<p>Абзац текста</p>
```

В этом примере `<p>` - открывающий тег, `Абзац текста` - содержимое, а `</p>` - закрывающий тег

Пустые элементы не имеют содержимого и закрывающего тега:

```html
<img src="photo.jpg" alt="Фотография города" />
<br />
<hr />
```

## Вложенность

Элементы можно вкладывать друг в друга. Вложенные элементы закрываются в обратном порядке:

```html
<p>Регистрация открыта <strong>до 18 апреля</strong></p>
```

HTML определяет вложенность по тегам, а не по отступам. Отступы нужны, чтобы видеть структуру кода:

```html
<ul>
  <li>Плакаты</li>
  <li>Иллюстрации</li>
</ul>
```

## Атрибуты

Атрибуты задают дополнительные свойства элемента и записываются в открывающем теге:

```html
<a href="https://example.com">Открыть сайт</a>
<h2 id="program">Программа</h2>
```

`href` содержит адрес ссылки, а `id` задает уникальный идентификатор элемента на странице. Каждый идентификатор должен встречаться на странице один раз

В материалах курса значения атрибутов записываются в двойных кавычках

## Структура документа

Базовая структура HTML-документа:

```html
<!doctype html>
<html lang="ru">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Название страницы</title>
  </head>
  <body>
    <h1>Заголовок страницы</h1>
    <p>Содержимое страницы</p>
  </body>
</html>
```

- `<!doctype html>` включает стандартный режим отображения HTML
- `html` - корневой элемент, содержащий `head` и `body`
- `lang="ru"` указывает язык документа
- `head` содержит служебные данные документа
- `meta charset="UTF-8"` задает кодировку
- настройка `viewport` задает ширину области просмотра по ширине устройства и начальный масштаб
- `title` задает название вкладки браузера
- `body` содержит основное содержимое страницы

## Заголовки и текст

`h1` обозначает основной заголовок страницы, `h2` - заголовки ее разделов, `h3` - подразделы. Уровень отражает структуру документа, а не размер текста

```html
<h1>Фестиваль городской графики</h1>
<h2>Программа</h2>
<h3>Лекции</h3>
```

Каждый абзац записывается в отдельном элементе `p`. `strong` отмечает важный фрагмент, а `em` - смысловое ударение:

```html
<p><strong>Регистрация обязательна</strong></p>
<p>Количество мест <em>ограничено</em></p>
```

`br` создает перенос строки внутри одного текстового блока, например в адресе. Элемент `hr` обозначает смысловой переход между частями содержимого

## Списки

Маркированный список создается элементом `ul`, нумерованный - элементом `ol`. Каждый пункт записывается в элементе `li`:

```html
<ul>
  <li>Плакаты</li>
  <li>Иллюстрации</li>
</ul>

<ol>
  <li>Зарегистрироваться</li>
  <li>Получить билет</li>
</ol>
```

## Ссылки

Ссылка создается элементом `a`, а адрес записывается в атрибуте `href`. Текст ссылки должен описывать назначение: `Программа фестиваля` понятнее, чем `Нажмите здесь`

```html
<a href="https://www.vvsu.ru/" target="_blank" rel="noopener">Сайт ВВГУ</a>
```

`target="_blank"` открывает ссылку в новой вкладке, а `rel="noopener"` запрещает новой странице получать доступ к исходной

Для перехода внутри страницы целевой элемент получает `id`, а адрес ссылки начинается с `#`:

```html
<a href="#program">Перейти к программе</a>
<h2 id="program">Программа</h2>
```

Браузер прокручивает страницу к элементу с соответствующим `id`

## Изображения и пути

Если файл `index.html` находится рядом с папкой `assets`, относительный путь к изображению имеет вид `assets/poster.jpg`:

```html
<img
  src="assets/poster.jpg"
  alt="Афиша фестиваля городской графики Контур"
  width="720"
/>
```

- `src` задает путь к файлу
- `alt` содержит текстовую замену изображения
- `width` задает ширину изображения в CSS-пикселях

Имена папок и файлов должны совпадать с путем, включая регистр букв. В веб-путях используется `/`, в том числе в Windows

Альтернативный текст передает существенную информацию изображения и используется программами чтения с экрана. Для изображения, которое служит только украшением, используется `alt=""`
