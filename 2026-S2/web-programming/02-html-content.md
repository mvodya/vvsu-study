# HTML: содержимое документа

## Назначение HTML

HTML - язык разметки, который описывает структуру и смысл содержимого страницы: заголовки, абзацы, списки, ссылки и изображения. Внешний вид содержимого задается с помощью CSS

HTML-файл - обычный текстовый файл с расширением `.html`. Браузер читает разметку и строит по ней страницу

Теги не задают точный внешний вид элементов. Например, браузер обычно показывает `h1` крупнее `h2`, но это только стандартное оформление браузера. Уровень заголовка выбирается по смыслу, а не по размеру текста

Имена HTML-файлов лучше записывать латинскими буквами без пробелов. Главную страницу сайта обычно называют `index.html`

## Элементы и теги

Обычно HTML-элемент состоит из открывающего тега, содержимого и закрывающего тега:

```html
<p>Абзац текста</p>
```

В этом примере `<p>` - открывающий тег, `Абзац текста` - содержимое, а `</p>` - закрывающий тег

Имя закрывающего тега начинается с `/` и должно совпадать с именем открывающего тега

В HTML регистр имен тегов не влияет на результат, но в материалах курса они записываются строчными буквами

Пустые элементы не имеют содержимого и закрывающего тега:

```html
<img src="photo.jpg" alt="Фотография города" />
<br />
<hr />
```

Символ `/` перед `>` у пустых элементов допустим, но отдельным закрывающим тегом не является

## Вложенность

Элементы можно вкладывать друг в друга. Вложенные элементы закрываются в обратном порядке:

```html
<p>Регистрация открыта <strong>до 18 апреля</strong></p>
```

Нарушенная вложенность затрудняет чтение документа и может привести к неожиданному результату:

```html
<p><strong>Неверная вложенность</p></strong>
```

HTML определяет вложенность по тегам, а не по отступам. Отступы нужны, чтобы видеть структуру кода:

```html
<ul>
  <li>Плакаты</li>
  <li>Иллюстрации</li>
</ul>
```

Пустые строки, несколько пробелов и переносы строк в исходном тексте обычно отображаются как один пробел. Поэтому перенос строки в редакторе не заменяет новый элемент `p` или элемент `br`

## Атрибуты

Атрибуты задают дополнительные свойства элемента и записываются в открывающем теге:

```html
<a href="https://example.com">Открыть сайт</a>
<h2 id="program">Программа</h2>
```

Несколько атрибутов отделяются друг от друга пробелами:

```html
<img src="assets/poster.jpg" alt="Афиша фестиваля" width="720" />
```

`href` содержит адрес ссылки, `src` - путь к файлу изображения, а `id` задает уникальный идентификатор элемента на странице

Значение `id` не должно содержать пробелы. Каждый идентификатор должен встречаться на странице один раз, иначе внутренняя ссылка не сможет однозначно выбрать элемент

В материалах курса значения атрибутов записываются в двойных кавычках

## Структура документа

Базовая структура HTML-документа:

```html
<!doctype html>
<html lang="ru">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Название страницы</title>
  </head>
  <body>
    <h1>Заголовок страницы</h1>
    <p>Содержимое страницы</p>
  </body>
</html>
```

- `<!doctype html>` располагается первой строкой и включает стандартный режим отображения HTML
- `html` - корневой элемент, содержащий `head` и `body`
- `lang="ru"` указывает язык текста браузеру и программам чтения с экрана
- `head` содержит информацию о документе, которая не является содержимым страницы
- `meta charset="UTF-8"` задает кодировку и позволяет корректно отображать кириллицу
- настройка `viewport` задает ширину области просмотра по ширине устройства и начальный масштаб
- `title` задает название вкладки браузера и сохраненной закладки
- `body` содержит заголовки, текст, списки, ссылки и изображения страницы

`<!doctype html>` не является HTML-элементом и не имеет закрывающего тега

## Заголовки и текст

HTML содержит заголовки от `h1` до `h6`. `h1` обозначает основной заголовок страницы, `h2` - заголовки ее разделов, `h3` - подразделы внутри этих разделов

```html
<h1>Фестиваль городской графики</h1>
<h2>Программа</h2>
<h3>Лекции</h3>
```

Уровень отражает структуру документа, а не размер текста. После `h2` для вложенного подраздела используется `h3`, а не `h4` или `h5`

В работах курса используйте один основной заголовок `h1`. Заголовки одного уровня должны обозначать равноправные части страницы

### Абзацы

Каждый самостоятельный абзац записывается в отдельном элементе `p`:

```html
<p>Выставка работает с 10:00 до 20:00</p>
<p>Вход на основные площадки свободный</p>
```

Не следует разделять абзацы пустыми строками внутри одного элемента `p`: браузер объединит такие пробелы

### Смысловое выделение

`strong` отмечает важный фрагмент, а `em` - смысловое ударение:

```html
<p><strong>Регистрация обязательна</strong></p>
<p>Количество мест <em>ограничено</em></p>
```

Эти элементы можно размещать внутри абзаца, заголовка или пункта списка. Они обозначают смысл текста, а не только его внешний вид

### Перенос и разделитель

`br` создает перенос строки внутри одного текстового блока, например в почтовом адресе:

```html
<p>
  ул. Гоголя, 41<br />
  Владивосток
</p>
```

Для разделения абзацев вместо нескольких `br` используются отдельные элементы `p`

Элемент `hr` обозначает смысловой переход между частями содержимого:

```html
<hr />
```

## Списки

Маркированный список создается элементом `ul`, нумерованный - элементом `ol`. Каждый пункт записывается в элементе `li`:

```html
<ul>
  <li>Плакаты</li>
  <li>Иллюстрации</li>
</ul>

<ol>
  <li>Зарегистрироваться</li>
  <li>Получить билет</li>
</ol>
```

`ul` подходит, когда порядок пунктов не важен. `ol` используется для последовательности действий, этапов или мест в рейтинге

Пункт списка может содержать не только текст, но и другие элементы. Например, внутрь пункта можно добавить смысловое выделение:

```html
<ul>
  <li><strong>10:00</strong> - открытие выставки</li>
  <li><strong>12:00</strong> - лекция</li>
</ul>
```

## Ссылки

Ссылка создается элементом `a`, а адрес записывается в атрибуте `href`. Текст ссылки должен описывать назначение: `Программа фестиваля` понятнее, чем `Нажмите здесь`

Полный адрес внешнего сайта включает схему и домен:

```html
<a href="https://www.vvsu.ru/" target="_blank" rel="noopener">Сайт ВВГУ</a>
```

`target="_blank"` открывает ссылку в новой вкладке, а `rel="noopener"` запрещает новой странице получать доступ к исходной

Для перехода внутри страницы целевой элемент получает `id`, а адрес ссылки начинается с `#`:

```html
<a href="#program">Перейти к программе</a>
<h2 id="program">Программа</h2>
```

Браузер прокручивает страницу к элементу с соответствующим `id`

Адрес `#top` ведет к элементу с `id="top"`. Если такого идентификатора нет или он написан в другом регистре, переход не сработает

Ссылкой может быть не только текст. Чтобы изображение открывало раздел страницы, элемент `img` помещается внутрь элемента `a`:

```html
<a href="#program">
  <img src="assets/poster.jpg" alt="Перейти к программе фестиваля" width="720" />
</a>
```

## Изображения и пути

Если файл `index.html` находится рядом с папкой `assets`, относительный путь к изображению имеет вид `assets/poster.jpg`:

```html
<img
  src="assets/poster.jpg"
  alt="Афиша фестиваля городской графики Контур"
  width="720"
/>
```

- `src` задает путь к файлу
- `alt` содержит текстовую замену изображения
- `width` задает ширину изображения в CSS-пикселях

В значении `width` указывается только число без `px`. Если задана только ширина, браузер сохраняет исходные пропорции изображения

Имена папок и файлов должны совпадать с путем, включая регистр букв. В веб-путях используется `/`, в том числе в Windows

Альтернативный текст передает существенную информацию изображения и используется программами чтения с экрана. Для изображения, которое служит только украшением, используется `alt=""`

Текст `alt` должен описывать назначение изображения в контексте страницы. Не нужно начинать его словами `Изображение` или `Картинка`: программа чтения с экрана уже сообщает тип элемента

Расширение в пути должно соответствовать настоящему формату файла. Простое переименование `poster.png` в `poster.jpg` не преобразует изображение в JPEG

## Проверка в браузере

После изменения HTML нужно сохранить файл и обновить страницу. Для статического сайта перезапускать сервер не требуется

Браузер старается показать документ даже при ошибках и может самостоятельно исправить незакрытые или неверно вложенные теги. Поэтому работающий внешний вид не всегда означает правильную разметку

Во вкладке `Elements` инструментов разработчика отображается структура, которую браузер построил из HTML. Во вкладке `Network` можно проверить загрузку изображения: запрос к файлу не должен иметь код `404`
