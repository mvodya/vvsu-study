# HTML: содержимое документа

## Назначение HTML

HTML расшифровывается как HyperText Markup Language - язык гипертекстовой разметки

HTML описывает структуру и смысл содержимого веб-страницы: заголовки, абзацы, списки, ссылки и изображения. Оформление этого содержимого задается с помощью CSS

HTML-файл является обычным текстовым файлом с расширением `.html`. Браузер читает разметку, строит по ней структуру документа и отображает результат

HTML не является языком программирования. В нем нет вычислений, условий и циклов

## Элементы и теги

HTML-документ состоит из элементов. Обычно элемент включает открывающий тег, содержимое и закрывающий тег:

```html
<p>Абзац текста</p>
```

В этом примере:

- `<p>` - открывающий тег
- `Абзац текста` - содержимое
- `</p>` - закрывающий тег
- вся строка - элемент `p`

Имя закрывающего тега начинается с `/`

Некоторые элементы не содержат текст или другие элементы и не имеют отдельного закрывающего тега:

```html
<img src="photo.jpg" alt="Фотография города" />
<br />
<hr />
```

К ним относятся изображения, переносы строк и разделители

## Вложенность

Элементы можно вкладывать друг в друга:

```html
<p>Регистрация открыта <strong>до 18 апреля</strong></p>
```

Вложенные элементы закрываются в обратном порядке:

```html
<p><strong>Верно</strong></p>
```

Следующая запись нарушает вложенность:

```html
<p><strong>Неверно</p></strong>
```

Отступы не меняют результат отображения, но показывают вложенность и упрощают чтение кода:

```html
<ul>
  <li>Плакаты</li>
  <li>Иллюстрации</li>
</ul>
```

## Атрибуты

Атрибут передает дополнительную информацию об элементе. Он записывается в открывающем теге:

```html
<a href="https://example.com">Открыть сайт</a>
```

Здесь `href` - имя атрибута, а `https://example.com` - его значение

Несколько атрибутов разделяются пробелами:

```html
<img src="assets/poster.jpg" alt="Афиша фестиваля" width="640" />
```

Значения атрибутов следует записывать в двойных кавычках

Атрибуты `id` и `class` могут использоваться у большинства элементов:

```html
<h2 id="program" class="section-title">Программа</h2>
```

`id` задает уникальный идентификатор элемента на странице. `class` объединяет элементы, которым позднее можно назначить общие стили

## Базовая структура документа

Минимальный HTML-документ:

```html
<!doctype html>
<html lang="ru">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Название страницы</title>
  </head>
  <body>
    <h1>Заголовок страницы</h1>
    <p>Содержимое страницы</p>
  </body>
</html>
```

### doctype

```html
<!doctype html>
```

Объявление `doctype` сообщает браузеру, что документ использует современный стандарт HTML

### html

```html
<html lang="ru"></html>
```

Элемент `html` содержит весь документ. Атрибут `lang` задает язык содержимого и используется браузерами, поисковыми системами и программами чтения с экрана

### head

Элемент `head` содержит служебные данные, которые не входят в основное содержимое страницы

Кодировка UTF-8 позволяет корректно отображать кириллицу и другие символы:

```html
<meta charset="UTF-8" />
```

Следующая настройка сообщает браузеру, что ширина страницы должна соответствовать ширине экрана устройства:

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
```

Элемент `title` задает название вкладки браузера:

```html
<title>Фестиваль городской графики</title>
```

### body

Элемент `body` содержит все, что отображается внутри страницы браузера:

```html
<body>
  <h1>Фестиваль городской графики</h1>
  <p>Программа мероприятия</p>
</body>
```

## Заголовки

HTML предоставляет шесть уровней заголовков:

```html
<h1>Название страницы</h1>
<h2>Основной раздел</h2>
<h3>Подраздел</h3>
<h4>Вложенный подраздел</h4>
<h5>Заголовок пятого уровня</h5>
<h6>Заголовок шестого уровня</h6>
```

Уровень показывает место раздела в структуре документа, а не желаемый размер текста. Внешний вид заголовка позднее настраивается через CSS

Обычно страница имеет один основной заголовок `h1`. Внутри нее сначала используются заголовки `h2`, а при необходимости их подразделы `h3`

Не следует выбирать `h4` сразу после `h2` только из-за подходящего размера шрифта

## Текст

Абзац создается элементом `p`:

```html
<p>Фестиваль объединяет молодых дизайнеров и иллюстраторов</p>
```

Несколько абзацев записываются отдельными элементами:

```html
<p>Выставка работает с 10:00 до 20:00</p>
<p>Вход на основные площадки свободный</p>
```

Пустые строки и несколько пробелов в исходном коде обычно отображаются как один пробел. Для нового абзаца нужен новый элемент `p`

`strong` обозначает важный фрагмент, а `em` - смысловой акцент:

```html
<p><strong>Регистрация обязательна</strong> для участия в мастер-классе</p>
<p>Количество мест <em>ограничено</em></p>
```

Внешний вид этих элементов задает браузер, но их основное назначение связано со смыслом текста

`br` создает перенос строки внутри одного текстового блока:

```html
<p>
  Океанский проспект, 19<br />
  Владивосток
</p>
```

Для разделения абзацев вместо нескольких `br` используются элементы `p`

`hr` обозначает смысловой переход между частями содержимого:

```html
<hr />
```

## Списки

Маркированный список создается элементом `ul`, а каждый пункт - элементом `li`:

```html
<ul>
  <li>Плакаты</li>
  <li>Книжная графика</li>
  <li>Цифровая иллюстрация</li>
</ul>
```

Нумерованный список создается элементом `ol`:

```html
<ol>
  <li>Зарегистрироваться</li>
  <li>Получить билет</li>
  <li>Показать билет на входе</li>
</ol>
```

Внутри `ul` и `ol` пункты размещаются в элементах `li`. В пункт списка можно вкладывать текст, ссылку или другой список

## Ссылки

Ссылка создается элементом `a`. Адрес указывается в атрибуте `href`:

```html
<a href="https://example.com">Сайт мероприятия</a>
```

Текст ссылки должен сообщать, куда она ведет. Формулировка `Программа фестиваля` понятнее, чем `Нажмите здесь`

### Ссылка на внешний сайт

Полный адрес содержит схему и домен:

```html
<a href="https://www.vvsu.ru/">Сайт ВВГУ</a>
```

Чтобы открыть внешний сайт в новой вкладке, используются атрибуты `target` и `rel`:

```html
<a href="https://www.vvsu.ru/" target="_blank" rel="noopener"> Сайт ВВГУ </a>
```

### Ссылка на место внутри страницы

Сначала элемент получает уникальный `id`:

```html
<h2 id="program">Программа</h2>
```

В адресе ссылки перед этим идентификатором ставится `#`:

```html
<a href="#program">Перейти к программе</a>
```

При переходе браузер прокручивает страницу до элемента с соответствующим `id`

## Пути к файлам

Полный URL ведет к ресурсу на определенном сайте:

```text
https://example.com/images/poster.jpg
```

Относительный путь вычисляется от расположения текущего HTML-файла

Для структуры:

```text
site/
|-- index.html
|-- logo.svg
|-- assets/
|   `-- poster.jpg
`-- pages/
    `-- program.html
```

Из файла `index.html` используются следующие пути:

```html
<img src="logo.svg" alt="Логотип" /> <img src="assets/poster.jpg" alt="Афиша" />
```

`logo.svg` находится в той же папке, а `assets/poster.jpg` - во вложенной папке `assets`

Из файла `pages/program.html` запись `../` позволяет перейти в родительскую папку:

```html
<img src="../assets/poster.jpg" alt="Афиша" />
```

В веб-путях используется символ `/`, в том числе при работе в Windows

Имена файлов должны совпадать с путями в HTML. На веб-сервере `Poster.jpg` и `poster.jpg` могут считаться разными файлами

## Изображения

Изображение добавляется элементом `img`:

```html
<img
  src="assets/poster.jpg"
  alt="Красная афиша фестиваля городской графики"
  width="720"
/>
```

Основные атрибуты:

- `src` задает путь к файлу
- `alt` содержит текстовую замену изображения
- `width` и `height` задают размеры

Если указан только один размер, браузер сохраняет исходные пропорции изображения

Альтернативный текст описывает информацию, которую передает изображение. Он отображается при ошибке загрузки и используется программами чтения с экрана

```html
<img src="assets/map.png" alt="Схема входа со стороны Океанского проспекта" />
```

Если изображение является только украшением и не передает информацию, используется пустой атрибут:

```html
<img src="assets/pattern.svg" alt="" />
```

Часто используемые форматы:

| Формат | Подходит для                          |
| ------ | ------------------------------------- |
| JPEG   | Фотографий                            |
| PNG    | Изображений с прозрачностью           |
| SVG    | Логотипов, иконок и векторной графики |
| WebP   | Фотографий и иллюстраций для веба     |

## Специальные символы

Символ `<` начинается тег, а `&` начинается символьная запись. Для вывода таких символов в тексте используются HTML-сущности:

| Запись   | Результат |
| -------- | --------- |
| `&lt;`   | `<`       |
| `&gt;`   | `>`       |
| `&amp;`  | `&`       |
| `&copy;` | `©`       |

Пример:

```html
<p>Формат файла: SVG &amp; PNG</p>
```

## Комментарии

Комментарий виден в исходном коде, но не отображается на странице:

```html
<!-- Главное изображение мероприятия -->
<img src="assets/poster.jpg" alt="Афиша мероприятия" />
```

Комментарии подходят для пояснения структуры документа. В них не следует хранить пароли и другие закрытые данные, так как исходный HTML доступен посетителю сайта

## Проверка документа

Браузер старается отобразить страницу даже при ошибках в разметке. Поэтому правильный внешний вид не гарантирует правильную структуру HTML

При проверке исходного файла следует убедиться, что:

- документ содержит `doctype`, `html`, `head` и `body`
- парные теги закрыты
- вложенность элементов не нарушена
- значения атрибутов заключены в кавычки
- каждый `id` встречается на странице один раз
- пути к локальным файлам открываются без ошибки `404`

Структуру элементов можно посмотреть во вкладке `Elements` инструментов разработчика. HTTP-запросы к изображениям отображаются во вкладке `Network`
