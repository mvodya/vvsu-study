# 互联网、HTTP 和本地 Web 服务器

## 互联网与 Web

互联网将不同网络连接起来，使设备能够交换数据。Web、电子邮件和即时通信工具是不同的互联网服务

浏览器作为客户端工作：请求资源并显示资源。Web 服务器接收请求并返回响应

## 浏览器如何获取页面

打开网站时，浏览器会执行以下操作：

1. 解析 URL，并通过 DNS 获取服务器的 IP 地址
2. 与服务器建立连接
3. 发送 HTTP 请求
4. 接收 HTTP 响应
5. 处理 HTML，并单独请求关联文件，例如图片和样式文件

浏览器解释接收到的 HTML，并根据它构建页面

## URL

URL 指定资源的地址。例如：

```text
http://localhost:8000/index.html
```

| 部分 | 值            | 用途                   |
| ---- | ------------- | ---------------------- |
| 方案 | `http`        | 访问方式（协议）       |
| 主机 | `localhost`   | 要连接的服务器         |
| 端口 | `8000`        | 服务器的网络端口       |
| 路径 | `/index.html` | 网站中资源的路径       |

如果未指定端口，浏览器会使用所选协议的标准端口：

- HTTP 使用 `80`
- HTTPS 使用 `443`

教学示例地址中明确指定了端口 `8000`，因为它不是 HTTP 的标准端口

## 域名、IP 地址和端口

DNS 查找与域名对应的 IP 地址

IP 地址指定网络地址，端口指定该地址上的服务。在 `127.0.0.1:8000` 中，端口是 `8000`

`localhost` 表示当前计算机。对于 IPv4，它通常对应地址 `127.0.0.1`

两个 TCP 服务器通常不能同时使用同一个 IP 地址和端口组合。如果端口 `8000` 已被占用，可以选择 `8080`

## HTTP 和 HTTPS

HTTP 是客户端和服务器之间交换请求与响应的协议

HTTPS 通过受 TLS 保护的连接传输 HTTP。浏览器与服务器之间的数据会被加密，并且可以检测数据在传输过程中是否被修改

对于自己计算机上的教学服务器，使用 HTTP 就足够了

## HTTP 请求和响应

打开页面时，浏览器通常会发送使用 `GET` 方法的请求。下面是一个简化的 HTTP/1.1 请求示例：

```http
GET /index.html HTTP/1.1
Host: localhost:8000
```

服务器返回状态码、响应头，并在需要时返回响应体：

```http
HTTP/1.1 200 OK
Content-Type: text/html; charset=utf-8

<!doctype html>
...
```

`Content-Type` 响应头告诉浏览器内容的类型，例如 `text/html` 或 `image/jpeg`

## HTTP 状态码

状态码的第一位数字表示请求处理的大致结果：

| 范围  | 含义                         |
| ----- | ---------------------------- |
| `1xx` | 已接收请求，正在继续处理     |
| `2xx` | 请求已成功完成               |
| `3xx` | 重定向或使用已保存的副本     |
| `4xx` | 服务器无法完成客户端请求     |
| `5xx` | 服务器处理请求时发生错误     |

常见状态码：

| 状态码                      | 含义                               |
| --------------------------- | ---------------------------------- |
| `200 OK`                    | 请求已完成，内容已返回             |
| `201 Created`               | 请求已完成，已创建新资源           |
| `204 No Content`            | 请求已完成，但没有响应体           |
| `301 Moved Permanently`     | 资源已永久移动到另一个地址         |
| `302 Found`                 | 资源暂时可通过另一个地址访问       |
| `304 Not Modified`          | 浏览器可以使用已保存的副本         |
| `400 Bad Request`           | 服务器无法解析请求                 |
| `401 Unauthorized`          | 访问需要身份验证                   |
| `403 Forbidden`             | 服务器理解请求，但拒绝访问         |
| `404 Not Found`             | 未找到请求的资源                   |
| `405 Method Not Allowed`    | 该资源不允许使用指定的 HTTP 方法   |
| `500 Internal Server Error` | 服务器程序内部错误                 |
| `502 Bad Gateway`           | 中间服务器收到了不正确的响应       |
| `503 Service Unavailable`   | 服务器暂时无法处理请求             |

状态码 `404` 表示已经与服务器建立连接，但指定路径下没有需要的资源。如果服务器未启动或地址不可访问，浏览器将不会收到 HTTP 状态码

## 本地 Web 服务器

可以直接从磁盘打开 HTML 文件，也可以通过服务器获取它：

```text
file:///C:/site/index.html
http://localhost:8000/index.html
```

第一种情况下，浏览器不使用 HTTP，直接读取文件；第二种情况下，浏览器向服务器发送请求

Python 模块 `http.server` 会提供当前文件夹中的文件。请求 `/` 时，它会返回 `index.html`；如果没有这个文件，则显示文件夹内容

`http.server` 适合学习和本地开发，但不适合将网站发布到互联网

## 代码编辑器

可以在任何能够处理纯文本的编辑器中编写 HTML。Microsoft Word 或 Pages 等文字处理软件不适合完成这项工作：它们会在保存文本的同时保存格式和辅助数据

合适的编辑器：

- Visual Studio Code - Windows 和 macOS
- Notepad++ - Windows
- Sublime Text - Windows 和 macOS

代码编辑器会高亮标签、显示文件夹结构，并帮助发现未闭合的引号和其他输入错误。HTML 文件应以 `.html` 扩展名保存，并使用 UTF-8 编码

## 终端和当前文件夹

终端使用文本命令启动程序。每个终端窗口都有一个当前文件夹。要启动本地服务器，当前文件夹必须是包含 `index.html` 的网站文件夹

### Windows

可以使用 `Win + R` 快捷键打开命令提示符：输入 `cmd`，然后按 `Enter`

使用 `cd /d` 命令进入网站文件夹：

```bat
cd /d "C:\Users\Student\Desktop\site"
```

参数 `/d` 可以在需要时切换到另一个磁盘。`dir` 命令显示当前文件夹的内容：

```bat
dir
```

另一种方法是在文件资源管理器中打开网站文件夹，在地址栏中输入 `cmd`，然后按 `Enter`。命令提示符会直接在所选文件夹中打开

### macOS

可以通过 Spotlight 打开 Terminal：按 `Command + Space`，输入 `Terminal`，然后按 `Enter`

要进入网站文件夹，请输入 `cd` 和一个空格，然后将文件夹从 Finder 拖到 Terminal 窗口中并按 `Enter`。完整命令大致如下：

```bash
cd "/Users/student/Desktop/site"
```

`pwd` 命令显示当前文件夹的路径，`ls` 命令显示其中的内容：

```bash
pwd
ls
```

包含空格的路径需要放在引号中

## 使用 Python 启动服务器

`http.server` 模块是 Python 3 的一部分，不需要单独安装。首先需要检查可用的 Python 版本

Windows：

```bat
python --version
```

如果找不到 `python` 命令，或者该命令启动的是 Python 2，请检查 Python Launcher：

```bat
py -3 --version
```

macOS：

```bash
python3 --version
```

进入网站文件夹后，使用以下命令之一启动服务器

Windows：

```bat
python -m http.server 8000 --bind 127.0.0.1
```

或者通过 Python Launcher：

```bat
py -3 -m http.server 8000 --bind 127.0.0.1
```

macOS：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

参数 `8000` 指定端口，`--bind 127.0.0.1` 只允许来自当前计算机的连接

服务器运行时，其进程会占用这个终端窗口。可以通过以下地址访问页面：

```text
http://127.0.0.1:8000/
```

修改文件后，只需保存文件并在浏览器中刷新页面。不需要重新启动服务器

要停止服务器，请返回终端并按 `Ctrl + C`

## 检查请求

运行中的 `http.server` 会在终端中显示每个请求及其状态码。打开页面时，日志中会出现请求 `GET /`，通常状态码为 `200`。如果浏览器使用已保存的副本，则可能出现状态码 `304`

可以在浏览器开发者工具中查看详细信息。在 Windows 中通常按 `F12` 打开；在 macOS 的 Chrome 和 Firefox 中使用 `Command + Option + I` 快捷键打开

`Network` 选项卡显示每个已加载资源的地址、方法、状态码和类型。如果打开此选项卡并刷新页面，将分别看到对 HTML 文件、图片和样式文件的请求

## 其他 Web 服务器

服务器一词既可以指计算机，也可以指接收请求的程序。一台计算机可以同时在不同端口上运行多个服务器程序

Web 服务器不仅用于提供现成的 HTML 文件。它们还可以将请求转发给其他程序、限制访问、记录请求日志以及配置 HTTPS

服务器软件示例：

- Apache HTTP Server - 拥有大量模块的常用 Web 服务器
- nginx - Web 服务器，也可作为中间服务器将请求转发给其他应用程序
- Caddy - 可以自动配置 HTTPS 的 Web 服务器
- Live Server - 用于在本地查看页面并自动刷新浏览器的 Visual Studio Code 扩展

本课程使用 `http.server`，因为对于静态教学网站，一条命令就足够，并且不需要额外配置

## 常见错误

### 显示文件列表

当前文件夹中没有 `index.html`，或者服务器不是从网站文件夹启动的

### 响应状态码为 404

网站文件夹中没有该文件，或者地址中的路径书写错误。文件名的字母大小写可能有影响

### 端口已被占用

另一个进程已经在使用端口 `8000`。可以停止之前启动的服务器，或者在命令和浏览器地址中将端口改为 `8080`

### 看不到更改

需要在编辑器中保存文件，并在浏览器中刷新页面
