# Интернет, HTTP и локальный веб-сервер

## Интернет и веб

Интернет объединяет сети и позволяет устройствам обмениваться данными. Веб, электронная почта и мессенджеры - разные сервисы интернета

Браузер работает как клиент: запрашивает ресурсы и отображает их. Веб-сервер принимает запросы и возвращает ответы

## Как браузер получает страницу

При открытии сайта браузер выполняет несколько действий:

1. Разбирает URL и через DNS получает IP-адрес сервера
2. Устанавливает соединение с сервером
3. Отправляет HTTP-запрос
4. Получает HTTP-ответ
5. Обрабатывает HTML и отдельно запрашивает связанные файлы, например изображения и стили

Браузер интерпретирует полученный HTML и строит по нему страницу

## URL

URL указывает адрес ресурса. Например:

```text
http://localhost:8000/index.html
```

| Часть | Значение      | Назначение                    |
| ----- | ------------- | ----------------------------- |
| Схема | `http`        | Способ (протокол) доступа     |
| Хост  | `localhost`   | Сервер, к которому обращаются |
| Порт  | `8000`        | Сетевой порт сервера          |
| Путь  | `/index.html` | Путь к ресурсу на сайте       |

Если порт не указан, браузер использует стандартный порт выбранной схемы:

- для HTTP - `80`
- для HTTPS - `443`

Порт `8000` в учебном адресе указан явно, потому что он не является стандартным для HTTP

## Домен, IP-адрес и порт

DNS находит IP-адрес, соответствующий доменному имени

IP-адрес указывает сетевой адрес, а порт - службу по этому адресу. В записи `127.0.0.1:8000` портом является `8000`

`localhost` обозначает текущий компьютер. Для IPv4 ему обычно соответствует адрес `127.0.0.1`

Два TCP-сервера обычно не могут одновременно использовать одну комбинацию IP-адреса и порта. Если порт `8000` занят, можно выбрать `8080`

## HTTP и HTTPS

HTTP - протокол обмена запросами и ответами между клиентом и сервером

HTTPS передает HTTP через защищенное соединение TLS. Данные между браузером и сервером шифруются, а их изменение при передаче можно обнаружить

Для учебного сервера на своем компьютере достаточно HTTP

## HTTP-запрос и ответ

При открытии страницы браузер обычно отправляет запрос с методом `GET`. Упрощенный пример запроса HTTP/1.1:

```http
GET /index.html HTTP/1.1
Host: localhost:8000
```

Сервер возвращает код состояния, заголовки и, если требуется, тело ответа:

```http
HTTP/1.1 200 OK
Content-Type: text/html; charset=utf-8

<!doctype html>
...
```

Заголовок `Content-Type` сообщает браузеру тип содержимого, например `text/html` или `image/jpeg`

## Коды состояния HTTP

Первая цифра кода обозначает общий результат обработки запроса:

| Диапазон | Значение                                      |
| -------- | --------------------------------------------- |
| `1xx`    | Запрос принят, обработка продолжается         |
| `2xx`    | Запрос успешно выполнен                       |
| `3xx`    | Перенаправление или работа с сохраненной копией |
| `4xx`    | Сервер не может выполнить запрос клиента      |
| `5xx`    | Ошибка при обработке запроса на сервере       |

Распространенные коды:

| Код                         | Значение                                              |
| --------------------------- | ----------------------------------------------------- |
| `200 OK`                    | Запрос выполнен, содержимое возвращено                |
| `201 Created`               | Запрос выполнен, новый ресурс создан                  |
| `204 No Content`            | Запрос выполнен, но тела ответа нет                   |
| `301 Moved Permanently`     | Ресурс постоянно перемещен на другой адрес            |
| `302 Found`                 | Ресурс временно доступен по другому адресу            |
| `304 Not Modified`          | Браузер может использовать сохраненную копию          |
| `400 Bad Request`           | Сервер не смог разобрать запрос                       |
| `401 Unauthorized`          | Для доступа требуется аутентификация                  |
| `403 Forbidden`             | Сервер понял запрос, но отказывает в доступе          |
| `404 Not Found`             | Запрошенный ресурс не найден                          |
| `405 Method Not Allowed`    | Указанный HTTP-метод не разрешен для ресурса           |
| `500 Internal Server Error` | Внутренняя ошибка серверной программы                 |
| `502 Bad Gateway`           | Промежуточный сервер получил некорректный ответ        |
| `503 Service Unavailable`   | Сервер временно не готов обрабатывать запрос          |

Код `404` означает, что соединение с сервером установлено, но нужного ресурса по указанному пути нет. Если сервер не запущен или адрес недоступен, браузер не получит HTTP-код

## Локальный веб-сервер

HTML-файл можно открыть напрямую с диска или получить через сервер:

```text
file:///C:/site/index.html
http://localhost:8000/index.html
```

В первом случае браузер читает файл без HTTP, во втором - отправляет запрос серверу

Модуль Python `http.server` раздает файлы из текущей папки. При запросе `/` он возвращает `index.html`, а при отсутствии файла показывает содержимое папки

`http.server` подходит для обучения и локальной разработки, но не для публикации сайта в интернете

## Редактор кода

HTML можно написать в любом редакторе, который работает с обычным текстом. Текстовые процессоры, например Microsoft Word или Pages, для этого не подходят: они сохраняют оформление и служебные данные вместе с текстом

Подходящие редакторы:

- Visual Studio Code - Windows и macOS
- Notepad++ - Windows
- Sublime Text - Windows и macOS

Редактор кода подсвечивает теги, показывает структуру папок и помогает заметить незакрытые кавычки и другие опечатки. HTML-файлы следует сохранять с расширением `.html` в кодировке UTF-8

## Терминал и текущая папка

Терминал запускает программы с помощью текстовых команд. У каждого окна терминала есть текущая папка. Для запуска локального сервера текущей должна быть папка сайта, в которой находится `index.html`

### Windows

Командную строку можно открыть сочетанием `Win + R`: введите `cmd` и нажмите `Enter`

Для перехода в папку сайта используется команда `cd /d`:

```bat
cd /d "C:\Users\Student\Desktop\site"
```

Ключ `/d` позволяет при необходимости перейти и на другой диск. Команда `dir` показывает содержимое текущей папки:

```bat
dir
```

Другой способ - открыть папку сайта в Проводнике, ввести `cmd` в адресной строке и нажать `Enter`. Командная строка сразу откроется в выбранной папке

### macOS

Terminal можно открыть через Spotlight: нажмите `Command + Space`, введите `Terminal` и нажмите `Enter`

Для перехода в папку сайта введите `cd` и пробел, затем перетащите папку из Finder в окно Terminal и нажмите `Enter`. Полная команда будет выглядеть примерно так:

```bash
cd "/Users/student/Desktop/site"
```

Команда `pwd` показывает путь к текущей папке, а `ls` - ее содержимое:

```bash
pwd
ls
```

Путь с пробелами нужно заключать в кавычки

## Запуск сервера с помощью Python

Модуль `http.server` входит в Python 3 и не требует отдельной установки. Сначала нужно проверить доступную версию Python

Windows:

```bat
python --version
```

Если команда `python` не найдена или запускает Python 2, проверьте Python Launcher:

```bat
py -3 --version
```

macOS:

```bash
python3 --version
```

После перехода в папку сайта сервер запускается одной из команд

Windows:

```bat
python -m http.server 8000 --bind 127.0.0.1
```

или через Python Launcher:

```bat
py -3 -m http.server 8000 --bind 127.0.0.1
```

macOS:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Параметр `8000` задает порт, а `--bind 127.0.0.1` разрешает подключения только с текущего компьютера

Пока сервер работает, окно терминала занято его процессом. Страница доступна по адресу:

```text
http://127.0.0.1:8000/
```

После изменения файла достаточно сохранить его и обновить страницу в браузере. Перезапускать сервер не требуется

Для остановки сервера вернитесь в терминал и нажмите `Ctrl + C`

## Проверка запросов

Работающий `http.server` выводит в терминал каждый запрос и его код состояния. При открытии страницы в журнале появится запрос `GET /`, обычно с кодом `200`. Для сохраненной браузером копии возможен код `304`

Подробности можно посмотреть в инструментах разработчика браузера. В Windows они обычно открываются клавишей `F12`, в macOS для Chrome и Firefox - сочетанием `Command + Option + I`

Во вкладке `Network` отображаются адрес, метод, код состояния и тип каждого загруженного ресурса. Если открыть эту вкладку и обновить страницу, отдельно появятся запросы к HTML-файлу, изображениям и стилям

## Другие веб-серверы

Слово сервер может обозначать как компьютер, так и программу, которая принимает запросы. Один компьютер может одновременно запускать несколько серверных программ на разных портах

Веб-серверы используются не только для выдачи готовых HTML-файлов. Они могут перенаправлять запросы другим программам, ограничивать доступ, вести журнал запросов и настраивать HTTPS

Примеры серверного ПО:

- Apache HTTP Server - распространенный веб-сервер с большим количеством модулей
- nginx - веб-сервер и промежуточный сервер для передачи запросов другим приложениям
- Caddy - веб-сервер с автоматической настройкой HTTPS
- Live Server - расширение Visual Studio Code для локального просмотра страницы и автоматического обновления браузера

В курсе используется `http.server`, потому что для статического учебного сайта достаточно одной команды и не нужна дополнительная настройка

## Частые ошибки

### Открывается список файлов

В текущей папке нет `index.html` или сервер запущен не из папки сайта

### Ответ имеет код 404

Файла нет в папке сайта или путь в адресе написан неверно. Регистр букв в именах файлов может иметь значение

### Порт занят

Другой процесс уже использует порт `8000`. Можно остановить ранее запущенный сервер или заменить порт на `8080` в команде и адресе браузера

### Изменения не видны

Нужно сохранить файл в редакторе и обновить страницу в браузере
