# Интернет, HTTP и локальный веб-сервер

## Интернет и веб

Интернет - это объединение компьютерных сетей, которое позволяет устройствам обмениваться данными. Сайты, электронная почта и мессенджеры используют интернет, но являются разными сервисами

Веб - это система документов и ресурсов, доступных по адресам URL. Для работы веба обычно используются:

- браузер, который запрашивает и отображает ресурсы
- веб-сервер, который принимает запросы и возвращает ответы
- HTTP, который задает формат обмена между ними

Браузер выполняет роль клиента. Клиент начинает обмен, отправляя запрос. Сервер ожидает запросы и отвечает на них

Слово сервер может обозначать как отдельный компьютер, так и программу. На одном компьютере могут одновременно работать несколько серверных программ

## Браузер

Браузер совмещает несколько задач:

- принимает URL из адресной строки
- выполняет сетевые запросы
- получает файлы и проверяет их типы
- обрабатывает HTML и CSS
- загружает связанные ресурсы
- формирует изображение страницы
- сохраняет часть ресурсов в кеше

Исходные файлы и отображаемая страница не являются одним и тем же. Браузер интерпретирует полученные данные и строит по ним результат. Инструменты разработчика позволяют посмотреть этот процесс и найти ошибки загрузки

## Как браузер получает страницу

При открытии сайта происходит последовательность действий:

1. Браузер разбирает введенный URL
2. По доменному имени определяется IP-адрес сервера (с помощью DNS)
3. Браузер устанавливает сетевое соединение с сервером
4. Браузер отправляет HTTP-запрос
5. Сервер возвращает HTTP-ответ
6. Браузер обрабатывает ответ и отображает страницу
7. Для изображений, стилей и других файлов браузер отправляет отдельные запросы

Одна страница поэтому может потребовать десятки HTTP-запросов

## URL

URL указывает адрес ресурса. Рассмотрим пример:

```text
https://example.com:443/catalog/card.html?theme=dark#details
```

Он состоит из следующих частей:

| Часть     | Значение             | Назначение                       |
| --------- | -------------------- | -------------------------------- |
| Схема     | `https`              | Протокол доступа                 |
| Хост      | `example.com`        | Доменное имя сервера             |
| Порт      | `443`                | Сетевая точка входа в программу  |
| Путь      | `/catalog/card.html` | Расположение ресурса на сервере  |
| Параметры | `theme=dark`         | Дополнительные данные запроса    |
| Фрагмент  | `details`            | Место внутри открытого документа |

Порт часто не пишется в адресе. Для HTTP по умолчанию используется порт `80`, для HTTPS - `443`

Фрагмент после `#` обрабатывается браузером и не передается серверу в HTTP-запросе

## Домен и IP-адрес

Компьютеры обращаются друг к другу по IP-адресам, например `93.184.216.34`. Доменное имя `example.com` проще запомнить человеку

DNS сопоставляет доменное имя с IP-адресом. Упрощенно это выглядит так:

```text
example.com -> DNS -> 93.184.216.34
```

Один домен может соответствовать нескольким IP-адресам, а один IP-адрес может обслуживать несколько доменов

## HTTP и HTTPS

HTTP это протокол, который определяет структуру запросов и ответов. Он не описывает внешний вид страницы и не хранит файлы сам по себе

HTTPS использует HTTP внутри защищенного соединения. Шифрование не позволяет постороннему наблюдателю прочитать передаваемые данные или незаметно изменить их

Для учебного сервера на собственном компьютере достаточно HTTP. Публичные сайты должны использовать HTTPS

## HTTP-запрос

Запрос содержит метод, путь, версию протокола и заголовки. Пример:

```http
GET /index.html HTTP/1.1
Host: localhost:8000
Accept: text/html
```

Часто используемые методы:

| Метод    | Назначение                    |
| -------- | ----------------------------- |
| `GET`    | Получить ресурс               |
| `POST`   | Передать новые данные серверу |
| `PUT`    | Заменить ресурс целиком       |
| `PATCH`  | Изменить часть ресурса        |
| `DELETE` | Удалить ресурс                |

При обычном открытии страницы браузер отправляет запрос `GET`

## HTTP-ответ

Ответ содержит код состояния, заголовки и иногда тело с данными:

```http
HTTP/1.1 200 OK
Content-Type: text/html; charset=utf-8
Content-Length: 1256

<!doctype html>
...
```

Код состояния сообщает результат обработки запроса:

| Диапазон | Значение                            | Примеры                                             |
| -------- | ----------------------------------- | --------------------------------------------------- |
| `2xx`    | Запрос выполнен                     | `200 OK`                                            |
| `3xx`    | Требуется переход по другому адресу | `301 Moved Permanently`, `302 Found`                |
| `4xx`    | Ошибка в запросе клиента            | `400 Bad Request`, `403 Forbidden`, `404 Not Found` |
| `5xx`    | Ошибка на стороне сервера           | `500 Internal Server Error`                         |

Код `404` означает, что сервер доступен, но не нашел запрошенный ресурс. Это отличается от ситуации, когда соединение с сервером вообще не установлено

## Заголовки и MIME-типы

HTTP-заголовки передают служебную информацию об обмене. Например:

- `Content-Type` сообщает тип содержимого ответа
- `Content-Length` сообщает размер тела ответа в байтах
- `Location` содержит новый адрес при перенаправлении
- `Cache-Control` задает правила кеширования

MIME-тип в заголовке `Content-Type` помогает браузеру выбрать способ обработки файла:

| MIME-тип          | Содержимое       |
| ----------------- | ---------------- |
| `text/html`       | HTML-документ    |
| `text/css`        | Таблица стилей   |
| `image/jpeg`      | Изображение JPEG |
| `image/png`       | Изображение PNG  |
| `application/pdf` | Документ PDF     |

Расширение файла полезно человеку и серверу, но браузер ориентируется прежде всего на `Content-Type` ответа

## IP-адрес и порт

IP-адрес определяет устройство или его сетевой интерфейс. Порт определяет программу внутри этого устройства

Это можно представить как пару:

```text
адрес устройства:порт программы
127.0.0.1:8000
```

Номер порта находится в диапазоне от `0` до `65535`. Для локальной разработки часто выбирают `8000` или `8080`

Две программы не могут одновременно принимать соединения на одной и той же комбинации IP-адреса и порта. Если порт занят, сервер завершится с ошибкой или потребуется другой номер

## localhost и адреса локальной сети

`localhost` обозначает текущий компьютер. Обычно ему соответствует IP-адрес `127.0.0.1`

Адрес:

```text
http://localhost:8000/
```

открывает порт `8000` на том же компьютере, где работает браузер

Компьютер также получает адрес в локальной сети, например `192.168.1.25`. По нему сервер может быть доступен другим устройствам в той же сети, если программа принимает внешние соединения и доступ не блокирует межсетевой экран

При запуске учебного сервера используется привязка к `127.0.0.1`. Она разрешает подключения только с текущего компьютера

Адрес `0.0.0.0` применяется серверной программой для приема соединений через все сетевые интерфейсы. Открывать учебный сервер для сети без необходимости не следует

## Локальный веб-сервер

HTML-файл можно открыть двумя способами:

```text
file:///C:/site/index.html
http://localhost:8000/index.html
```

В первом случае браузер читает файл напрямую с диска. HTTP-запрос и HTTP-ответ отсутствуют

Во втором случае браузер обращается к локальной серверной программе. Такое окружение ближе к работе настоящего сайта и позволяет увидеть HTTP-коды, заголовки и корректные типы файлов

Модуль `http.server` входит в Python 3 и подходит для раздачи статических файлов. Сервер использует текущую папку терминала как корень сайта. При запросе `/` он пытается открыть файл `index.html`

Этот сервер предназначен для обучения и локальной разработки. Публиковать с его помощью сайт в интернете не следует

## Терминал и текущая папка

Терминал позволяет запускать программы текстовыми командами. Каждая вкладка терминала имеет текущую папку. Команда запуска сервера должна выполняться из папки сайта

### Windows

Открыть командную строку:

1. Нажать `Win + R`
2. Ввести `cmd`
3. Нажать `Enter`

Полезные команды:

```bat
cd /d "C:\Users\Student\Desktop\site"
dir
```

`cd /d` меняет текущую папку и при необходимости переключает диск. `dir` показывает содержимое папки

### macOS

Открыть терминал:

1. Нажать `Command + Space`
2. Ввести `Terminal`
3. Нажать `Enter`

Полезные команды:

```bash
cd "/Users/student/Desktop/site"
pwd
ls
python3 --version
```

`pwd` показывает текущую папку. `ls` показывает ее содержимое

Путь с пробелами необходимо заключать в кавычки. На macOS папку также можно перетащить из Finder в окно терминала, чтобы вставить ее полный путь

## Запуск HTTP сервера (с помощью Python)

Требуется Python 3. Проверить версию можно следующими командами

Windows:

```bat
python --version
```

Если команда `python` не найдена, можно проверить Python Launcher:

```bat
py -3 --version
```

macOS:

```bash
python3 --version
```

После перехода в папку сайта сервер запускается одной из команд

Windows:

```bat
python -m http.server 8000 --bind 127.0.0.1
```

или:

```bat
py -3 -m http.server 8000 --bind 127.0.0.1
```

macOS:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Пока сервер работает, терминал занят его процессом. Остановить сервер можно сочетанием `Ctrl + C`

## Проверка ответа

Откройте в браузере:

```text
http://localhost:8000/
```

Инструменты разработчика браузера открываются клавишей `F12` в Windows или сочетанием `Command + Option + I` в macOS. Во вкладке `Network` можно увидеть адрес каждого запроса, метод, код состояния и MIME-тип ответа

В macOS и системах с установленной программой `curl` заголовки вместе с телом ответа можно вывести в терминал:

```bash
curl -i http://localhost:8000/
```

`curl` не входит в стандартную установку Windows 7, поэтому для выполнения лабораторной работы он не требуется

## Частые ошибки

### Сервер показывает список файлов

В текущей папке нет файла `index.html` или сервер запущен не из папки сайта

### Ответ имеет код 404

Запрошенного файла нет в корне сайта или путь в адресе написан неверно. Регистр букв в именах файлов может иметь значение

### Изображение не отображается

Имя файла или путь к нему не совпадает с адресом, указанным в документе. В инструментах разработчика такой запрос обычно имеет код `404`

### Порт занят

Другой процесс уже использует этот порт. Можно остановить ранее запущенный сервер или выбрать порт `8080`, изменив номер и в команде, и в адресе браузера

### Изменения не видны

Необходимо сохранить файл в редакторе и обновить страницу в браузере. Перезапускать статический сервер после каждого изменения файла не требуется
