# Лабораторная работа 1: Локальный веб-сервер и первая страница

## Задание

Создать страницу участника курса и открыть ее через локальный веб-сервер

Для работы требуется Python 3 и редактор кода

## Структура проекта

Создайте папку `lab1-server` со следующей структурой

```text
lab1-server/
|-- index.html
`-- assets/
    `-- avatar.jpg
```

Названия папок и файлов должны совпадать со схемой, включая регистр букв

В Windows включите отображение расширений файлов или проверьте, что файл не получил имя `index.html.txt`

## Страница

Откройте папку `lab1-server` в редакторе кода, создайте файл `index.html` и скопируйте в него следующий код

```html
<!doctype html>
<html lang="ru">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Участник курса</title>
  </head>
  <body>
    <main>
      <h1>Имя Фамилия</h1>
      <img src="assets/avatar.jpg" alt="Аватар участника курса" width="240" />
      <p>Группа: AAA-XX-XX</p>
      <p>Моя первая страница работает на локальном веб-сервере</p>
    </main>
  </body>
</html>
```

Замените `Имя Фамилия` и `AAA-XX-XX` своими данными

Выберите квадратное изображение в формате JPEG, переименуйте его в `avatar.jpg` и поместите в папку `assets`

Сохраните `index.html`

## Запуск в Windows

Откройте командную строку

1. Нажмите `Win + R`
2. Введите `cmd`
3. Нажмите `Enter`

В Проводнике откройте папку `lab1-server` и скопируйте ее путь из адресной строки

В командной строке введите `cd /d`, добавьте пробел и вставьте путь в кавычках, например

```bat
cd /d "C:\Users\Student\Desktop\lab1-server"
```

Проверьте версию Python

```bat
python --version
```

Если команда вывела версию Python 3, запустите сервер

```bat
python -m http.server 8000 --bind 127.0.0.1
```

Если команда `python` не найдена, проверьте Python Launcher

```bat
py -3 --version
```

При наличии Python 3 запустите сервер через Launcher

```bat
py -3 -m http.server 8000 --bind 127.0.0.1
```

## Запуск в macOS

Откройте Terminal через поиск Spotlight

1. Нажмите `Command + Space`
2. Введите `Terminal`
3. Нажмите `Enter`

Введите `cd` и пробел, перетащите папку `lab1-server` из Finder в окно Terminal и нажмите `Enter`

Проверьте версию Python

```bash
python3 --version
```

Запустите сервер

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

## Проверка

Не закрывая терминал, откройте в браузере адрес

```text
http://localhost:8000/
```

На странице должны отображаться ваши имя, группа и изображение

Адрес страницы должен начинаться с `http://localhost:8000`, а не с `file://`

Откройте инструменты разработчика клавишей `F12` в Windows или сочетанием `Command + Option + I` в macOS

Откройте вкладку `Network` и обновите страницу

Запросы `index.html` и `avatar.jpg` должны иметь код состояния `200`

Для остановки сервера вернитесь в терминал и нажмите `Ctrl + C`

## Если сервер не запускается

Если порт `8000` занят, запустите сервер на порту `8080`, заменив номер в команде и адресе браузера

Если открывается список файлов, проверьте наличие `index.html` в папке, из которой запущен сервер

Если изображение не отображается, проверьте имя `avatar.jpg`, расширение файла и папку `assets`
