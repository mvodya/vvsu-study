# Лабораторная работа 1: Локальный веб-сервер и первая страница

## Задание

Создать персональную страницу с именем, учебной группой и изображением и открыть ее через локальный веб-сервер

Для работы нужны Python 3 и редактор кода

## Структура проекта

Создайте папку `lab1-server` со следующей структурой

```text
lab1-server/
|-- index.html
`-- assets/
    `-- avatar.jpg
```

Названия папок и файлов должны совпадать со схемой, включая регистр букв

В Windows включите отображение расширений файлов или проверьте, что файл не получил имя `index.html.txt`

## Страница

Откройте папку `lab1-server` в редакторе кода, создайте файл `index.html` и скопируйте в него следующий код

```html
<!doctype html>
<html lang="ru">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Участник курса</title>
  </head>
  <body>
    <h1>Имя Фамилия</h1>
    <img src="assets/avatar.jpg" alt="Аватар участника курса" width="240" />
    <p>Группа: AAA-XX-XX</p>
    <p>Моя первая страница работает на локальном веб-сервере</p>
  </body>
</html>
```

Замените `Имя Фамилия` и `AAA-XX-XX` своими данными

Выберите квадратное изображение в формате JPEG размером не менее 240 x 240 пикселей, сохраните его под именем `avatar.jpg` (или иным расширением) и поместите в папку `assets`

Сохраните `index.html` в кодировке UTF-8

## Запуск в Windows

Откройте командную строку - нажмите `Win + R`, введите `cmd` и нажмите `Enter`

В Проводнике откройте папку `lab1-server` и скопируйте ее путь из адресной строки

В командной строке введите `cd /d`, добавьте пробел и вставьте путь в кавычках, например

```bat
cd /d "C:\Users\Student\Desktop\lab1-server"
```

Проверьте версию Python

```bat
python --version
```

Если команда вывела версию Python 3, запустите сервер

```bat
python -m http.server 8000 --bind 127.0.0.1
```

Если команда `python` не найдена, используйте Python Launcher

```bat
py -3 -m http.server 8000 --bind 127.0.0.1
```

## Запуск в macOS

Откройте Terminal через Spotlight - нажмите `Command + Space`, введите `Terminal` и нажмите `Enter`

Введите `cd` и пробел, перетащите папку `lab1-server` из Finder в окно Terminal и нажмите `Enter`

Проверьте версию Python

```bash
python3 --version
```

Запустите сервер

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

## Проверка

Не закрывая окно, в котором запущен сервер, откройте в браузере адрес

```text
http://127.0.0.1:8000/
```

На странице должны отображаться ваши имя, группа и изображение

Адрес страницы должен начинаться с `http://127.0.0.1:8000`, а не с `file://`

В окне сервера должны появиться запросы `GET /` и `GET /assets/avatar.jpg` без кода `404`

Для остановки сервера вернитесь в окно, в котором он запущен, и нажмите `Ctrl + C`

## Если сервер не запускается

Если порт `8000` занят, замените `8000` на `8080` в команде запуска и откройте `http://127.0.0.1:8080/`

Если открывается список файлов, проверьте наличие `index.html` в папке, из которой запущен сервер

Если изображение не отображается, проверьте путь `assets/avatar.jpg`, имя файла, расширение и фактический формат изображения
