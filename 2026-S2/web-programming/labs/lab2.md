# Лабораторная работа 2: Базовый HTML

## Задание

Создать одностраничную афишу фестиваля городской графики `Контур`

Страница выполняется только на HTML без CSS

## Структура проекта

Создайте новый проект со следующей структурой

```text
lab2-poster/
|-- index.html
`-- assets/
    `-- poster.jpg
```

Файл `poster.jpg` должен содержать изображение городской архитектуры, плаката или уличной графики в формате JPEG

## Служебная часть

Создайте в `index.html` базовую структуру HTML-документа

Укажите следующие значения

- язык документа - `ru`
- кодировка - `UTF-8`
- настройка viewport - `width=device-width, initial-scale=1.0`
- название вкладки - `Контур - фестиваль городской графики`

## Содержимое страницы

Разместите в начале страницы заголовок первого уровня `Контур` с идентификатором `top`

Под ним добавьте абзац

```text
Фестиваль городской графики во Владивостоке
```

Создайте четыре ссылки для перехода к разделам этой же страницы

- `О фестивале` с адресом `#about`
- `Направления` с адресом `#directions`
- `Программа` с адресом `#program`
- `Место проведения` с адресом `#location`

После ссылок добавьте изображение `assets/poster.jpg` шириной `720` с альтернативным текстом

```text
Афиша фестиваля городской графики Контур
```

## О фестивале

Создайте заголовок второго уровня `О фестивале` с идентификатором `about`

Добавьте два отдельных абзаца

```text
Контур объединяет дизайнеров, иллюстраторов и художников, которые работают с городской средой
```

```text
В программе выставка плакатов, открытые лекции и практические мастер-классы
```

В первом абзаце выделите слово `Контур` как важный фрагмент, во втором сделайте смысловой акцент на словах `практические мастер-классы`

## Направления

Создайте заголовок второго уровня `Направления` с идентификатором `directions`

Разместите под ним маркированный список

- Типографика в городской среде
- Плакат и социальная реклама
- Навигация и пиктограммы
- Цифровая иллюстрация

## Программа

Создайте заголовок второго уровня `Программа` с идентификатором `program`

Разместите под ним нумерованный список

1. 10:00 - открытие выставки
2. 12:00 - лекция о городской типографике
3. 15:00 - мастер-класс по созданию плаката
4. 18:00 - встреча с участниками фестиваля

## Место проведения

Создайте заголовок второго уровня `Место проведения` с идентификатором `location`

Добавьте адрес с переносом строки между улицей и городом

```text
Океанский проспект, 19
Владивосток
```

Под адресом разместите информацию

```text
20 апреля, с 10:00 до 20:00
```

Добавьте ссылку `Сайт ВВГУ`, ведущую на `https://www.vvsu.ru/` и открывающуюся в новой вкладке с атрибутами `target="_blank"` и `rel="noopener"`

Отделите нижнюю часть страницы горизонтальным разделителем и добавьте ссылку `Вернуться к началу` с адресом `#top`

## Запуск

Запустите локальный веб-сервер из папки `lab2-poster` и откройте страницу по HTTP
