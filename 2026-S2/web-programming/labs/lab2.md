# Лабораторная работа 2: Базовый HTML

## Задание

Создать HTML-страницу с учебной афишей собственного вымышленного фестиваля

Страница выполняется только на HTML - не подключайте CSS и не используйте элемент `style` или одноименный атрибут

## Идея фестиваля

Перед созданием страницы придумайте

- название фестиваля
- тему и аудиторию: чему он посвящен и кому будет интересен
- место проведения: город, площадку и адрес, реальные или вымышленные
- дату и время проведения

Подберите тексты, направления, события и изображение под выбранную тему

## Структура проекта

Создайте новый проект со следующей структурой

```text
lab2-poster/
|-- index.html
`-- assets/
    `-- poster.jpg
```

Выберите изображение по теме своего фестиваля в формате JPEG шириной не менее 720 пикселей, сохраните его под именем `poster.jpg` и поместите в папку `assets`

Если исходный файл имеет другой формат, экспортируйте его в JPEG - простое изменение расширения не меняет формат изображения

В Windows включите отображение расширений файлов или проверьте, что файлы не получили имена `index.html.txt` и `poster.jpg.jpg`

## Служебная часть

Создайте HTML-документ с `<!doctype html>` и элементами `html`, `head` и `body`

Укажите следующие значения

- атрибут `lang="ru"` у элемента `html`
- элемент `<meta charset="UTF-8" />`
- элемент `<meta name="viewport" content="width=device-width, initial-scale=1.0" />`
- элемент `title` с названием фестиваля и кратким указанием его темы

Сохраните `index.html` в кодировке UTF-8

## Содержимое страницы

Разместите в начале страницы заголовок первого уровня с идентификатором `top` и названием своего фестиваля

Под ним добавьте абзац с темой фестиваля и городом проведения

Создайте пять элементов `a` для перехода к разделам этой же страницы

- `О фестивале` с адресом `#about`
- `Направления` с адресом `#directions`
- `Программа` с адресом `#program`
- `Участникам` с адресом `#participants`
- `Место проведения` с адресом `#location`

После ссылок добавьте элемент `a` с адресом `#program`

Внутрь ссылки поместите элемент `img` с атрибутами `src="assets/poster.jpg"`, `width="720"` и текстом `alt` по шаблону `Перейти к программе фестиваля [название]`, подставив свое название

## О фестивале

Создайте заголовок второго уровня `О фестивале` с идентификатором `about`

Добавьте три отдельных абзаца по одному-два предложения

1. Чему посвящен фестиваль и кого он объединяет - название фестиваля поместите в элемент `strong`
2. Какие занятия ждут посетителей - один значимый фрагмент поместите в элемент `em`
3. Что посетитель сможет увидеть или попробовать

## Направления

Создайте заголовок второго уровня `Направления` с идентификатором `directions`

Разместите под ним маркированный список из шести пунктов с помощью элементов `ul` и `li`

Назовите направления по теме фестиваля, каждое название должно состоять не более чем из шести слов

## Программа

Создайте заголовок второго уровня `Программа` с идентификатором `program`

Разместите под ним нумерованный список из шести пунктов с помощью элементов `ol` и `li`

Придумайте события по теме фестиваля и расположите их по времени в пределах выбранных часов проведения

Для каждого пункта используйте формат `10:00 - название события`

## Участникам

Создайте заголовок второго уровня `Участникам` с идентификатором `participants`

Добавьте абзац

```text
Для участия в фестивале необходима предварительная регистрация
```

Поместите слова `предварительная регистрация` в элемент `strong`

Добавьте заголовок третьего уровня `Что взять с собой`, а под ним маркированный список из шести пунктов

Первые три пункта заданы

- Блокнот и ручку
- Телефон с зарядным устройством
- Подтверждение регистрации

Оставшиеся три пункта придумайте с учетом занятий на своем фестивале

Добавьте заголовок третьего уровня `Порядок участия`, а под ним нумерованный список из пяти пунктов

Первые три пункта заданы

1. Выбрать событие из программы
2. Зарегистрироваться на сайте фестиваля
3. Прийти за 15 минут до начала

Добавьте еще два действия самостоятельно, сохранив логичный порядок шагов

## Место проведения

Создайте заголовок второго уровня `Место проведения` с идентификатором `location`

Укажите название выбранной площадки в отдельном элементе `p`

Добавьте ее адрес в одном элементе `p` и поставьте элемент `br` между улицей с номером дома и городом

Под адресом добавьте отдельный элемент `p` с выбранной датой и временем проведения

Добавьте еще один абзац и самостоятельно напишите одно предложение с ориентиром или способом добраться до места проведения

Добавьте элемент `a` со ссылкой на существующий сайт по теме фестиваля или сайт выбранной площадки, понятным текстом ссылки и атрибутами `target="_blank"` и `rel="noopener"`

Добавьте элемент `hr`, а после него элемент `a` с текстом `Вернуться к началу` и адресом `#top`

## Проверка

Откройте страницу в браузере через любой локальный веб-сервер, используя адрес и порт своего сервера

Страница и изображение должны открываться по HTTP, а запросы `/` и `/assets/poster.jpg` не должны иметь код `404`

Проверьте переходы по пяти ссылкам в начале страницы и по ссылке `Вернуться к началу`

При нажатии на изображение страница должна переходить к разделу `Программа`
