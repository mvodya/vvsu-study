# 实验作业 2：HTML 基础

## 作业内容

创建一个 HTML 页面，作为自己构思的虚构节庆活动的教学用宣传页

页面只能使用 HTML - 不要引入 CSS，也不要使用 `style` 元素或同名属性

## 活动构思

制作页面之前，先构思以下内容

- 活动名称
- 主题和目标受众：活动围绕什么主题，哪些人会感兴趣
- 举办地点：城市、场地和地址，可以是真实的，也可以是虚构的
- 举办日期和时间

根据所选主题准备文字、主题方向、活动项目和图片

## 项目结构

创建一个新项目，其结构如下

```text
lab2-poster/
|-- index.html
`-- assets/
    `-- poster.jpg
```

选择一张符合活动主题、宽度至少为 720 像素的 JPEG 格式图片，将其以 `poster.jpg` 为文件名保存，并放入 `assets` 文件夹

如果原文件使用其他格式，请将其导出为 JPEG - 仅修改扩展名不会改变图片格式

在 Windows 中启用文件扩展名显示，或者检查文件名是否被保存为 `index.html.txt` 和 `poster.jpg.jpg`

## 文档基本设置

创建一个包含 `<!doctype html>` 声明以及 `html`、`head` 和 `body` 元素的 HTML 文档

设置以下内容

- 为 `html` 元素添加 `lang="zh-CN"` 属性
- 添加 `<meta charset="UTF-8" />` 元素
- 添加 `<meta name="viewport" content="width=device-width, initial-scale=1.0" />` 元素
- 在 `title` 元素中填写活动名称及简短的主题说明

使用 UTF-8 编码保存 `index.html`

## 页面内容

在页面开头放置一个一级标题，以活动名称作为标题内容，并设置标识符 `top`

在标题下添加一个段落，说明活动主题和举办城市

创建五个 `a` 元素，用于跳转到同一页面的各个部分

- `活动介绍`，地址为 `#about`
- `主题方向`，地址为 `#directions`
- `活动日程`，地址为 `#program`
- `参与须知`，地址为 `#participants`
- `举办地点`，地址为 `#location`

在这些链接之后添加一个地址为 `#program` 的 `a` 元素

在该链接内放置一个 `img` 元素，设置 `src="assets/poster.jpg"`、`width="720"`，并按 `查看[活动名称]的活动日程` 的格式填写 `alt` 文本，将占位内容替换为自己的活动名称

## 活动介绍

创建二级标题 `活动介绍`，并设置标识符 `about`

添加三个独立段落，每段一到两句话

1. 活动围绕什么主题、面向哪些人 - 将活动名称放入 `strong` 元素
2. 访客可以参加哪些项目 - 将一个需要强调的片段放入 `em` 元素
3. 访客可以看到或体验什么

## 主题方向

创建二级标题 `主题方向`，并设置标识符 `directions`

在标题下使用 `ul` 和 `li` 元素创建一个包含六项的无序列表

根据活动主题为各个方向命名，每个名称不超过六个词

## 活动日程

创建二级标题 `活动日程`，并设置标识符 `program`

在标题下使用 `ol` 和 `li` 元素创建一个包含六项的有序列表

构思符合主题的活动项目，并在所选举办时段内按时间顺序排列

每一项使用 `10:00 - 活动项目名称` 的格式

## 参与须知

创建二级标题 `参与须知`，并设置标识符 `participants`

添加以下段落

```text
参加活动需要提前报名
```

将 `提前报名` 放入 `strong` 元素

添加三级标题 `需要携带的物品`，并在标题下创建一个包含六项的无序列表

前三项已给出

- 笔记本和笔
- 手机和充电器
- 报名确认凭证

根据自己活动中的项目构思其余三项

添加三级标题 `参与流程`，并在标题下创建一个包含五项的有序列表

前三项已给出

1. 从日程中选择一个活动项目
2. 在活动网站上报名
3. 提前 15 分钟到场

自行添加另外两个步骤，保持流程顺序合理

## 举办地点

创建二级标题 `举办地点`，并设置标识符 `location`

在一个独立的 `p` 元素中填写所选场地的名称

在一个 `p` 元素中填写地址，并在街道及门牌号与城市之间插入 `br` 元素

在地址下添加一个独立的 `p` 元素，填写所选举办日期和时间

再添加一个段落，用一句话说明附近的地标或到达场地的方式

添加一个 `a` 元素，链接到与活动主题相关的现有网站或所选场地的网站，使用含义清楚的链接文本，并设置 `target="_blank"` 和 `rel="noopener"` 属性

添加一个 `hr` 元素，然后添加一个文本为 `返回顶部`、地址为 `#top` 的 `a` 元素

## 检查

使用任意本地 Web 服务器，通过该服务器的地址和端口在浏览器中打开页面

页面和图片应通过 HTTP 打开，`/` 和 `/assets/poster.jpg` 请求不应返回 `404` 状态码

检查页面开头的五个链接以及 `返回顶部` 链接能否正确跳转

点击图片时，页面应跳转到 `活动日程` 部分
