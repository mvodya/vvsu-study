# Лабораторная работа 4: Первые стили CSS

## Задание

Создать сайт музыкального релиза из трех страниц: об альбоме, треки и об исполнителе

Выберите альбом реального или вымышленного исполнителя; названия, тексты и треки можно взять из примера ниже, заменить своими или дополнить с сохранением требований

Пример: вымышленный исполнитель `Тихий город`, альбом `После полуночи`, жанр `Электроника`, дата выхода `15 октября 2026`

## Проект

Создайте новый проект

```text
lab4-css/
|-- index.html
|-- tracks.html
|-- artist.html
`-- assets/
    `-- cover.jpg
```

На каждой странице разместите название исполнителя, заголовок текущей страницы и ссылки `Об альбоме`, `Треки`, `Об исполнителе` на соответствующие файлы

Для `cover.jpg` выберите обложку альбома или собственное изображение для вымышленного релиза

Используйте только атрибут `style` и элемент `<style>` внутри `head`; отдельные CSS-файлы, JavaScript и CSS-библиотеки не нужны

Располагайте содержимое обычным потоком сверху вниз, без Flexbox, Grid, `float`, `position` и колонок

## Об альбоме: атрибут style

В `index.html` укажите название альбома в `h1`, затем добавьте три отдельных абзаца: исполнитель, жанр и дата выхода

```text
Исполнитель: Тихий город
Жанр: Электроника
Дата выхода: 15 октября 2026
```

Сначала оформите каждый абзац через его атрибут `style`

1. Первый: цвет текста `#1e40af`, размер шрифта `24px`, жирное начертание
2. Второй: цвет `#166534`, размер `18px`, курсив
3. Третий: цвет `#991b1b`, фон `#fee2e2`, внутренние отступы `12px`

В атрибуте перечисляют пары `свойство: значение`, разделяя их точкой с запятой, например

```html
<p style="color: #1e40af; font-size: 24px;">Исполнитель: Тихий город</p>
```

Для жирного начертания используйте `font-weight: bold`, для курсива - `font-style: italic`

## Об альбоме: элемент style

В `head` страницы `index.html` добавьте

```html
<style>
  body {
    font-family: Arial, sans-serif;
    color: #1f2937;
    background-color: #ffffff;
  }

  .release-info {
    font-size: 18px;
  }
</style>
```

Здесь `body` выбирает элемент по имени тега, а `.release-info` - все элементы с `class="release-info"`

1. Добавьте класс `release-info` всем трем абзацам
2. Перенесите размер, цвет и начертание второго абзаца из атрибута в правило `.release-info`, удалите у него пустой атрибут `style`
3. После этого правила добавьте еще одно правило `.release-info`, задающее только `color: #374151`; остальные свойства оставьте в первом правиле
4. Первый и третий абзацы должны сохранить собственные цвета из атрибутов, а второй - получить цвет из последнего правила
5. Добавьте четвертый абзац с кратким описанием альбома и классом `release-info`, без атрибута `style`, например `Музыка для вечерних прогулок по городу`
6. Для `h1` задайте через селектор тега размер `32px`, выравнивание по центру через `text-align` и межбуквенный интервал `1px` через `letter-spacing`

После описания добавьте обложку из `assets` с классом `cover`; в `<style>` задайте ей `width: 100%`, `max-width: 320px`, `height: auto` и скругление `8px` через `border-radius`

Шрифт из `body` применяется к вложенному тексту по наследованию; правило класса можно использовать для нескольких элементов, а атрибут `style` относится к одному элементу

## Треки: классы, размеры и отступы

В `tracks.html` создайте минимум три карточки `article`, каждая с названием трека в `h2`, длительностью, описанием и отдельным абзацем с настроением

| Трек              | Длительность | Описание                                | Настроение |
| ----------------- | ------------ | --------------------------------------- | ---------- |
| Последний трамвай | 03:42        | Мягкий ритм и звуки ночного города      | Спокойное  |
| Неон              | 04:08        | Быстрый бит и яркая мелодия синтезатора | Энергичное |
| До рассвета       | 05:16        | Медленное завершение ночной прогулки    | Задумчивое |

Для этой страницы все правила запишите в собственном `<style>`; стили из `index.html` автоматически сюда не переносятся

1. Для `body` установите `font-family: Arial, sans-serif` и `color: #1f2937`
2. Всем карточкам назначьте класс `track` и оформите его одним правилом: фон `#f3f4f6`, граница `2px solid #475569`, скругление `12px`, внутренние отступы `16px`, нижний внешний отступ `24px`
3. Этому же классу задайте `width: 100%`, `max-width: 480px` и `box-sizing: border-box`, чтобы граница и внутренние отступы входили в заданную ширину
4. Через селектор `.track h2` установите заголовкам размер `22px` и верхний внешний отступ `0`
5. Абзацам описания назначьте класс `description`, задайте ему `font-size: 16px` и `line-height: 1.6`
6. Одной карточке добавьте второй класс `featured`, сохранив `track`; правилом `.featured`, расположенным после `.track`, измените только фон на `#fef3c7` и цвет границы на `#92400e`
7. Абзацам с настроением назначьте класс `mood` с жирным начертанием, а одному из них дополнительно класс `accent` с цветом `#991b1b`
8. Длительность каждого трека разместите в абзаце с классом `duration`; задайте ему `font-family: monospace`, `font-size: 16px` и `color: #475569`

Несколько классов записываются через пробел: `class="track featured"`

`padding` задает внутренние отступы, `margin-bottom` и `margin-top` - внешние, `border` - границу, `border-radius` - скругление; название настроения должно оставаться понятным и без цвета

## Об исполнителе: текст, списки и ссылки

В `artist.html` разместите краткую биографию исполнителя, список музыкальных влияний и отдельный абзац о записи альбома

Биография

```text
Тихий город - электронный проект из Владивостока. Его музыка соединяет записи городских звуков и мелодии синтезаторов
```

Музыкальные влияния

- Эмбиент
- Синт-поп
- Звуки ночного города

О записи

```text
Звуки улиц для альбома записаны во время ночных прогулок
```

Все стили этой страницы разместите в ее `<style>`

1. Для `body` задайте `font-family: Georgia, serif` и `color: #1f2937`
2. Биографии назначьте класс `intro`: размер `20px`, межстрочный интервал `1.5`, выравнивание по левому краю
3. Списку назначьте класс `influences`: квадратные маркеры через `list-style-type: square` и левый внутренний отступ `24px`
4. Через селектор `.influences li` задайте нижний внешний отступ пунктов `10px`
5. Абзацу о записи задайте `id="recording"`; в правиле `#recording` установите фон `#fff7ed`, левую границу `4px solid #9a3412` и внутренние отступы `12px`
6. Для всех ссылок страницы задайте цвет `#1e40af` и подчеркивание через `text-decoration: underline`
7. В правиле `a:hover` измените цвет на `#7c2d12`, а фон - на `#fff7ed`
8. В правиле `a:focus` задайте `outline: 2px solid #1e40af` и `outline-offset: 3px`; не убирайте обводку фокуса

`:hover` применяется при наведении мыши, `:focus` - когда ссылка получает фокус, например после нажатия `Tab`
