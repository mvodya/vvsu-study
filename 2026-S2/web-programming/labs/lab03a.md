# Лабораторная работа 03a: Структура многостраничного HTML-сайта

## Задание

Создать сайт вымышленного кафе из трех страниц: главная, каталог и информация для посетителей

Выберите концепцию кафе из примеров или предложите свою

| Концепция           | Что представить в каталоге             |
| ------------------- | -------------------------------------- |
| Обычное кафе        | Блюда и напитки из меню                |
| Котокафе            | Коты, с которыми можно познакомиться   |
| Кафе настольных игр | Игры для посетителей                   |
| Книжное кафе        | Книги, которые можно почитать на месте |

Придумайте название кафе, город и адрес

Далее данные приведены на примере котокафе: тексты, карточки, занятия, правила, контакты, время работы и цены можно использовать, заменять или дополнять под выбранную концепцию

Сохраните назначение трех страниц, структуру разделов, HTML-элементы и переходы между ними; названия разделов, подписи и содержание адаптируйте к своему кафе и согласуйте на всех страницах

Работа рассчитана на одну пару

## Структура проекта

Создайте новый проект `lab03a-cafe` по следующей схеме; файлы котов показаны для примера

```text
lab03a-cafe/
|-- index.html
|-- pages/
|   |-- catalog.html
|   `-- visit.html
`-- assets/
    |-- cafe.jpg
    |-- misty.jpg
    |-- pixel.jpg
    `-- luna.jpg
```

Подберите изображение интерьера для `cafe.jpg` и отдельное изображение для каждой карточки каталога

Все изображения храните в `assets`; файлы для своих карточек назовите самостоятельно и добавьте в эту папку, а неиспользуемые файлы из примера создавать не нужно

Все страницы выполняются на HTML без оформления CSS и без JavaScript

## Общая структура страниц

Каждый файл должен быть отдельным HTML-документом со своим `title` по шаблону `Название страницы - название кафе`

Внутри `body` расположите элементы в следующем порядке

1. Ссылка `К содержимому` на `#content`
2. `header` с названием кафе в абзаце и основной навигацией в `nav`
3. Один `main` с идентификатором `content` и содержимым текущей страницы
4. `footer` с текстом `Учебный сайт вымышленного кафе` и вашими именем и группой

В начале `main` разместите `h1` с названием страницы; для котокафе это `Котокафе [название]`, `Наши коты` и `Планирование визита`

В `nav` используйте список из трех пунктов в одном порядке: `Главная`, название каталога по вашей теме и `Визит`; для котокафе каталог называется `Наши коты`, для обычного кафе - `Меню`

Название текущей страницы оставьте обычным текстом, остальные пункты сделайте ссылками на соответствующие файлы

Шапка, порядок пунктов навигации и подвал должны быть согласованы на всех страницах, а пути в ссылках должны учитывать расположение текущего файла

## Главная страница

В `index.html` после основного заголовка добавьте вводный абзац, например

```text
Место для спокойного отдыха, настольных игр и знакомства с котами
```

Создайте два раздела `section` с заголовками `h2`

В разделе `О кафе` разместите описание, например

```text
У нас живут коты с разными характерами. Можно почитать книгу, поработать над эскизами или просто провести время рядом с ними
```

Добавьте фотографию интерьера в элементе `figure`, а под изображением внутри того же элемента - `figcaption` с подписью к интерьеру, например `Общая гостиная котокафе`

В разделе `Чем заняться` разместите список минимум из трех занятий, например

- Познакомиться с котами
- Поиграть в настольные игры
- Порисовать в тихой зоне

После списка добавьте две ссылки: на страницу `catalog.html` с подходящей подписью, например `Познакомиться с котами`, и `Правила посещения` на раздел `rules` страницы `visit.html`

## Страница каталога

В `pages/catalog.html` после основного заголовка добавьте абзац, например

```text
У каждого кота есть любимые занятия. Знакомьтесь постепенно и дайте ему самому подойти к вам
```

Представьте минимум шесть объектов по выбранной теме: котов, блюд, игр или книг

Для котокафе можно взять трех котов из примера и добавить еще минимум трех своих или составить собственный список целиком

Для каждой карточки создайте отдельный `article` внутри `main`

Пример данных

| Имя     | Файл фотографии | Возраст | Характер                   | Любимое занятие        |
| ------- | --------------- | ------- | -------------------------- | ---------------------- |
| Мисти   | `misty.jpg`     | 4 года  | Спокойный и наблюдательный | Отдыхать у окна        |
| Пиксель | `pixel.jpg`     | 2 года  | Любопытный и общительный   | Играть с удочкой       |
| Луна    | `luna.jpg`      | 3 года  | Осторожная и ласковая      | Сидеть рядом с гостями |

Это исходные данные для карточек, размещать HTML-таблицу на странице не нужно

В каждом `article` разместите имя или название в `h2`, изображение и три характеристики через `dl`, `dt` и `dd`

Для котов используйте `Возраст`, `Характер`, `Любимое занятие`; для блюд - `Состав`, `Масса или объем`, `Цена`; для игр - `Число игроков`, `Возраст игроков`, `Длительность партии`; для книг - `Автор`, `Жанр`, `Год издания`

Под характеристиками добавьте одно собственное предложение с рекомендацией посетителю: как познакомиться с котом, к чему заказать блюдо или кому подойдет игра либо книга

После всех карточек разместите ссылку `Спланировать визит` на страницу `visit.html`

## Страница визита

В `pages/visit.html` создайте три раздела `section` с заголовками `h2`

В разделе `Как нас найти` разместите придуманные город и адрес обычным абзацем, затем еще одним абзацем укажите ориентир или ближайшую остановку

Контакт для связи с кафе поместите в `address`: ссылка с текстом `Написать в кафе` и адресом вида `mailto:hello@example.com`

В разделе `Время и стоимость` разместите три отдельных абзаца: часы работы, условия оплаты и доступные посетителю услуги

Для обычного кафе можно указать оплату по меню и доступность Wi-Fi, для котокафе - почасовую оплату, например

```text
Ежедневно с 11:00 до 20:00
Первый час - 400 рублей, каждый следующий - 200 рублей
Чай и настольные игры включены в стоимость
```

Разделу `Правила посещения` задайте идентификатор `rules` и добавьте список минимум из четырех правил, например

- Не будите спящих котов
- Не берите котов на руки без разрешения сотрудника
- Не кормите котов своей едой
- Фотографируйте без вспышки

После списка добавьте совет посетителям отдельным абзацем, например

```text
Если кот отошел, дайте ему отдохнуть и выберите другое занятие
```

## Проверка сайта

Откройте проект через любой локальный веб-сервер

Пройдите маршрут `Главная -> Каталог -> Визит -> Главная` по пунктам своего меню, затем откройте каждую внутреннюю страницу напрямую по ее адресу и обновите ее

С главной страницы перейдите по ссылке `Правила посещения`: должна открыться страница визита с нужным разделом, а адрес должен оканчиваться на `pages/visit.html#rules`

На каждой странице с помощью `Tab` выберите ссылку `К содержимому` и нажмите `Enter`, затем продолжите переходить по ссылкам с клавиатуры

Во вкладке `Elements` инструментов разработчика найдите общие области страницы и убедитесь, что карточки каталога расположены внутри `main`, а подвал - после него
