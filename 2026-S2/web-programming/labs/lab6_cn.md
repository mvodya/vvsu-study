# 实验作业 6：使用 Flexbox 和 Grid 制作游戏页面

## 作业内容

为一款真实存在的电脑或主机游戏制作一个在线商店页面

本作业安排两次课：第一次课准备素材、页眉和图片展示区，第二次课完成购买区域、游戏介绍和评价

请参考[理论 05：Flexbox](../05-css-layout_cn.md#flexbox) 和 [Grid](../05-css-layout_cn.md#grid)

## 游戏与素材

选择一款游戏，例如 `Hollow Knight`、`Stardew Valley`、`Half Life 2`、`Tetris`、`Animal Crossing`、`Hades` 等，从官方网站或商店页面获取名称、图片和基本信息

商店可以是真实存在的，也可以由你虚构；选择商店名称和两到三种主要配色

准备五张不同的游戏画面截图，以及一张独立的游戏宣传图或标志图片，将它们保存在本地

价格、评分和评价文字可以使用教学示例数据；如果使用示例数据，请在对应位置注明，并在页脚提供信息和图片的来源链接

## 项目

```text
lab6-game/
|-- index.html
|-- css/
|   `-- styles.css
`-- assets/
    |-- cover.jpg
    |-- screen-1.jpg
    |-- screen-2.jpg
    |-- screen-3.jpg
    |-- screen-4.jpg
    |-- screen-5.jpg
    `-- icons/
```

使用外部 CSS，将全部内容放在 `index.html` 中

这是一个使用 HTML 和 CSS 制作的静态页面：无需实现截图切换、购买、加入收藏或提交评价，不使用 JavaScript 和 CSS 库

检查时的浏览器窗口宽度为 `1280px` 或更大，主要容器宽度为 `1120px`，水平居中；本作业不要求响应式布局和媒体查询

## 页面内容

1. 在页眉放置商店名称或标志，以及 `游戏介绍`、`截图`、`评价`、`购买` 导航链接，通过 `id` 跳转到本页相应区域
2. 在页眉下方使用 `h1` 显示游戏名称，并添加至少三个游戏类型或主题标签
3. 主要区域左侧放置图片展示区，右侧放置游戏信息：独立的宣传图或标志、简短介绍、开发商、发行日期、平台和支持的语言
4. 图片展示区包含一张大截图，以及下方的四张小截图；为每张图片设置有意义的 `alt`，通过 `aspect-ratio` 和 `object-fit` 保持比例
5. 在右栏显示评分：注明评分范围的数值评分或好评百分比、文字评价以及评分人数
6. 添加购买区域，包含版本名称、价格与货币，以及 `购买` 和 `加入收藏` 按钮；使用 `button type="button"`，在旁边注明 `教学示例：按钮无实际功能`
7. 两个按钮都包含图标和文字，可以使用本地 SVG/PNG 或内嵌 SVG；通过 `alt=""` 或 `aria-hidden="true"` 向辅助技术隐藏装饰性图标
8. 在主要区域下方放置两段游戏介绍，以及列出至少四项玩法特点的列表
9. 添加至少三张评价卡片，每张包含作者姓名或昵称、注明评分范围的评分、游戏时长，以及两到三句话的评价
10. 在页脚注明页面作者并提供来源链接

## 使用 CSS 布局

使用有意义的类名，并按以下方式排列元素

| 区域 | 工具 | 检查要求 |
| --- | --- | --- |
| 页眉 | Flexbox | 标志和导航位于同一行，使用 `align-items: center` 和 `justify-content: space-between` |
| 导航和标签 | Flexbox | 通过 `gap` 设置间距，标签使用 `flex-wrap: wrap` 允许换行 |
| 图片展示区和游戏信息 | Grid | 两列分别为 `minmax(0, 2fr)` 和 `minmax(0, 1fr)`，间距为 `24px`，两列内容顶部对齐 |
| 五张截图 | Grid | 通过 `repeat(4, minmax(0, 1fr))` 创建四个等宽列，大图通过 `grid-column: 1 / -1` 占据全部列，间距为 `8px` |
| 价格和购买按钮 | Flexbox | 位于同一行，垂直居中，并分配剩余空间 |
| 按钮内容 | Flexbox 或 inline-flex | 图标和文字居中对齐，通过 `gap` 设置间距 |
| 评价卡片 | Grid 和 Flexbox | Grid 创建三个等宽列；卡片内部使用 Flexbox 和 `flex-direction: column`，评分行通过 `margin-top: auto` 靠近卡片底部 |

为所有元素设置 `box-sizing: border-box`，为信息区域和卡片设置内边距，并统一边框和圆角样式

为按钮和链接设置 `:hover` 和 `:focus-visible` 样式，确保文字和图标在背景上清晰可辨

通过指定的 Flexbox 和 Grid 容器排列主要区域；小型装饰部件可以使用绝对定位

## 检查与答辩

通过本地服务器检查页面：六张图片全部成功加载，页眉链接能跳转到对应区域，在指定窗口宽度下内容能够容纳在容器内

在开发者工具的 `Elements` 面板中开启 Grid 和 Flexbox 布局高亮，展示列边界、间距和容器

答辩时，教师可能要求修改列宽比例、评价区域的列数、元素间距或页眉对齐方式；请修改 CSS 并展示效果
