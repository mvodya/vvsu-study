# 实验 7：拉面店菜单的响应式布局

## 任务

制作一个菜单页面，顾客可以在店内用手机查看，也可以在到店前用电脑浏览

本实验以符拉迪沃斯托克的一家虚构拉面店“雾”（Туман）为例。你也可以选择其他城市的店铺、游戏或动漫中的拉面店，或者自己设计一家店。店名、菜品、价格和货币均可修改

本实验安排两次课，每次为一个双课时

请参考[理论 06：CSS 响应式布局](../06-responsive-css_cn.md)

## 第一次课 - 手机端菜单

1. 创建项目，包含文件 `index.html`、`css/styles.css` 和存放图片的 `images/` 文件夹。在 `head` 中引入样式表，并使用 `<meta name="viewport" content="width=device-width, initial-scale=1">` 设置视口
2. 在页眉中写出拉面店的名称和所在地。添加指向页面内三个区域的链接：“招牌菜”“拉面”和“加料”
3. 在“招牌菜”区域放置一张大照片或插画，并写出菜名、简短介绍和价格。例如，售价 690 ₽ 的“海湾上的雾”拉面可以使用介绍：“味噌汤底，配蟹肉、玉米和葱花”
4. 在“拉面”区域制作三张卡片，每张都包含名称、配料和价格。可以使用下表提供的内容
5. 在“加料”区域制作至少三行。例如：卤蛋 - 80 ₽、海苔 - 50 ₽、加面 - 100 ₽

| 拉面           | 配料                             |  价格 |
| -------------- | -------------------------------- | ----: |
| 鸡肉酱油拉面   | 鸡汤、酱油、面条、鸡肉和葱花     | 490 ₽ |
| 猪肉辣味噌拉面 | 味噌汤、面条、猪肉、辣椒酱和芝麻 | 570 ₽ |
| 香菇拉面       | 蔬菜汤、面条、香菇、菠菜和海苔   | 510 ₽ |

编写适合窄屏的基础样式。各区域和卡片采用单列布局，招牌菜区域中图片位于介绍文字之前。图片宽度应受容器宽度限制，并保持其比例

在每行加料中，将可用空间留给名称，价格靠右对齐。较长的名称可以占两行，金额和货币符号应保持在同一行

## 第二次课 - 调整菜单布局

所有屏幕尺寸使用同一份 HTML 结构。在样式文件末尾添加两个使用 `min-width` 的媒体查询。每个查询中的规则从指定窗口宽度开始生效

| 窗口宽度         | 菜单布局的变化                                                                   |
| ---------------- | -------------------------------------------------------------------------------- |
| 从 `640px` 开始  | 拉面卡片排列为两列等宽布局，第三张卡片换到下一行。招牌菜的图片与介绍文字并排显示 |
| 从 `1024px` 开始 | 三张卡片排列在同一行。店名和导航分别位于页眉的两端。主容器设置最大宽度并水平居中 |

使用 CSS Grid 实现分列布局，可以使用 Flexbox 对齐导航和带价格的行。页眉中的链接应支持换行。为手机端设置合适的间距，并在宽屏上增大间距

## 检查与答辩

- 通过本地服务器打开页面，在浏览器开发者工具中启用设备模式。分别在 `360px`、`768px` 和 `1280px` 宽度下检查菜单，再连续调整这些宽度之间的窗口尺寸。出现横向滚动、文字被裁切或元素重叠，说明布局存在问题
- 将窗口宽度设为 `1280px`，把页面缩放比例提高到 `200%`：所有价格都应保持可见，链接仍应跳转到对应区域
- 答辩时，教师可能要求修改切换为三列布局的宽度，或将某项加料替换为较长的名称。请展示修改后的页面效果
