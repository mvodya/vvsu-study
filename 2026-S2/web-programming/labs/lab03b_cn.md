# 实验作业 03b：课程表

## 作业内容

创建一个网站，包含连续三周的课程表以及三门课程的介绍

本作业安排为一次课（两个课时），只使用 HTML，不使用 CSS 或 JavaScript

## 原始数据

使用自己班级的课程表，或者编写一个教学示例，并确定班级和第一周星期一的日期

示例使用班级 `АМПО-25-1`；这是教学用课程表，不是该班级的实际课程表

课程和教室可以参考 [ВВГУ 教师课程表](https://portfolio.vvsu.ru/timetable/tid/14280/)，例如 `面向对象程序设计`、`Web 编程`、`大数据分析导论`，教室可以使用 `1403`、`1410`、`1412`、`1415`、`1524`

教学示例使用该课程表中的上课时段：`08:30 - 10:00`、`10:10 - 11:40`、`11:50 - 13:20`、`13:30 - 15:00`；每次课时长为 90 分钟

不需要复制教师课程表中的班级名称：网站中的所有课程都属于同一个选定的班级

每次课都要注明课程名称、教室、开始和结束时间，以及教师的姓、名和父称

每周都应安排课程，三周内至少有一天没有课；同一天的上课时间不能重叠

如果实际课程表中星期一至星期六每天都有课，请改用教学示例，并安排一天不上课

从课程表中选择三门不同的课程，为它们分别创建介绍页面

## 项目结构

创建新项目 `lab03b-schedule`

```text
lab03b-schedule/
|-- index.html
|-- week2.html
|-- week3.html
`-- subjects/
    |-- subject1.html
    |-- subject2.html
    `-- subject3.html
```

`index.html`、`week2.html` 和 `week3.html` 分别用于第一周、第二周和第三周

`subjects` 中的文件用于介绍三门选定的课程

## 共同结构

为每个 HTML 文档设置独立的 `title`：课程表页面包含班级和周次，课程介绍页面使用课程名称

在 `body` 内放置 `header`、一个包含主要内容的 `main`，以及包含你的姓名和班级的 `footer`；`header` 中的网站名称为 `[班级]课程表`

每周课程表的 `main` 以注明周次的 `h1` 开头；课程介绍页面的主标题放在 `article` 内，具体要求见下文

## 课程表页面

在主标题下注明星期一至星期六的日期范围；下一周的开始日期比上一周晚七天

每个页面放置六个表格，按星期一至星期六排列，包括没有课的日子；不包含星期日

每个表格使用以下结构

- `caption`，注明星期几和日期
- `thead`，包含一行表头：`时间`、`课程`、`教室`、`教师`
- 每个列标题使用带有 `scope="col"` 属性的 `th`
- `tbody`，包含课程数据：每次课占一行 `tr`，每行包含四个 `td` 单元格

按上课时间排列课程，例如

| 时间          | 课程             | 教室 | 教师                      |
| ------------- | ---------------- | ---- | ------------------------- |
| 08:30 - 10:00 | 面向对象程序设计 | 1410 | Водяницкий Марк Вадимович |
| 10:10 - 11:40 | Web 编程         | 1524 | Водяницкий Марк Вадимович |

没有课的日期仍需保留表头，并在 `tbody` 中添加一行：使用 `colspan` 将四列合并为一个单元格，填写 `当天无课`

三门选定课程在课程表中每次出现时，都要设为指向 `subjects` 文件夹内对应介绍页面的链接；其他课程名称保留为普通文本

## 各周之间的跳转

在课程表之后添加 `nav`，放置指向相邻周的链接

| 页面         | 上一页       | 下一页       |
| ------------ | ------------ | ------------ |
| `index.html` | 无链接       | `week2.html` |
| `week2.html` | `index.html` | `week3.html` |
| `week3.html` | `week2.html` | 无链接       |

链接文本使用 `上一页` 和 `下一页`；第一页不添加上一页链接，最后一页不添加下一页链接

## 课程介绍页面

在每个课程介绍页面的 `main` 内放置一个 `article`，其中包含以课程名称为内容的主标题，以及以下带有 `h2` 标题的 `section`

- `课程介绍` - 用一个包含两到三句话的段落说明学习内容
- `主题` - 列出至少三个学习主题
- `上课信息` - 使用 `dl`、`dt` 和 `dd` 组成的属性列表，说明教师、授课形式以及需要携带的物品

教师信息必须与课程表一致；如果有多位教师，请全部列出

在介绍之后添加一个 `nav`，包含三个链接：`第一周`、`第二周`、`第三周`

从 `subjects` 文件夹返回课程表时，使用包含 `../` 的相对路径

## 检查

通过任意本地 Web 服务器打开项目

按顺序访问所有周次并返回，打开每门选定课程的介绍页面，再返回所需周次

通过地址直接打开课程介绍页面，确认无需使用浏览器历史记录也能返回课程表

在开发者工具的 `Elements` 标签页中检查行和单元格的嵌套关系，并检查无课日的提示行：它应占据表格的全部宽度
