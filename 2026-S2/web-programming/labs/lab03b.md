# Лабораторная работа 03b: Расписание занятий

## Задание

Создать сайт с расписанием занятий на три последовательные недели и описаниями трех предметов

Работа рассчитана на одну пару и выполняется на HTML без CSS и JavaScript

## Исходные данные

Используйте расписание своей группы или придумайте учебный пример, выбрав группу и дату понедельника первой недели

В примерах используется группа `АМПО-25-1`; это учебное расписание, а не фактическое расписание группы

Предметы и аудитории можно взять из [расписания преподавателя ВВГУ](https://portfolio.vvsu.ru/timetable/tid/14280/): например, `Объектно-ориентированное программирование`, `Веб-программирование`, `Введение в анализ больших данных`, аудитории `1403`, `1410`, `1412`, `1415`, `1524`

Для учебного примера используйте интервалы пар из этого расписания: `08:30 - 10:00`, `10:10 - 11:40`, `11:50 - 13:20`, `13:30 - 15:00`; продолжительность каждой пары - 90 минут

Названия групп из расписания преподавателя переносить не нужно: все занятия на сайте относятся к одной выбранной группе

Для каждой пары укажите название предмета, аудиторию, время начала и окончания, фамилию, имя и отчество преподавателя

На каждой неделе должны быть занятия, а хотя бы один из дней за три недели должен быть без пар; время занятий в пределах дня не должно пересекаться

Если в реальном расписании нет свободных дней с понедельника по субботу, используйте учебный пример и освободите один день

Выберите три разных предмета из расписания для отдельных страниц с описаниями

## Структура проекта

Создайте новый проект `lab03b-schedule`

```text
lab03b-schedule/
|-- index.html
|-- week2.html
|-- week3.html
`-- subjects/
    |-- subject1.html
    |-- subject2.html
    `-- subject3.html
```

Файлы `index.html`, `week2.html` и `week3.html` предназначены для первой, второй и третьей недели соответственно

Файлы в `subjects` предназначены для трех выбранных предметов

## Общая структура

Каждому HTML-документу задайте отдельный `title`: для расписания укажите группу и номер недели, для описания - название предмета

Внутри `body` разместите `header` с названием сайта `Расписание группы [группа]`, один `main` с основным содержимым и `footer` с вашим именем и группой

На страницах недель начните `main` с `h1`, указав номер недели; на страницах предметов основной заголовок разместите внутри `article`, как описано ниже

## Страницы расписания

Под основным заголовком укажите диапазон дат с понедельника по субботу; каждая следующая неделя начинается через семь дней после предыдущей

На каждой странице разместите шесть таблиц в порядке дней с понедельника по субботу, включая дни без занятий; воскресенье не включайте

Для каждой таблицы используйте

- `caption` с днем недели и датой
- `thead` со строкой заголовков `Время`, `Предмет`, `Аудитория`, `Преподаватель`
- `th` с атрибутом `scope="col"` для каждого заголовка столбца
- `tbody` с данными: одна строка `tr` на пару, четыре ячейки `td` в строке

Расположите занятия по времени, например

| Время | Предмет | Аудитория | Преподаватель |
| --- | --- | --- | --- |
| 08:30 - 10:00 | Объектно-ориентированное программирование | 1410 | Водяницкий Марк Вадимович |
| 10:10 - 11:40 | Веб-программирование | 1524 | Водяницкий Марк Вадимович |

В таблице дня без занятий сохраните заголовки столбцов, а в `tbody` добавьте одну строку с текстом `Пар нет` в ячейке, объединяющей четыре столбца через `colspan`

Все появления трех выбранных предметов в расписании сделайте ссылками на соответствующие страницы в папке `subjects`; названия остальных предметов оставьте обычным текстом

## Переходы между неделями

После расписания разместите `nav` со ссылками на соседние недели

| Страница     | Назад        | Далее        |
| ------------ | ------------ | ------------ |
| `index.html` | Нет ссылки   | `week2.html` |
| `week2.html` | `index.html` | `week3.html` |
| `week3.html` | `week2.html` | Нет ссылки   |

Используйте тексты ссылок `Назад` и `Далее`; отсутствующую ссылку на первой и последней страницах просто не добавляйте

## Страницы предметов

Внутри `main` каждой страницы предмета разместите один `article`, включающий основной заголовок с названием предмета и следующие разделы `section` с заголовками `h2`

- `О предмете` - один абзац из двух-трех предложений о том, что изучают на занятиях
- `Темы` - список минимум из трех тем
- `Занятия` - информация о преподавателе, формате занятий и том, что нужно взять с собой, в виде списка характеристик `dl`, `dt` и `dd`

Данные преподавателя должны соответствовать расписанию; если преподавателей несколько, перечислите их

После описания добавьте `nav` с тремя ссылками: `Неделя 1`, `Неделя 2`, `Неделя 3`

Для возврата из папки `subjects` используйте относительные пути с `../`

## Проверка

Откройте проект через любой локальный веб-сервер

Пройдите все недели вперед и обратно, откройте описание каждого выбранного предмета из расписания и вернитесь на нужную неделю

Откройте страницу предмета напрямую по адресу и проверьте возврат к расписанию без использования истории браузера

Во вкладке `Elements` инструментов разработчика проверьте вложенность строк и ячеек, а также строку дня без пар: она должна занимать всю ширину таблицы
