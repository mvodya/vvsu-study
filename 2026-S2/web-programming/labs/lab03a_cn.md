# 实验作业 03a：多页面 HTML 网站的结构

## 作业内容

为一家虚构的咖啡馆创建一个包含三个页面的网站：首页、展示目录和到店信息

从以下示例中选择咖啡馆类型，也可以提出自己的创意

| 类型       | 展示目录中的内容     |
| ---------- | -------------------- |
| 普通咖啡馆 | 菜单中的餐点和饮品   |
| 猫咖       | 可以与客人互动的猫咪 |
| 桌游咖啡馆 | 供客人游玩的桌游     |
| 书店咖啡馆 | 可以在店内阅读的书籍 |

构思咖啡馆的名称、所在城市和地址

以下数据以猫咖为例：文字、卡片、活动、规则、联系方式、营业时间和价格都可以根据所选主题使用、替换或补充

保留三个页面的用途、各部分的结构、HTML 元素及页面之间的跳转；根据自己的咖啡馆调整各部分的标题、说明和内容，并确保所有页面的信息一致

本作业安排为一次课（两个课时）

## 项目结构

按照以下结构创建新项目 `lab03a-cafe`；猫咪图片文件仅作为示例

```text
lab03a-cafe/
|-- index.html
|-- pages/
|   |-- catalog.html
|   `-- visit.html
`-- assets/
    |-- cafe.jpg
    |-- misty.jpg
    |-- pixel.jpg
    `-- luna.jpg
```

为 `cafe.jpg` 选择一张室内图片，并为展示目录中的每张卡片选择单独的图片

所有图片都保存在 `assets` 中；自行命名自己卡片的图片文件并放入该文件夹，无需创建示例中未使用的文件

所有页面只使用 HTML，不使用 CSS 样式或 JavaScript

## 页面的共同结构

每个文件都必须是独立的 HTML 文档，并按 `页面名称 - 咖啡馆名称` 的格式设置各自的 `title`

在 `body` 内按以下顺序放置元素

1. 文本为 `跳转到正文`、地址为 `#content` 的链接
2. `header`，其中用一个段落显示咖啡馆名称，并将主要导航放入 `nav`
3. 一个标识符为 `content` 的 `main`，包含当前页面的主要内容
4. `footer`，包含文字 `虚构咖啡馆教学网站` 以及你的姓名和班级

在 `main` 开头使用 `h1` 显示页面名称；猫咖的三个页面标题分别为 `猫咖[名称]`、`我们的猫咪` 和 `到店指南`

在 `nav` 中使用包含三项的列表，并保持相同顺序：`首页`、符合主题的展示目录名称、`到店`；猫咖的目录称为 `我们的猫咪`，普通咖啡馆的目录称为 `菜单`

当前页面的名称保留为普通文本，其余项目设为指向相应文件的链接

所有页面的页头、导航项目顺序和页脚应保持一致，链接路径则需要根据当前文件的位置调整

## 首页

在 `index.html` 的主标题后添加一个介绍段落，例如

```text
一个可以安静休息、玩桌游和认识猫咪的地方
```

创建两个 `section`，各自使用 `h2` 标题

在 `关于咖啡馆` 部分添加介绍，例如

```text
这里住着性格各异的猫咪。你可以读书、画草图，或者只是陪伴它们度过一段时光
```

将室内照片放在 `figure` 元素中，并在同一元素内的图片下方添加 `figcaption`，填写室内场景的说明，例如 `猫咖公共休息区`

在 `可以做什么` 部分添加一个至少包含三项活动的列表，例如

- 认识猫咪
- 玩桌游
- 在安静区域画画

在列表后添加两个链接：一个指向 `catalog.html`，使用合适的链接文本，例如 `认识猫咪`；另一个文本为 `到店规则`，指向 `visit.html` 页面中标识符为 `rules` 的部分

## 展示目录页面

在 `pages/catalog.html` 的主标题后添加一个段落，例如

```text
每只猫咪都有自己喜欢的活动。请慢慢熟悉它，让它主动靠近你
```

根据所选主题展示至少六个对象：猫咪、餐点、桌游或书籍

如果选择猫咖，可以使用示例中的三只猫咪，再添加至少三只自己构思的猫咪，也可以完全使用自己的名单

在 `main` 内为每张卡片创建一个独立的 `article`

示例数据

| 名称     | 照片文件    | 年龄 | 性格           | 喜欢的活动   |
| -------- | ----------- | ---- | -------------- | ------------ |
| 米斯蒂   | `misty.jpg` | 4 岁 | 安静，善于观察 | 在窗边休息   |
| 皮克塞尔 | `pixel.jpg` | 2 岁 | 好奇，喜欢互动 | 玩逗猫棒     |
| 露娜     | `luna.jpg`  | 3 岁 | 谨慎，亲人     | 坐在客人身边 |

这些是卡片的原始数据，不需要在页面上制作 HTML 表格

在每个 `article` 中，用 `h2` 显示名字或名称，添加图片，并使用 `dl`、`dt` 和 `dd` 展示三个属性

猫咪使用 `年龄`、`性格`、`喜欢的活动`；餐点使用 `配料`、`重量或容量`、`价格`；桌游使用 `玩家人数`、`适合年龄`、`每局时长`；书籍使用 `作者`、`体裁`、`出版年份`

在属性下方自行写一句给客人的建议：如何与猫咪熟悉、餐点适合搭配什么，或者桌游和书籍适合哪些人

在所有卡片之后添加文本为 `安排到店`、指向 `visit.html` 的链接

## 到店信息页面

在 `pages/visit.html` 中创建三个 `section`，分别使用 `h2` 标题

在 `如何找到我们` 部分，用一个普通段落填写构思的城市和地址，再用一个段落说明附近的地标或最近的车站

将咖啡馆的联系方式放入 `address`：添加文本为 `给咖啡馆写邮件`、地址格式为 `mailto:hello@example.com` 的链接

在 `时间与费用` 部分添加三个独立段落：营业时间、收费方式和提供的服务

普通咖啡馆可以说明按菜单收费以及是否提供 Wi-Fi；猫咖可以按小时收费，例如

```text
每天 11:00 至 20:00
首小时 400 卢布，之后每小时 200 卢布
费用包含茶饮和桌游
```

为 `到店规则` 部分设置标识符 `rules`，并添加一个至少包含四条规则的列表，例如

- 不要叫醒熟睡的猫咪
- 未经工作人员允许，不要抱起猫咪
- 不要用自己的食物喂猫
- 拍照时不要使用闪光灯

在列表后用一个独立段落给客人一条建议，例如

```text
如果猫咪走开了，请让它休息，选择其他活动
```

## 检查网站

通过任意本地 Web 服务器打开项目

使用自己的菜单依次访问 `首页 -> 展示目录 -> 到店 -> 首页`，然后通过地址直接打开每个内部页面并刷新

从首页点击 `到店规则` 链接：应打开到店信息页面的对应部分，地址应以 `pages/visit.html#rules` 结尾

在每个页面上，使用 `Tab` 选中 `跳转到正文` 链接并按 `Enter`，然后继续使用键盘在链接之间移动

在开发者工具的 `Elements` 标签页中找到页面的共同区域，确认目录卡片位于 `main` 内部，页脚位于 `main` 之后
