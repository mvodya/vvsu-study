# Лабораторная работа 5: CSS-фигуры, бинго и расписание

## Задание

Работа рассчитана на две пары и состоит из трех частей: рисунок из HTML-элементов, тематическое бинго и оформление расписания

На первой паре выполните рисунок и начните бинго, на второй завершите бинго и оформите расписание

## Проект

Создайте папку `lab5-css` с такой структурой

```text
lab5-css/
|-- index.html
|-- bingo.html
|-- css/
|   `-- styles.css
|-- assets/
|   `-- изображения для бинго
`-- schedule/
    |-- index.html
    |-- week2.html
    |-- week3.html
    `-- subjects/
        |-- subject1.html
        |-- subject2.html
        `-- subject3.html
```

На страницах рисунка и бинго добавьте ссылки `Рисунок`, `Бинго`, `Расписание`; на страницах расписания добавьте ссылку возврата к рисунку, сохранив переходы между неделями и предметами

Все стили проекта разместите в одном `css/styles.css`, подключенном через `link` к каждому HTML-файлу; учитывайте глубину папок при указании пути

JavaScript, CSS-библиотеки, Flexbox, Grid и медиазапросы в этой работе не используются

## Часть 1. Рисунок из div

В `index.html` выберите один вариант; число деталей в таблице - минимум без учета общей сцены

| Вариант  | Обязательные детали                                                                    | Вложенность                                                                                                       |
| -------- | -------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Снеговик | Три снежных круга разного размера, два глаза, нос, две руки, три пуговицы - 11 деталей | Глаза и нос внутри верхнего круга, руки и пуговицы внутри среднего, все три круга внутри сцены                    |
| Смайлик  | Круг лица, два глаза, два зрачка, рот, две брови - 8 деталей                           | Глаза, рот и брови внутри лица, каждый зрачок внутри своего глаза                                                 |
| Домик    | Стена, крыша, дверь, ручка, два окна, две оконные перемычки - 8 деталей                | Стена и крыша внутри сцены; дверь и окна внутри стены, ручка внутри двери, по одной перемычке внутри каждого окна |
| Котик    | Туловище, голова, два уха, два глаза, нос, две лапы, хвост - 10 деталей                | Голова, лапы и хвост внутри туловища; уши, глаза и нос внутри головы                                              |

1. Каждую деталь создайте отдельным `div` с осмысленным классом; не заменяйте детали картинкой, символом, SVG или псевдоэлементом
2. Сделайте сцену размером `400px` на `400px` с `position: relative`; вложенные детали размещайте через `position: absolute` и координаты `top`, `left`, `right` или `bottom`
3. Задайте размеры деталей через `width` и `height`, используйте минимум три значения `background-color` и `border-radius` минимум у двух деталей; у треугольников допустимы нулевые размеры и цветная граница
4. Повторяющиеся детали оформите общим классом, а отличающиеся координаты - дополнительными классами, например `eye eye-left`
5. Координаты глаз должны отсчитываться от головы, ручки - от двери и аналогично для других вложенных деталей; все детали должны помещаться в сцене
6. Добавьте сцене `role="img"` и `aria-label` с коротким описанием рисунка

### Пример: человек

Это отдельный пример страницы, показывающий вложенность и координаты; для своей работы выполните один из четырех вариантов выше

Глаза находятся внутри головы, а руки и ноги - внутри туловища; `absolute` у головы и туловища также делает их опорой для вложенных деталей

```html
<!doctype html>
<html lang="ru">
  <head>
    <meta charset="utf-8" />
    <title>Человек из div</title>
    <style>
      .person {
        position: relative;
        width: 240px;
        height: 320px;
        background-color: #eef2ff;
      }
      .head {
        position: absolute;
        top: 20px;
        left: 80px;
        width: 80px;
        height: 80px;
        border-radius: 50%;
        background-color: #fbbf24;
      }
      .eye {
        position: absolute;
        top: 28px;
        width: 10px;
        height: 10px;
        border-radius: 50%;
        background-color: #1f2937;
      }
      .eye-left {
        left: 20px;
      }
      .eye-right {
        right: 20px;
      }
      .torso {
        position: absolute;
        top: 100px;
        left: 115px;
        width: 10px;
        height: 110px;
        background-color: #1f2937;
      }
      .arm,
      .leg {
        position: absolute;
        width: 10px;
        border-radius: 5px;
        background-color: #1f2937;
        transform-origin: top center;
      }
      .arm {
        top: 12px;
        left: 0;
        height: 75px;
      }
      .arm-left {
        transform: rotate(50deg);
      }
      .arm-right {
        transform: rotate(-50deg);
      }
      .leg {
        top: 100px;
        left: 0;
        height: 90px;
      }
      .leg-left {
        transform: rotate(25deg);
      }
      .leg-right {
        transform: rotate(-25deg);
      }
    </style>
  </head>
  <body>
    <h1>Человек из div</h1>
    <div
      class="person"
      role="img"
      aria-label="Человек с круглой головой, двумя глазами, руками и ногами"
    >
      <div class="head">
        <div class="eye eye-left"></div>
        <div class="eye eye-right"></div>
      </div>
      <div class="torso">
        <div class="arm arm-left"></div>
        <div class="arm arm-right"></div>
        <div class="leg leg-left"></div>
        <div class="leg leg-right"></div>
      </div>
    </div>
  </body>
</html>
```

## Часть 2. Бинго студента-дизайнера

В `bingo.html` сделайте поле из 25 ячеек: пять столбцов и пять строк

1. Используйте один контейнер `div` и 25 вложенных `div` с общим классом ячейки, в порядке слева направо и сверху вниз; не используйте `table`, отдельные обертки строк или `br`
2. Разместите ячейки через `display: inline-block` с автоматическим переносом при заполнении ширины контейнера, выравнивание - `vertical-align: top`
3. Ширина поля - `700px`, размер каждой ячейки - `140px` на `140px` вместе с границей и внутренними отступами; примените `box-sizing: border-box`
4. Уберите влияние пробелов между `inline-block`: задайте контейнеру `font-size: 0`, а ячейкам верните `font-size: 14px`; не добавляйте внешние отступы, меняющие расчет пяти столбцов
5. В каждой ячейке разместите подпись и отдельное изображение через `img`: локальную фотографию или иконку размером `40px` на `40px`, подходящую по смыслу; используйте минимум пять разных файлов, не заменяйте изображения эмодзи
6. Возьмите подписи из таблицы ниже или замените их своими в рамках одной темы; изображение должно дополнять подпись по смыслу
7. Добавьте границу и внутренние отступы ячеек, выравнивание содержимого по центру, читаемый цвет текста; при `:hover` меняйте `background-color` любой ячейки
8. Если изображение повторяет смысл подписи, задайте `alt=""`; если добавляет сведения, опишите их в `alt`

## Часть 3. Оформление расписания

Скопируйте результат лабораторной 03b в `schedule` или распакуйте туда [готовую HTML-заготовку](../assets/lab5-schedule/schedule-starter.zip); исходную работу 03b сохраните отдельно

Используйте все три страницы недель и три страницы предметов; содержимое таблиц, `caption`, заголовки столбцов, объединенную ячейку дня без пар и существующие ссылки сохраните

В общем файле стилей задайте

1. Единый шрифт и цвет текста, фон страницы, внутренние отступы у `header`, `main` и `footer`
2. Основному содержимому ширину `960px` и горизонтальные внешние отступы `auto`
3. Таблицам ширину `100%`, `border-collapse: collapse` и нижний отступ `24px`
4. Ячейкам `th` и `td` границу `1px solid`, внутренние отступы `12px` и вертикальное выравнивание `top`
5. Заголовкам столбцов отдельный фон и контрастный цвет текста; `caption` - выравнивание слева, жирное начертание и нижний отступ `8px`
6. Четным строкам `tbody` другой фон через `:nth-child(even)`; при наведении на строку меняйте фон всех ее ячеек так, чтобы выделение было видно и на четной строке
7. Ячейке `Пар нет` отдельный класс: выравнивание по центру, курсив и собственный фон
8. Столбцу времени запрет переноса через `white-space: nowrap`, номеру аудитории - выравнивание по центру
9. Ссылкам навигации внутренние отступы, границу и `display: inline-block`; состояниям `:hover` и `:focus-visible` - заметное оформление, сохранив видимый фокус
10. Страницам предметов единое оформление заголовков, списков и пар `dt` / `dd` через тот же файл CSS

Ограничивайте правила областью применения: например, классом на `body`, чтобы оформление таблиц расписания не меняло рисунок и бинго
