## Семантические области

Семантические элементы объясняют назначение содержимого. Экранные дикторы используют области страницы для навигации

| Элемент   | Назначение                                                     |
| --------- | -------------------------------------------------------------- |
| `header`  | Вводная часть страницы или материала                           |
| `nav`     | Основной блок навигации                                        |
| `main`    | Главное содержимое страницы                                    |
| `footer`  | Завершающая информация, например сведения об авторе            |
| `section` | Тематический раздел с заголовком                               |
| `article` | Самостоятельный материал: описание предмета, новость, карточка |
| `div`     | Группа элементов без собственного семантического значения      |

В простом документе используется один `main`; общую шапку и подвал размещают вне него. `article` может включать несколько разделов `section`. Уровни заголовков выбираются по вложенности содержания

Ссылка перед шапкой `<a href="#content">К содержимому</a>` позволяет пропустить меню, если у `main` указан `id="content"`. `Tab` выбирает следующую ссылку, `Shift + Tab` - предыдущую, `Enter` активирует ее

## Несколько страниц и пути

Каждая страница - отдельный HTML-документ со своими `head`, `body` и названием в `title`. Общие части обычных HTML-файлов не синхронизируются автоматически

Относительный путь отсчитывается от папки текущего документа:

```text
site/
|-- index.html
|-- week2.html
`-- subjects/
    `-- drawing.html
```

| Откуда                  | Куда          | Значение `href`         |
| ----------------------- | ------------- | ----------------------- |
| `index.html`            | Вторая неделя | `week2.html`            |
| `week2.html`            | Рисунок       | `subjects/drawing.html` |
| `subjects/drawing.html` | Первая неделя | `../index.html`         |

`../` поднимает на уровень папок выше. Начальный `/` отсчитывает путь от корня сайта

Ссылка `../week2.html#monday` открывает другую страницу и переходит к элементу с `id="monday"`

`Назад` и `Далее` - обычные ссылки с явно заданными адресами. Они не зависят от истории браузера

## Характеристики, подписи и контакты

`dl` объединяет названия характеристик `dt` и их значения `dd`:

```html
<dl>
  <dt>Формат</dt>
  <dd>Практические занятия</dd>
  <dt>Что взять</dt>
  <dd>Альбом и карандаши</dd>
</dl>
```

`figure` объединяет иллюстрацию с подписью `figcaption`, расположенной первым или последним дочерним элементом. Подпись видна посетителям и не заменяет `alt`

`address` содержит контакты автора или организации, к которым относится материал. Произвольный адрес места события не требует этого элемента

Ссылка `<a href="mailto:hello@example.com">Написать</a>` передает адрес настроенному почтовому приложению, но не отправляет письмо автоматически

## Таблицы

Таблицы предназначены для связанных данных, например расписания, а не для размещения блоков сайта

| Элемент   | Назначение                                           |
| --------- | ---------------------------------------------------- |
| `table`   | Таблица                                              |
| `caption` | Название таблицы, сразу после открывающего `table`   |
| `thead`   | Группа строк заголовков                              |
| `tbody`   | Группа строк данных                                  |
| `tr`      | Строка                                               |
| `th`      | Ячейка заголовка                                     |
| `td`      | Ячейка данных                                        |
| `tfoot`   | Необязательные итоговые строки, например общая сумма |

```html
<table>
  <caption>
    Понедельник, 5 октября
  </caption>
  <thead>
    <tr>
      <th scope="col">Время</th>
      <th scope="col">Предмет</th>
      <th scope="col">Аудитория</th>
      <th scope="col">Преподаватель</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>09:00 - 10:30</td>
      <td><a href="subjects/drawing.html">Рисунок</a></td>
      <td>А-201</td>
      <td>Иванова Анна Сергеевна</td>
    </tr>
  </tbody>
</table>
```

Ячейки располагаются внутри строк. Ссылки, абзацы и списки помещают в ячейки, а не между строками

`scope="col"` связывает заголовок со столбцом, `scope="row"` - со строкой. Это помогает экранному диктору объяснить данные. Жирный текст в `td` не заменяет `th`

### Объединение ячеек

`colspan` задает число занимаемых столбцов, `rowspan` - строк

Для дня без занятий сохраните `caption` и `thead`, а внутри `tbody` разместите:

```html
<tr>
  <td colspan="4">Пар нет</td>
</tr>
```

Ячейка занимает четыре столбца. Дополнительные пустые ячейки не нужны. При `rowspan="2"` ячейка занимает место также в следующей строке, где соответствующую ячейку пропускают

### Вид без CSS

Браузер выстраивает строки и столбцы, обычно выделяет `th` жирным и показывает `caption` над таблицей. Ширина зависит от содержимого

Сетка по умолчанию не отображается. Границы, отступы и фон задаются CSS. Устаревшие атрибуты `border`, `cellpadding`, `cellspacing`, `bgcolor` не используйте
