# Адаптивная верстка на CSS

## Область просмотра

Адаптивный макет меняет размеры и расположение блоков при изменении доступной ширины

Viewport - область просмотра страницы, измеряемая в CSS-пикселях

В `head` страницы задают

```html
<meta name="viewport" content="width=device-width, initial-scale=1" />
```

`width=device-width` согласует ширину области верстки с устройством, `initial-scale=1` задает начальный масштаб. Сохраняйте возможность увеличения страницы жестом. [MDN о viewport](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/meta/name/viewport)

## Гибкие размеры

Контейнер должен помещаться в окно и иметь предел ширины для удобного чтения

```css
* {
  box-sizing: border-box;
}

body {
  margin: 0;
}

.container {
  width: calc(100% - 32px);
  max-width: 1120px;
  margin-inline: auto;
}

img {
  display: block;
  max-width: 100%;
  height: auto;
}
```

При ширине окна `360px` контейнер занимает `328px`, при `1280px` достигает предела `1120px`

Изображение уменьшается с сохранением пропорций. Гибкие размеры работают между точками перестроения. [MDN об адаптивной верстке](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout/Responsive_Design)

## Медиазапросы и mobile-first

Медиазапрос `@media` включает CSS при выполнении условия. Брейкпоинт - граница, на которой меняется компоновка

Mobile-first означает базовые стили для узкого экрана и изменения для большей ширины. Пример для контейнера `cards` с тремя карточками

```css
.cards {
  display: grid;
  grid-template-columns: minmax(0, 1fr);
  gap: 16px;
}

@media (min-width: 640px) {
  .cards {
    grid-template-columns: repeat(2, minmax(0, 1fr));
  }
}

@media (min-width: 1024px) {
  .cards {
    grid-template-columns: repeat(3, minmax(0, 1fr));
    gap: 24px;
  }
}
```

При `768px` работают базовые правила и первый запрос. При `1280px` действуют оба запроса, позднее объявление с тем же селектором задает три колонки

`min-width` включает указанную границу. Брейкпоинт выбирают по содержимому, когда карточкам достаточно места для дополнительной колонки. [MDN о медиазапросах](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout/Media_queries)

## Перестройка блоков

Изображение и описание можно перестроить из одной колонки в две

```css
.feature {
  display: grid;
  grid-template-columns: minmax(0, 1fr);
  gap: 24px;
}

@media (min-width: 640px) {
  .feature {
    grid-template-columns: repeat(2, minmax(0, 1fr));
    align-items: center;
  }
}
```

Навигации задайте `display: flex` и `flex-wrap: wrap` для переноса ссылок. Порядок элементов HTML определяет последовательность чтения и переходов клавишей Tab

## Текст и нехватка места

Высота карточки должна расти при переносе текста. Строка с названием и ценой

```css
.menu-row {
  display: flex;
  align-items: baseline;
  gap: 16px;
}

.menu-name {
  flex: 1;
  min-width: 0;
  overflow-wrap: anywhere;
}

.price {
  flex-shrink: 0;
  white-space: nowrap;
}
```

Название занимает свободное место и сжимается благодаря `min-width: 0`. Длинное слово переносится, цена остается целиком

Размер текста и отступы также меняются внутри медиазапросов

## Проверка в браузере

В инструментах разработчика Chrome включите кнопку телефона и планшета, выберите режим `Responsive`

1. Задайте ширину окна и проверьте границы перестроения с обеих сторон, например `639px`, `640px` и `641px`
2. Плавно меняйте ширину, наблюдая за переносами и изображениями
3. Выберите проблемный элемент в `Elements`, найдите его медиазапрос в `Styles` и итоговую ширину в `Computed`

Если появилась горизонтальная прокрутка, проверьте фиксированную ширину, `min-width`, длинные слова и размеры изображений. Обрезка через `overflow-x: hidden` может скрыть содержимое за границей экрана

Выйдите из режима устройств и увеличьте масштаб страницы до `200%` через меню браузера. Доступная ширина в CSS-пикселях уменьшится, макет может перестроиться. Проверьте тексты, цены и ссылки, верните масштаб к `100%`
