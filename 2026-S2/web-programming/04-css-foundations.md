## Запись и подключение CSS

CSS задает внешний вид HTML-элементов. Одни и те же свойства можно записывать тремя способами

### Атрибут style

Стиль относится к конкретному элементу:

```html
<p style="color: #1e40af; font-size: 24px;">Название альбома</p>
```

Удобен для первого знакомства и единичного примера, но при повторении приходится менять каждый элемент отдельно. Селекторы и состояния вроде `:hover` внутри атрибута не записывают

### Элемент style

Правила размещают в `head` текущего документа:

```html
<style>
  .description {
    color: #374151;
    font-size: 16px;
  }
</style>
```

Стили действуют только на этот документ, даже если другие страницы открываются с того же сайта

### Внешний файл

```text
site/
|-- index.html
|-- pages/
|   `-- artist.html
|-- css/
|   `-- styles.css
`-- assets/
    |-- cover.jpg
    `-- fonts/
        `-- album-sans.woff2
```

В `head` файла `index.html`:

```html
<link rel="stylesheet" href="css/styles.css" />
```

В `head` файла `pages/artist.html`:

```html
<link rel="stylesheet" href="../css/styles.css" />
```

В самом `styles.css` пишется только CSS, без тегов `<style>`:

```css
body {
  font-family: Arial, sans-serif;
  color: #1f2937;
}
```

Один файл можно подключить ко всем страницам: изменение общего правила отразится на каждой из них. Файл сохраняют в UTF-8 с расширением `.css`

Путь в `href` отсчитывается от HTML-документа. Путь внутри `url()` внешнего CSS отсчитывается от CSS-файла: для приведенной структуры подойдет `url("../assets/cover.jpg")`

Можно подключить несколько таблиц стилей. При равном приоритете правил важен порядок их подключения, а не скорость загрузки. Внешний файл сам по себе не слабее и не сильнее `<style>`

`@import url("theme.css");` также подключает таблицу стилей из CSS. Для обычных файлов курса используйте `<link>`: зависимости видны в HTML и не образуют цепочку загрузок. `@import` должен предшествовать обычным правилам; перед ним допустимы `@charset` и объявления порядка слоев `@layer`

## Синтаксис

```css
/* Краткое описание правила */
.track {
  color: #1f2937;
  padding: 16px;
}
```

`.track` - селектор, содержимое фигурных скобок - блок объявлений. Объявление состоит из свойства и значения, разделенных двоеточием, и заканчивается `;`

В атрибуте `style` фигурные скобки не нужны. В CSS используются комментарии `/* ... */`, а не `//`

Имена свойств пишутся через дефис: `background-color`. Значения зависят от свойства: `16px`, `bold`, `#ffffff`, `url("image.jpg")`

Браузер игнорирует неизвестные свойства и неподходящие значения. Пропущенная точка с запятой может испортить соседнее объявление, а незакрытая скобка - структуру нескольких правил

Сокращенные свойства задают несколько составляющих сразу:

```css
.track {
  border: 2px solid #475569;
}
```

Это толщина, тип линии и цвет. Сокращение может сбрасывать неуказанные составляющие: например, `background: white` сбросит ранее заданную фоновую картинку. Для изменения только цвета используйте `background-color`

## Селекторы

### Базовые селекторы и комбинации

| Селектор | Что выбирает |
| --- | --- |
| `*` | Все элементы |
| `h1` | Все элементы `h1` |
| `.track` | Элементы с классом `track` |
| `#recording` | Элемент с идентификатором `recording` |
| `article.track` | Элементы `article` с классом `track` |
| `.track.featured` | Элементы, у которых одновременно есть оба класса |
| `h1, h2, h3` | Каждый из перечисленных типов заголовков |

```html
<article class="track featured">
  <h2>Неон</h2>
</article>
```

Класс подходит для повторяющегося оформления. Один элемент может иметь несколько классов, порядок слов в `class` не влияет на приоритет. Для учебных проектов удобно использовать названия по назначению: `track`, `description`, `duration`

### Связи между элементами

| Селектор | Что выбирает |
| --- | --- |
| `.track h2` | `h2` внутри `.track` на любой глубине |
| `.track > h2` | Только непосредственные дочерние `h2` элемента `.track` |
| `h2 + p` | Абзац, следующий сразу после `h2` у того же родителя |
| `h2 ~ p` | Все следующие абзацы у того же родителя |

Селектор `.track .featured` ищет потомка, а `.track.featured` - один элемент с двумя классами. Пробел меняет смысл

### Атрибуты

| Селектор | Условие |
| --- | --- |
| `[required]` | Есть атрибут `required` |
| `input[type="email"]` | Поле имеет указанный тип |
| `a[href^="https://"]` | Адрес начинается с указанной строки |
| `a[href$=".pdf"]` | Адрес заканчивается указанной строкой |
| `[class~="featured"]` | Значение содержит отдельное слово `featured` |
| `[data-kind*="live"]` | Значение содержит подстроку `live` |

`data-*` позволяет хранить собственные метки в HTML, например `data-kind="live-recording"`. Селектор по подстроке не понимает смысл URL: адрес `file.pdf?download=1` не заканчивается на `.pdf`

Перечень синтаксических форм: [селекторы CSS в MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Selectors)

## Псевдоклассы

Псевдокласс записывается через одно двоеточие и проверяет состояние или положение элемента

| Селектор | Когда применяется |
| --- | --- |
| `a:link` | Ссылка еще не посещена |
| `a:visited` | Ссылка посещена; браузер ограничивает доступное оформление ради приватности |
| `a:hover` | Указатель наведен на ссылку |
| `a:active` | Ссылка активируется, например при удержании кнопки мыши |
| `a:focus` | Ссылка получила фокус |
| `a:focus-visible` | Браузер считает необходимым показать фокус, обычно при управлении клавиатурой |
| `.track:focus-within` | Фокус на карточке или одном из ее потомков |
| `input:checked` | Флажок или переключатель выбран |
| `input:disabled` | Поле отключено атрибутом `disabled` |
| `input:required` | Поле обязательно для заполнения |
| `input:invalid` | Значение не соответствует ограничениям HTML |
| `section:target` | Идентификатор раздела указан во фрагменте адреса после `#` |

`:active` не означает «текущая страница меню». Для текущей страницы можно использовать класс или `[aria-current="page"]`

При одинаковой специфичности правила ссылок часто записывают в порядке `:link`, `:visited`, `:hover`, `:active`, чтобы более позднее состояние перекрывало цвет предыдущего. Обводку фокуса задают отдельно

### Положение среди соседей

```css
.track:first-child { border-color: #1e40af; }
.track:last-child { margin-bottom: 0; }
li:nth-child(odd) { color: #374151; }
li:nth-child(3n) { font-weight: bold; }
```

`:first-child` требует, чтобы элемент был первым ребенком родителя: заголовок перед первой карточкой уже мешает условию. `:nth-child()` считает позиции всех соседних элементов, начиная с 1; `odd` - нечетные, `even` - четные

`p:first-of-type` выбирает первый `p` среди соседей, даже если перед ним есть заголовок. `p:nth-of-type(2)` - второй абзац

### Условия выбора

```css
.track:not(.featured) { border-color: #475569; }
:is(h1, h2, h3) { font-family: Arial, sans-serif; }
:where(.article) p { line-height: 1.6; }
.track:has(.badge) { background-color: #fef3c7; }
```

`:not()` исключает совпадение, `:is()` объединяет варианты, `:where()` делает это без добавления специфичности, `:has()` проверяет наличие связанного элемента. В примере `:has()` оформляет карточку, содержащую `.badge`

Для старых браузеров в учебных VM проверяйте поддержку новых селекторов. В первых работах достаточно классов и обычных связей элементов

## Псевдоэлементы

Псевдоэлемент записывается через два двоеточия и позволяет оформить часть элемента

| Селектор | Область оформления |
| --- | --- |
| `p::first-letter` | Первая буква |
| `p::first-line` | Первая отображаемая строка |
| `li::marker` | Маркер списка |
| `::selection` | Выделенный пользователем текст |
| `input::placeholder` | Текст подсказки в пустом поле |
| `.badge::before`, `.badge::after` | Сгенерированное содержимое в начале или конце элемента |

```css
.badge::before {
  content: "★ ";
  color: #92400e;
}

li::marker {
  color: #1e40af;
}
```

Для `::before` и `::after` обычно требуется `content`, хотя бы пустая строка. Существенные сведения, например цену, название или предупреждение, оставляйте в HTML: декоративное содержимое CSS не должно быть их единственным источником

## Каскад и специфичность

Каскад выбирает значение отдельно для каждого свойства. Учитываются применимость правила, источник и важность, слой каскада, специфичность и порядок записи. Правила браузера, пользователя и автора страницы имеют разные приоритеты; одной специфичностью нельзя перекрыть более приоритетный источник

Для обычных авторских правил без слоев и `!important`:

1. Атрибут `style` перекрывает правила из `<style>` и подключенных файлов
2. Среди правил сравнивают специфичность
3. При равной специфичности побеждает более позднее объявление

Специфичность сравнивают как три числа: количество `id`, затем классов, атрибутов и псевдоклассов, затем тегов и псевдоэлементов

| Селектор | Специфичность |
| --- | --- |
| `h2` | 0-0-1 |
| `.track` | 0-1-0 |
| `.track h2` | 0-1-1 |
| `.track.featured` | 0-2-0 |
| `#recording` | 1-0-0 |

Это не десятичные числа: множество классов не перевешивает один `id`. `*` и знаки связей веса не добавляют

У `:where()` специфичность нулевая вместе с аргументами. `:is()`, `:not()` и `:has()` берут вес самого специфичного селектора из аргументов, поэтому `id` в одном из вариантов может неожиданно усилить правило

```css
.description {
  color: #166534;
  font-size: 18px;
}

.description {
  color: #374151;
}
```

Текст станет серым, но сохранит размер `18px`. Новое правило не отменяет предыдущее целиком

Описание механизма: [каскад](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Cascade/Introduction) и [специфичность](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Cascade/Specificity)

### Важность и слои

`color: red !important` повышает приоритет объявления; это не увеличение специфичности. В авторских стилях такое объявление перекрывает обычный атрибут `style`. Среди важных объявлений тоже действуют правила каскада. Не используйте `!important` как способ исправлять любую непонятную ситуацию

Слои позволяют заранее установить порядок групп правил:

```css
@layer base, components;

@layer base {
  h2 { color: #374151; }
}

@layer components {
  .track h2 { color: #1e40af; }
}
```

Для обычных авторских объявлений более поздний слой сильнее раннего, а правила вне слоев сильнее правил внутри них. Для `!important` порядок слоев обратный. Слои полезны в больших таблицах стилей, для лабораторной 4 не требуются

Анимации и активные переходы имеют собственные позиции в каскаде: ключевые кадры перекрывают обычные объявления, важные объявления перекрывают ключевые кадры, а активные переходы имеют приоритет даже над важными объявлениями

## Наследование и сброс значений

`color`, `font-family`, `font-size`, `line-height` обычно наследуются. Шрифт удобно задавать для `body`; явно заданное значение дочернего элемента заменяет унаследованное, независимо от силы селектора родителя

`padding`, `margin` и границы не наследуются. Видимый через прозрачный элемент фон родителя - не наследование

| Значение | Действие |
| --- | --- |
| `inherit` | Взять значение свойства у родителя |
| `initial` | Использовать исходное значение из спецификации |
| `unset` | Наследовать наследуемое свойство, иначе использовать исходное |
| `revert` | Откатить влияние текущего источника стилей, например к пользовательским или браузерным стилям |
| `revert-layer` | Откатить влияние текущего слоя |

`initial` не означает «как обычно показывает браузер»: браузерная таблица стилей сама может переопределять исходные значения

```css
button,
input,
textarea,
select {
  font: inherit;
}
```

Элементы форм нередко имеют собственный браузерный шрифт. Это правило явно передает им шрифт родителя

## Единицы и вычисления

| Единица | От чего зависит |
| --- | --- |
| `px` | CSS-пиксель, не обязательно один физический пиксель экрана |
| `%` | Зависит от свойства: для обычного `width` - от ширины содержащего блока |
| `rem` | Размер шрифта корневого элемента `html` |
| `em` | Для `font-size` - размер шрифта родителя; для отступов - самого элемента |
| `ch` | Ширина символа `0` текущего шрифта |
| `vw`, `vh` | 1 процент ширины или высоты области просмотра |
| `dvh` | 1 процент динамической высоты области просмотра, учитывающей изменение панелей браузера |
| `s`, `ms` | Секунды и миллисекунды |
| `deg` | Угол в градусах |

Без изменения настроек корневой размер часто равен `16px`, но пользователь может его изменить. `2rem` означает удвоенный корневой размер, а не всегда `32px`

Нулевую длину можно записывать как `0`. `line-height: 1.5` - множитель размера шрифта; `line-height: 1.5px` - очень маленькая фиксированная высота строки

```css
.description {
  max-width: 65ch;
  font-size: clamp(1rem, 0.9rem + 0.5vw, 1.25rem);
}

.cover {
  width: min(100%, 320px);
}
```

`min()` выбирает меньшее, `max()` - большее, `clamp(минимум, желаемое, максимум)` ограничивает значение с двух сторон. `calc(100% - 2rem)` вычисляет выражение; вокруг `+` и `-` нужны пробелы. Совмещаемые величины должны подходить свойству

## Переменные CSS

Пользовательские свойства начинаются с `--`, а значения читаются через `var()`:

```css
:root {
  --accent: #1e40af;
  --surface: #f3f4f6;
  --radius: 12px;
}

.track {
  color: var(--accent);
  background-color: var(--surface);
  border-radius: var(--radius);
}

.featured {
  --accent: #92400e;
}
```

`:root` выбирает корневой элемент документа. Обычные пользовательские свойства участвуют в каскаде и наследуются, поэтому переопределение внутри карточки действует и на ее потомков

`var(--accent, #1e40af)` задает запасное значение, если переменная отсутствует или имеет гарантированно недействительное значение. Но запасное значение не исправит неподходящий тип: если `--accent: 20px`, объявление `color: var(--accent, red)` не станет красным

Имена переменных чувствительны к регистру. Переменные удобны для палитры, размеров скруглений и повторяющихся отступов. [Описание `var()`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/var)

## Цвет, фон и прозрачность

```css
.badge {
  color: #1e40af;
  background-color: rgb(219 234 254 / 80%);
  border: 1px solid currentColor;
}
```

`color` задает цвет текста, `background-color` - фон. `currentColor` подставляет вычисленный цвет текста, `transparent` означает полностью прозрачный цвет

Цвета записывают именами (`white`), HEX (`#ffffff`, сокращенно `#fff`), функциями `rgb()` или `hsl()`. Например, `hsl(220 70% 40%)` задает оттенок, насыщенность и светлоту. Альфа-канал после `/` управляет прозрачностью цвета

`opacity: 0.5` делает полупрозрачным весь элемент вместе с потомками. Для полупрозрачного фона и непрозрачного текста нужен альфа-канал именно в цвете фона. `opacity: 0` не удаляет элемент и сам по себе не исключает его из клавиатурной навигации

### Изображения и градиенты фона

```css
.album-note {
  background-color: #172554;
  background-image: linear-gradient(135deg, #172554, #3730a3);
  color: white;
}

.texture {
  background-image: url("../assets/texture.jpg");
  background-repeat: no-repeat;
  background-position: center;
  background-size: cover;
}
```

`cover` заполняет область с возможным обрезанием картинки, `contain` показывает ее целиком с возможными пустыми участками. Градиент считается фоновым изображением; `radial-gradient()` создает радиальный градиент

Фон может иметь несколько изображений через запятую, первое рисуется поверх остальных. Значимая иллюстрация должна оставаться HTML-изображением с текстовой альтернативой: у CSS-фона нет `alt`

Проверяйте читаемость на фактическом фоне, включая картинки и прозрачность. Не передавайте смысл только цветом и не делайте весь текст бледным через `opacity`

## Шрифты и текст

| Свойство | Пример | Назначение |
| --- | --- | --- |
| `font-family` | `Arial, sans-serif` | Шрифты в порядке предпочтения |
| `font-size` | `1rem` | Размер шрифта |
| `font-weight` | `400`, `700`, `normal`, `bold` | Насыщенность |
| `font-style` | `normal`, `italic` | Прямое или курсивное начертание |
| `line-height` | `1.6` | Высота строки |
| `letter-spacing` | `0.03em` | Дополнительный интервал между буквами |
| `word-spacing` | `0.1em` | Дополнительный интервал между словами |
| `text-align` | `left`, `center`, `right` | Выравнивание текста внутри блока |
| `text-indent` | `1.5em` | Отступ первой строки |
| `text-transform` | `uppercase`, `lowercase`, `capitalize` | Отображение регистра |
| `text-decoration` | `underline`, `line-through`, `none` | Линии подчеркивания и зачеркивания |

`text-align: center` не центрирует сам блок. `text-transform` не меняет исходный текст HTML. `capitalize` меняет первые буквы слов, а не исправляет написание имен

Если первого шрифта нет, браузер пробует следующий. Завершайте список общим семейством: `serif` с засечками, `sans-serif` без засечек, `monospace` с одинаковой шириной символов. Названия с пробелами записывайте в кавычках

`font-weight: 700` обычно соответствует жирному начертанию, но доступные варианты зависят от файла шрифта. Не каждый шрифт содержит кириллицу или китайские символы

```css
.description {
  font: 400 1rem/1.6 Arial, sans-serif;
}
```

Сокращение `font` требует как минимум размера и семейства; оно сбрасывает неуказанные составляющие к исходным значениям

### Переносы и длинный текст

- `white-space: normal` разрешает обычные переносы и схлопывает пробелы
- `white-space: nowrap` запрещает переносы строк
- `white-space: pre-wrap` сохраняет пробелы и исходные переводы строк, разрешая перенос длинных строк
- `overflow-wrap: anywhere` разрешает разорвать длинный URL или слово, если иначе оно не помещается
- `hyphens: auto` включает автоматические переносы при наличии словаря для языка документа

Для длинных названий не задавайте малую фиксированную высоту. Увеличение текста пользователем не должно скрывать содержимое

### Подключение шрифта

```css
@font-face {
  font-family: "Album Sans";
  src: url("../assets/fonts/album-sans.woff2") format("woff2");
  font-weight: 400;
  font-style: normal;
  font-display: swap;
}

body {
  font-family: "Album Sans", Arial, sans-serif;
}
```

В примере файл шрифта должен существовать по указанному пути. `font-display: swap` разрешает сначала показать запасной шрифт. Для отдельного жирного файла создают еще одно правило с соответствующим `font-weight`. Используйте шрифты с разрешением на веб-применение. [Описание `@font-face`](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@font-face)

## Размеры и блочная модель

Содержимое окружено внутренним отступом `padding` и границей `border`. Внешний отступ `margin` отделяет элемент от соседей

```css
.track {
  width: 100%;
  max-width: 480px;
  box-sizing: border-box;
  padding: 16px;
  border: 2px solid #475569;
  margin-bottom: 24px;
}
```

При `content-box` значение `width: 480px` относится к содержимому. С отступами по `16px` и границами по `2px` общая ширина будет `516px`. При `border-box` все это входит в `480px`, а для содержимого остается `444px`. Внешний `margin` в ширину не входит в обоих случаях

Часто режим задают всем элементам, включая псевдоэлементы:

```css
*,
*::before,
*::after {
  box-sizing: border-box;
}
```

`width` и `height` задают размеры, `min-width` и `min-height` - минимумы, `max-width` и `max-height` - максимумы. `height: auto` позволяет высоте определяться содержимым. Процентная высота требует подходящей определенной высоты содержащего блока и не всегда означает процент окна

### Краткая запись отступов

| Запись | Стороны |
| --- | --- |
| `padding: 12px` | Все стороны |
| `padding: 12px 20px` | Верх/низ, лево/право |
| `padding: 12px 20px 8px` | Верх, лево/право, низ |
| `padding: 12px 20px 8px 4px` | Верх, право, низ, лево |

Для `margin` порядок такой же. Отдельную сторону задают через `padding-left`, `margin-top` и подобные свойства. `padding` не бывает отрицательным; отрицательный `margin` возможен, но для первых работ не нужен

Вертикальные внешние отступы в обычном блочном потоке могут схлопываться: два соседних положительных отступа не всегда складываются. Правила потока подробно рассматриваются в CSS Layout

Логические свойства учитывают направление письма: `padding-inline` задает отступы вдоль строки, `margin-block` - поперек нее. При обычном горизонтальном русском тексте это соответственно лево/право и верх/низ

### Переполнение

`overflow: visible` позволяет содержимому выходить за границы; `hidden` обрезает видимую часть; `auto` добавляет прокрутку при необходимости. Оси можно задавать отдельно через `overflow-x` и `overflow-y`

Не исправляйте потерю текста обрезанием. Сначала проверьте ширину, высоту, переносы и отступы. Тип отображения элемента тоже влияет на применение размеров; `display` разбирается в CSS Layout

## Границы, обводки и тени

```css
.track {
  border: 2px solid #475569;
  border-radius: 12px;
  box-shadow: 0 4px 12px rgb(0 0 0 / 15%);
}
```

У `border` задаются толщина, тип линии (`solid`, `dashed`, `dotted`) и цвет. `border-left` меняет одну сторону, `border-color` - цвет. Без видимого типа линии одного цвета недостаточно

`border-radius` скругляет углы. Значение `50%` у квадратного изображения делает его круглым

В `box-shadow` указаны смещения по горизонтали и вертикали, размытие и цвет. Дополнительно можно задать расширение тени и `inset` для внутренней тени. Тень не занимает место в потоке. `text-shadow` рисует тень у текста, но сильное размытие ухудшает читаемость

`outline` тоже не занимает место в потоке и особенно полезен для фокуса. `outline-offset` задает расстояние от края элемента

## Изображения

Для сохранения пропорций:

```css
.cover {
  width: 100%;
  max-width: 320px;
  height: auto;
  border-radius: 8px;
}
```

Для одинаковых квадратных миниатюр:

```css
.thumbnail {
  width: 160px;
  height: 160px;
  object-fit: cover;
  object-position: center;
}
```

`object-fit: cover` обрезает лишнее, `contain` сохраняет изображение целиком внутри заданного прямоугольника. `object-position` выбирает положение изображения, например `50% 30%`

`aspect-ratio: 1 / 1` задает предпочтительное соотношение сторон и помогает, когда один из размеров определяется автоматически. Если жестко заданы обе стороны, оно не переопределяет их

`filter: grayscale(100%)` делает изображение серым, `brightness(0.8)` уменьшает яркость. Фильтры меняют отображение, а не исходный файл; не применяйте их к важной информации без проверки читаемости

## Списки и таблицы

```css
.influences {
  list-style-type: square;
  padding-left: 24px;
}

.influences li {
  margin-bottom: 10px;
}
```

`list-style-position: outside` располагает маркер вне основного текстового блока пункта, `inside` - внутри. `list-style-type: none` убирает маркеры, но не превращает список в обычный текст

Таблица оформляется теми же цветами, отступами и границами:

```css
table {
  border-collapse: collapse;
}

th,
td {
  border: 1px solid #64748b;
  padding: 8px 12px;
  text-align: left;
  vertical-align: top;
}

thead {
  background-color: #e2e8f0;
}

tbody tr:nth-child(even) {
  background-color: #f8fafc;
}

caption {
  text-align: left;
  font-weight: bold;
  margin-bottom: 8px;
}
```

`border-collapse: collapse` объединяет соседние границы. При `separate` расстояние между ячейками задают через `border-spacing`. Фон строк не заменяет заголовки `th`, `scope` и название таблицы

## Ссылки, кнопки и поля

Ссылка выполняет переход, кнопка - действие. Внешний вид не меняет назначение HTML-элемента

```css
a {
  color: #1e40af;
  text-decoration: underline;
  text-underline-offset: 0.15em;
}

a:hover {
  color: #7c2d12;
}

a:focus,
button:focus,
input:focus {
  outline: 2px solid #1e40af;
  outline-offset: 3px;
}
```

Не убирайте фокус без видимой замены. Не прячьте необходимую информацию только в состоянии наведения: на сенсорном экране его может не быть

```css
button {
  font: inherit;
  color: white;
  background-color: #1e40af;
  border: 1px solid #1e40af;
  border-radius: 8px;
  padding: 10px 16px;
  cursor: pointer;
}

button:disabled {
  background-color: #475569;
  cursor: not-allowed;
}

input,
textarea,
select {
  font: inherit;
  border: 1px solid #64748b;
  padding: 8px;
}

input[type="checkbox"],
input[type="radio"] {
  accent-color: #1e40af;
}
```

Курсор `not-allowed` не отключает кнопку: нужен HTML-атрибут `disabled`. Подсказка `placeholder` не заменяет подпись `label`. Ошибка поля должна объясняться текстом, а не только красной рамкой

`appearance: none` убирает часть нативного оформления элементов управления; применять его стоит только при готовности восстановить понятные состояния. Для начальных работ сохраняйте стандартное поведение

## Переходы, преобразования и анимации

### Переход между состояниями

```css
button {
  transition: background-color 180ms ease, color 180ms ease;
}

button:hover {
  background-color: #172554;
}
```

`transition` задается на обычном состоянии, чтобы изменение плавно шло в обе стороны. В записи указаны свойство, длительность и функция изменения скорости; дополнительное время задает задержку

Выбирайте конкретные свойства вместо `transition: all`. Не каждое свойство интерполируется плавно; размеры `auto` не стоит использовать в первых упражнениях на переходы

### Преобразование

```css
.cover {
  transition: transform 180ms ease;
}

.cover:hover {
  transform: scale(1.03) rotate(-1deg);
}
```

`scale()` изменяет масштаб, `rotate()` поворачивает, `translate()` сдвигает отображение. Преобразование не перераспределяет место между соседями, поэтому элемент может перекрыть их. Порядок функций влияет на результат; точка преобразования задается через `transform-origin`

### Ключевые кадры

```css
@keyframes appear {
  from { opacity: 0.5; }
  to { opacity: 1; }
}

.cover {
  animation: appear 400ms ease-out;
}
```

`@keyframes` описывает этапы, `animation` применяет их к элементу. Кроме имени, длительности и функции скорости можно задать задержку, число повторов, направление и сохранение состояния. `infinite` означает бесконечный повтор, `animation-fill-mode: forwards` сохраняет значения конечного кадра после завершения

Не используйте постоянное движение и мигание как украшение учебной страницы

```css
@media (prefers-reduced-motion: reduce) {
  .cover {
    animation: none;
    transition: none;
  }

  .cover:hover {
    transform: none;
  }
}
```

Так учитывается системное предпочтение уменьшить движение. В примере отдельно отменяется преобразование при наведении: отключение `transition` убрало бы только плавность, но сохранило само увеличение картинки

[Описание prefers-reduced-motion](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion)

## Условия применения стилей

`@media` применяет правила при выполнении условия. Кроме размера экрана, можно учитывать печать или цветовую схему:

```css
@media print {
  body {
    color: black;
    background-color: white;
  }
}

@media (prefers-color-scheme: dark) {
  :root {
    --surface: #1f2937;
  }
}
```

Темная тема требует согласовать фон и цвет текста всех связанных элементов; замены одной переменной может быть недостаточно. Условия по ширине экрана и проектирование брейкпоинтов рассматриваются в теории адаптивной верстки

`@supports` проверяет поддержку синтаксиса свойства:

```css
@supports (color: oklch(50% 0.1 250)) {
  .accent {
    color: oklch(50% 0.1 250);
  }
}
```

Базовое оформление задают вне условия, улучшение - внутри. Поддержка синтаксиса не гарантирует отсутствие всех браузерных особенностей

## Организация и проверка CSS

Группируйте правила по назначению: переменные, общие стили, элементы и их состояния. Предпочитайте короткие селекторы и классы по смыслу. Не добавляйте новый `id` или `!important` только ради победы над старым правилом

В `Elements` выберите элемент. Панель `Styles` показывает подходящие правила, файл и строку источника, зачеркнутые переопределенные объявления. Неверные значения обычно отмечаются предупреждением

В `Computed` видны итоговые значения и схема размеров. У заголовков, абзацев и списков есть стандартные стили браузера, поэтому отступы появляются и без вашего CSS

Если оформление не применяется, проверьте последовательно:

1. Загружен ли нужный `.css` в `Network`, нет ли `404` и корректно ли сервер отдает CSS вместо HTML
2. Совпадает ли селектор с тегом, классом, идентификатором или состоянием элемента
3. Допустимы ли свойство и значение, закрыты ли скобки
4. Не перекрыто ли объявление другим правилом, атрибутом или сокращенным свойством
5. Применимо ли свойство к этому элементу и не мешает ли ограничение размера

Изменения через DevTools временные: переносите нужные значения в исходный файл. При подозрении на кеш перезагрузите страницу с отключенным кешем в инструментах разработчика

Проверяйте не только обычное состояние: длинный текст, увеличение масштаба, навигацию клавиатурой и системное уменьшение движения. Внешний вид не должен мешать читать содержание и пользоваться элементами
