## Диапазон алгоритма

Алгоритмы из `<algorithm>` работают с диапазоном `[first, last)`. Первый итератор указывает на начало, второй обозначает границу после последнего элемента. При равных границах диапазон пуст

```cpp
std::vector<int> samples{12, 18, 18, 27, 15};
auto count = std::count(samples.begin(), samples.end(), 18);
std::cout << count << '\n';
```

Результат равен `2`. Границы можно сдвигать. В этом примере `samples.begin() + 2` задает начало с третьего измерения. У арифметики итераторов есть предусловие - результат лежит внутри последовательности или на ее конечной границе

## Лямбда и предикат

Лямбда создает объект, который можно вызвать как функцию. В записи `[](int value) { return value > 20; }` квадратные скобки задают захват внешних переменных, круглые скобки - параметры, фигурные - тело. Тип результата компилятор выводит из `return`

```cpp
auto isHot = [](int value) { return value > 20; };
std::cout << isHot(27) << '\n';
std::cout << std::count_if(samples.begin(), samples.end(), isHot) << '\n';
```

Предикат отвечает на вопрос об элементе. Здесь `isHot` истинен для одного измерения. Алгоритм принимает любой подходящий вызываемый объект, в том числе обычную функцию или объект класса с `operator()`

## Захват переменных

Часть условия можно задать во время выполнения. Захват по значению сохраняет копию в создаваемом объекте лямбды. Захват по ссылке обращается к исходной переменной при каждом вызове

```cpp
int limit = 20;
auto fixed = [limit](int value) { return value > limit; };
auto current = [&limit](int value) { return value > limit; };
limit = 30;
std::cout << fixed(27) << ' ' << current(27) << '\n';
```

Результат - `1 0`. Захваченная по ссылке переменная должна существовать при вызове лямбды. Для условия с несколькими границами их можно перечислить в одном списке захвата, например `[low, high]`

## Поиск и подсчет

| Операция        | Критерий           | Результат                     |
| --------------- | ------------------ | ----------------------------- |
| `std::find`     | Равенство значению | Итератор на первое совпадение |
| `std::find_if`  | Предикат           | Итератор на первое совпадение |
| `std::count`    | Равенство значению | Число совпадений              |
| `std::count_if` | Предикат           | Число совпадений              |

```cpp
auto exact = std::find(samples.begin(), samples.end(), 18);
auto hot = std::find_if(samples.begin(), samples.end(), isHot);
if (exact != samples.end()) std::cout << *exact << '\n';
if (hot != samples.end()) std::cout << *hot << '\n';
```

Поиск останавливается при первом совпадении и возвращает конечную границу, если диапазон исчерпан. Перед разыменованием итератор сравнивают с этой границей. Подсчет просматривает весь диапазон, для пустого диапазона результат равен нулю

## Сортировка и компаратор

`std::sort` переставляет элементы внутри переданного диапазона. Алгоритму нужны итераторы произвольного доступа, например у `vector` или `array`. Для сохранения исходного порядка сортируют копию

```cpp
struct Reading {
  int channel;
  int value;
};
std::vector<Reading> readings{{3, 18}, {2, 27}, {1, 27}};
auto ranked = readings;
std::sort(ranked.begin(), ranked.end(), [](const Reading &a, const Reading &b) {
  if (a.value != b.value) return a.value > b.value;
  return a.channel < b.channel;
});
```

Компаратор возвращает `true`, если первый элемент должен стоять раньше второго. Каналы в примере идут в порядке `1, 2, 3`. Второй ключ разрешает равенство показаний

Компаратор задает строгий слабый порядок. В частности, сравнение элемента с собой дает `false`, а отношение «раньше» транзитивно. Условие `a.value >= b.value` нарушает первое правило. Для эквивалентных элементов порядок после `std::sort` произволен. `std::stable_sort` сохраняет их исходную очередность

Сортировка требует `O(n log n)` сравнений. Чтобы вывести первые `k` элементов, берут минимум из `k` и фактического размера

## Фильтрация и преобразование

`std::copy_if` копирует элементы, прошедшие проверку, сохраняя их относительный порядок. Третий аргумент указывает, куда записывать результат

```cpp
int threshold = 20;
std::vector<Reading> selected;
std::copy_if(readings.begin(), readings.end(), std::back_inserter(selected),
             [threshold](const Reading &r) { return r.value >= threshold; });
```

`std::back_inserter` из `<iterator>` создает выходной итератор, который при записи вызывает `push_back`. Так пустой вектор растет по мере появления результатов. Запись через обычный `begin()` требует заранее созданных элементов. Один вызов `reserve` выделяет память и сохраняет прежний размер

`std::transform` применяет функцию к каждому входному элементу и записывает по одному результату. Вход и результат могут иметь разные типы

```cpp
std::vector<int> channels;
std::transform(selected.begin(), selected.end(), std::back_inserter(channels),
               [](const Reading &r) { return r.channel; });
for (int channel : channels) std::cout << channel << ' ';
```

Получатся номера каналов `2 1`. Здесь выборка строится из исходных измерений. Если передать отсортированную копию на этапе фильтрации, получится порядок `1 2`. Для получения краткой записи лямбда может возвращать объект структуры с выбранными полями

## Записи из текстового потока

Чтобы сохранить пробелы внутри текстового поля, сначала читают строку целиком, затем извлекают поля с заданным разделителем. В примере строка содержит имя датчика и показание через табуляцию

```cpp
std::istringstream row{"room sensor\t27"};
std::string name;
int value{};
if (std::getline(row, name, '\t') && row >> value) {
  std::cout << name << ' ' << value << '\n';
}
```

Для файла с заголовком первый вызов `std::getline(input, line)` читает имена полей. Следующие вызовы в цикле читают строки данных. Для разбора каждой строки создают новый `std::istringstream` из `<sstream>`
