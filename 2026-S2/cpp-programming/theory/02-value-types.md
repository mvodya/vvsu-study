## class и объект

`class` позволяет создать свой тип данных. Внутри класса объявляют поля и методы. Поля хранят данные, методы - это функции для работы с ними.

Например, у счетчика есть поле `value` с текущим числом. Метод `current()` возвращает это число, а `reset()` сбрасывает его в ноль.

```cpp
class Counter {
public:
    int current() const { return value; }
    void reset() { value = 0; }

private:
    int value{0};
};
```

После определения класса ставится `;`. Чтобы создать объект, указывают имя класса и имя переменной. Через `.` вызывают методы объекта:

```cpp
Counter first;
Counter second;
first.reset();
std::cout << first.current() << ' ' << second.current() << '\n';
```

У каждого объекта собственное поле `value`. Вызов `first.reset()` работает с полем объекта `first`.

Под `public` размещают поля и методы, доступные из другого кода. Под `private` размещают внутренние поля и методы. К ним обращаются методы самого класса. Например, `reset()` может изменить `value`, а запись `first.value = 100;` в `main` вызовет ошибку компиляции.

У `class` доступ по умолчанию - `private`, у `struct` - `public`. Обе конструкции поддерживают поля, методы и конструкторы. В курсе `struct` используется для записей с открытыми полями, `class` - для типов, которые сами проверяют и изменяют свои данные.

## Инкапсуляция и инвариант

Инкапсуляция позволяет скрыть внутренние поля и методы класса от остального кода. Для этого их помещают в `private`. Снаружи объект используют через открытые методы из `public`.

Это помогает защитить данные от случайных изменений. Например, уровень сигнала должен быть от `0` до `10`. Если поле открыто, в него можно записать `100`. Если поле закрыто, значение меняется через метод, который проверяет границу.

Правило "уровень всегда от `0` до `10`" называется инвариантом класса. Оно должно выполняться после создания объекта и после каждого вызова его открытых методов.

В классе `Level` начальное значение задает конструктор `Level(int initial)`, а увеличение выполняет метод `increase()`:

```cpp
class Level {
public:
    explicit Level(int initial) : value{initial} {
        if (value < 0) { value = 0; }
        if (value > 10) { value = 10; }
    }
    int current() const { return value; }
    void increase() {
        if (value < 10) { ++value; }
    }
private:
    int value;
};
```

`Level{-3}` получает значение `0`, `Level{20}` получает `10`. Конструктор сразу приводит число к допустимому диапазону.

`increase()` добавляет единицу, пока значение меньше `10`. При значении `10` метод оставляет его прежним. Благодаря `private` остальной код меняет уровень только через предусмотренные методы.

Если добавить метод `setValue` для установки произвольного уровня, в нем тоже потребуется проверка диапазона.

### Отклонение входного значения

Вместо исправления входного числа конструктор может сообщить об ошибке. Например, количество должно быть больше нуля:

```cpp
#include <stdexcept>

class PositiveCount {
public:
    explicit PositiveCount(int initial) : value{initial} {
        if (value <= 0) {
            throw std::invalid_argument{"Count must be positive"};
        }
    }
    int current() const { return value; }
private:
    int value;
};
```

`throw` останавливает выполнение конструктора и передает сообщение об ошибке вызывающему коду. Такой способ сообщения называется исключением. Создание объекта завершается ошибкой. `std::invalid_argument` из `<stdexcept>` - тип исключения для ошибочного аргумента.

Обработать эту ошибку можно так:

```cpp
try {
    const PositiveCount count{0};
    std::cout << count.current() << '\n';
} catch (const std::exception& error) {
    std::cerr << error.what() << '\n';
}
```

В `try` помещают код, который может вызвать исключение. При ошибке управление переходит в подходящий `catch`. Вызов `what()` возвращает текст сообщения. Для примера нужны `<iostream>`, `<exception>` и определение `PositiveCount`. Подробная модель исключений рассматривается в теме обработки ошибок.

Для своего класса заранее выбирают допустимые значения и способ обработки ошибок. Иногда разные входные значения обозначают одно и то же: например, угол `370` градусов можно хранить как `10` градусов. Приведение таких значений к одному виду называется нормализацией.

## Конструкторы

Конструктор вызывается при создании объекта и задает начальные значения его полей. Его имя совпадает с именем класса. Тип возвращаемого значения у конструктора отсутствует.

```cpp
class Point {
public:
    Point() = default;
    Point(int xValue, int yValue) : x{xValue}, y{yValue} {}

    int xCoordinate() const { return x; }
    int yCoordinate() const { return y; }
private:
    int x{0};
    int y{0};
};
```

Конструктор с параметрами получает начальные данные из аргументов: `Point{10, 25}` создает точку с координатами `10` и `25`. Конструктор по умолчанию позволяет создать объект без аргументов: `Point{}`.

```cpp
Point origin{};       // конструктор по умолчанию: (0, 0)
Point marker{10, 25}; // конструктор с параметрами: (10, 25)
```

Запись `Point() = default;` поручает компилятору создать обычный конструктор по умолчанию. В примере он использует начальные значения полей `x{0}` и `y{0}`.

Если в классе вообще отсутствуют объявления конструкторов, компилятор сам объявляет конструктор по умолчанию. После добавления `Point(int, int)` конструктор `Point()` потребуется объявить отдельно. Компилятор сможет создать его реализацию, если все поля допускают такую инициализацию.

Запись `Point object();` объявляет функцию `object`, возвращающую `Point`. Запись `Point object{};` создает объект.

## Список инициализации полей

После параметров конструктора можно поставить `:` и перечислить начальные значения полей. Эта часть называется списком инициализации. Поля получают значения до выполнения команд в теле конструктора.

```cpp
#include <string>

class Label {
public:
    Label(const std::string& text, int code)
        : caption{text}, identifier{code} {}
private:
    std::string caption;
    const int identifier;
};
```

`caption{text}` сразу создает строку с нужным содержимым. Присваивание `caption = text;` в теле выполнялось бы после первоначального создания строки. Поле `const` получает значение при инициализации.

Начальное значение в объявлении поля применяется, когда соответствующее поле отсутствует в списке инициализации.

### Порядок инициализации

Поля инициализируются в порядке объявления внутри класса. Список инициализации записывают в том же порядке:

```cpp
class Interval {
public:
    Interval(int start, int width)
        : left{start}, right{left + width} {}
private:
    int left;
    int right;
};
```

Сначала создается `left`, затем вычисляется `left + width` для `right`. Для этого примера сумма должна помещаться в `int`.

Порядок полей в классе важнее порядка записей после `:`. В примере `right` использует уже готовое значение `left`. Если объявить `right` раньше `left`, вычисление обратится к целому полю без начального значения. В C++20 это приводит к неопределенному поведению (undefined behavior): результат работы программы становится непредсказуемым. Флаги `-Wall -Wextra -Wpedantic` помогают обнаружить ошибки в порядке инициализации.

### Делегирующий конструктор

Один конструктор может поручить начальную настройку объекта другому конструктору того же класса. Это делегирующий конструктор:

```cpp
class Pair {
public:
    Pair() : Pair{0, 0} {}
    Pair(int first, int second) : left{first}, right{second} {}
private:
    int left;
    int right;
};
```

Сначала выполняется выбранный конструктор, затем тело делегирующего конструктора. В списке после `:` у делегирующего конструктора записывают только вызов другого конструктора.

## Константные объекты и методы

Объект с `const` используют для чтения. Методы, которые только читают поля, тоже отмечают `const` - после списка параметров. Так компилятор разрешает вызывать их для константных объектов.

```cpp
const Level fixed{7};
std::cout << fixed.current() << '\n';

Level adjustable{7};
adjustable.increase();
std::cout << adjustable.current() << '\n';
```

В `int current() const` слово `int` означает, что метод возвращает целое число. `const` в конце означает, что через этот метод обычные поля объекта доступны только для чтения. Метод `increase()` меняет поле, поэтому его вызывают для изменяемого объекта.

Попытка вызвать `fixed.increase()` вызывает ошибку компиляции. Читающие методы объявляют `const` сразу: это позволяет использовать их с константами и параметрами `const T&`.

## Передача по значению и по ссылке

Если параметр записан как `Level level`, функция получает копию переданного объекта:

```cpp
void printNext(Level level) {
    level.increase();
    std::cout << level.current() << '\n';
}
```

Вызов `printNext` увеличивает уровень в копии. Исходный объект остается прежним.

Ссылка `T&` дает функции доступ к исходному объекту. Запись `const T&` разрешает только чтение. Например, `const Level&` позволяет прочитать уровень прямо из переданного объекта:

```cpp
void printLevel(const Level& level) {
    std::cout << level.current() << '\n';
}
```

Функция читает исходный `Level` без создания копии. Для изменения исходного объекта используют ссылку без `const`:

```cpp
void increaseLevel(Level& level) {
    level.increase();
}
```

Небольшие типы, включая компактные value types, удобно передавать по значению. Для чтения крупных объектов подходит `const T&`. Новое вычисленное значение возвращают по значению. Время жизни объектов и ссылок рассматривается в следующей теме.

## Value type

Value type - тип, с объектами которого работают как с обычными значениями. Объект можно скопировать, изменить копию отдельно от оригинала и присвоить новое значение. При сравнении таких объектов проверяют их содержимое.

```cpp
Level first{3};
Level second = first; // создание копии
second.increase();    // first: 3, second: 4
first = second;       // присваивание: first: 4, second: 4
```

Для `Level` компилятор сам создает операции копирования и присваивания: они копируют поле `value`. Поля `std::string` и `std::vector` также поддерживают самостоятельные копии содержимого. Для класса с такими полями обычно достаточно стандартных операций копирования.

`Level second = first;` создает новый объект через конструктор копирования. `first = second;` заменяет значение уже существующего объекта через оператор присваивания. Подробно эти операции разбираются в теме времени жизни объектов.

## Перегрузка операторов

Перегрузка операторов позволяет задать, что означают `+`, `-`, `==` и другие операции для своего класса. Например, выражение `start + step` может складывать два объекта `Offset`.

Значения слева и справа от знака операции называют операндами. Хотя бы один из них должен иметь тип класса или перечисления. Приоритет и количество операндов остаются такими же, как у обычного оператора.

Операторы сохраняют привычный смысл: `+` возвращает сумму, `==` проверяет равенство. Арифметические операции обычно возвращают новый объект по значению.

### Оператор как метод класса

Оператор можно объявить как метод класса. В операции с двумя значениями метод вызывается у левого объекта, а правый передается параметром:

```cpp
class Offset {
public:
    explicit Offset(int units) : value{units} {}
    int count() const { return value; }
    Offset operator+(const Offset& other) const {
        return Offset{value + other.value};
    }
    Offset operator-(const Offset& other) const {
        return Offset{value - other.value};
    }
private:
    int value;
};
```

```cpp
const Offset start{12};
const Offset step{5};
const Offset sum = start + step;        // 17
const Offset difference = start - step; // 7
```

`start + step` вызывает `start.operator+(step)`. `const` у метода сохраняет левый операнд; `const Offset&` дает доступ к правому операнду для чтения. `other.value` доступно методу класса `Offset`.

В этих коротких примерах результаты должны помещаться в `int`. Переполнение знакового целого приводит к неопределенному поведению. Поэтому перед сложением или умножением проверяют, поместится ли результат в выбранный тип.

Для сложения двух значений из диапазона `0..max` проверка выглядит так:

```cpp
#include <limits>
#include <stdexcept>

int checkedAdd(int left, int right) {
    const int max = std::numeric_limits<int>::max();
    if (left > max - right) {
        throw std::overflow_error{"Addition overflow"};
    }
    return left + right;
}
```

Эта функция рассчитана на аргументы >= `0`. Выражение `max - right` показывает, какое наибольшее значение можно прибавить к `right`. Проверка выполняется до сложения, пока переполнение еще возможно предотвратить.

### Оператор как свободная функция

Оператор также можно определить вне класса, как обычную функцию. Ее называют свободной функцией. Оба значения для операции она получает через параметры. Например, для `Offset` можно добавить умножение:

```cpp
Offset operator*(const Offset& offset, int factor) {
    return Offset{offset.count() * factor};
}

Offset operator*(int factor, const Offset& offset) {
    return offset * factor;
}
```

Две перегрузки поддерживают `Offset{3} * 4` и `4 * Offset{3}`. Условие примера: произведение помещается в `int`.

Здесь функция получает значение через открытый метод `count()`. Если ей нужен прямой доступ к закрытым полям, внутри класса добавляют ее объявление с `friend`. Это дает доступ к полям, а сама функция продолжает находиться вне класса.

Для операции выбирают одну форму: метод или свободную функцию. Если одновременно определить оба варианта `+` для одинаковых типов, компилятор может сообщить, что подходят сразу две функции.

## Операции сравнения

`operator==` проверяет равенство двух значений, `operator<` проверяет, меньше ли левое значение правого. Обе функции возвращают `bool`:

```cpp
bool operator==(const Offset& left, const Offset& right) {
    return left.count() == right.count();
}

bool operator<(const Offset& left, const Offset& right) {
    return left.count() < right.count();
}
```

```cpp
const bool equal = Offset{3} == Offset{3}; // true
const bool less = Offset{3} < Offset{8};   // true
const bool different = Offset{3} != Offset{8}; // true, C++20
```

C++20 позволяет использовать `!=` через подходящий `operator==`. Отдельный `operator<` задает только `<`. Операции `>`, `<=`, `>=` требуют своих перегрузок либо подходящего `operator<=>`.

### operator<=> в C++20

Оператор `<=>` различает три результата: меньше, равно или больше. Запись `= default` поручает компилятору сравнить поля объектов:

```cpp
#include <compare>

class Rank {
public:
    explicit Rank(int initial) : value{initial} {}
    auto operator<=>(const Rank& other) const = default;
private:
    int value;
};
```

Вариант с `= default` сравнивает поля по порядку объявления. Если первые поля равны, сравниваются вторые, затем следующие. Первое различие определяет результат. Для поля `int` результат имеет тип `std::strong_ordering`.

После такого объявления для `Rank` доступны `<`, `<=`, `>`, `>=`. В этом примере компилятор также создает `operator==`, поэтому работают `==` и `!=`. Если написать тело `<=>` самостоятельно, сравнение на равенство потребуется задать отдельно.

```cpp
const Rank low{2};
const Rank high{5};
std::cout << (low < high) << ' ' << (low == Rank{2}) << '\n';
```

Сравнение с `= default` подходит, когда порядок полей соответствует нужному порядку сравнения. Для `Rank` достаточно сравнить единственное поле `value`.

## Вывод в поток: operator<<

В выражении `output << object` левым операндом является поток. Перегрузку для своего типа размещают свободной функцией рядом с типом:

```cpp
#include <ostream>

std::ostream& operator<<(std::ostream& output, const Offset& offset) {
    output << offset.count() << " units";
    return output;
}
```

Параметр `std::ostream&` дает доступ к потоку, в который нужно писать. `const Offset&` передает объект для чтения. `return output;` возвращает тот же поток, поэтому вывод можно продолжить:

```cpp
std::cout << Offset{12} << ' ' << Offset{5} << '\n';
```

Выражение группируется как `(std::cout << Offset{12}) << ' '`. Поток может быть `std::cout`, файловым `std::ofstream` или строковым `std::ostringstream`.

Оператор использует переданный `output` и оставляет выбор потока вызывающему коду. Если реализация меняет настройки форматирования потока, она сохраняет и восстанавливает эти настройки.

## Преобразующий конструктор и explicit

Конструктор может позволить компилятору автоматически преобразовать число в объект класса. Такой конструктор называют преобразующим. Например, конструктор `Count(int)` позволяет создать `Count` из целого числа:

```cpp
class Count {
public:
    Count(int initial) : value{initial} {}
    int current() const { return value; }
private:
    int value;
};

void printCount(Count count) {
    std::cout << count.current() << '\n';
}
```

```cpp
Count count = 5;
printCount(7);
```

В обоих случаях компилятор сам вызывает конструктор и создает `Count` из `int`. Это неявное преобразование: программист передает число, а нужный объект создает компилятор.

Чтобы создание объекта требовало явного указания типа, например `Count{7}`, к конструктору добавляют `explicit`:

```cpp
explicit Count(int initial) : value{initial} {}
```

После изменения допустимы явные формы создания:

```cpp
Count count{5};
Count another(7);
printCount(Count{7});
```

Выражения `Count count = 5;` и `printCount(7);` теперь вызывают ошибки компиляции. Прямое создание `Count{5}` и копирование уже существующего `Count` остаются доступными.

Одноаргументные конструкторы обычно объявляют `explicit`, когда числовой аргумент имеет специальный смысл или единицы измерения. Конструктор с дополнительными параметрами по умолчанию также может допускать вызов с одним аргументом.

## Оператор преобразования

Оператор преобразования позволяет получить из объекта значение другого типа. Например, `operator int()` получает целое число из `SampleCount`. Тип пишут после `operator`:

```cpp
class SampleCount {
public:
    explicit SampleCount(int initial) : value{initial} {}
    explicit operator int() const { return value; }
private:
    int value;
};
```

```cpp
const SampleCount count{42};
const int raw = static_cast<int>(count);
```

Здесь `explicit` разрешает преобразование по явному запросу через `static_cast<int>(count)`. Запись `int raw = count;` вызывает ошибку компиляции. Именованный метод, например `count.asSamples()`, также может предоставлять числовое представление и явно обозначать его единицы.

Оператор преобразования без `explicit` позволяет компилятору автоматически использовать число из объекта в выражениях. С `explicit` место числового преобразования видно в коде.

## Класс в .hpp и .cpp

Определение класса размещают в заголовочном файле. Тела крупных методов и свободных операторов размещают в `.cpp`. Константность метода указывается и в объявлении, и в определении.

`sample_count.hpp`:

```cpp
#pragma once
#include <iosfwd>

class SampleCount {
public:
    explicit SampleCount(int initial);
    int current() const;
private:
    int value;
};

std::ostream& operator<<(std::ostream& output, const SampleCount& count);
```

`sample_count.cpp`:

```cpp
#include "sample_count.hpp"
#include <ostream>

SampleCount::SampleCount(int initial) : value{initial} {}

int SampleCount::current() const {
    return value;
}

std::ostream& operator<<(std::ostream& output, const SampleCount& count) {
    return output << count.current();
}
```

`SampleCount::` связывает определение метода с классом. `explicit` записывается в объявлении конструктора внутри класса. `<iosfwd>` предоставляет объявления потоковых типов для заголовочного файла, `<ostream>` - операции вывода для реализации.

Метод с телом внутри класса в обычном заголовочном файле автоматически получает свойство `inline`. Благодаря этому один заголовок можно подключить в несколько TU с соблюдением правила ODR из первой темы. Для обычной свободной функции с телом в заголовке потребуется явно написать `inline` либо перенести тело в `.cpp`.

`main.cpp`:

```cpp
#include "sample_count.hpp"
#include <iostream>

int main() {
    const SampleCount count{42};
    std::cout << count << '\n';
}
```

Сборка связывает оба `.cpp`:

```bash
clang++ -std=c++20 -Wall -Wextra -Wpedantic -g main.cpp sample_count.cpp -o app
./app
```

В команду сборки включают оба `.cpp`. Если пропустить `sample_count.cpp`, компоновщик сообщит об отсутствующих определениях конструктора или оператора вывода.

В отладчике можно поставить точку останова в конструкторе и посмотреть, какие значения получают поля. Остановка внутри оператора помогает проверить переданные значения и результат вычисления.
