## Параметр типа

Шаблон функции задает общее определение для семейства функций. Параметр шаблона обозначает тип, который компилятор подставляет при использовании

```cpp
template<class T>
T larger(T left, T right) {
  return left < right ? right : left;
}
```

`template<class T>` объявляет параметр типа `T`. Здесь `class` и `typename` взаимозаменяемы. Аргументом может быть встроенный тип или пользовательский класс. В теле `T` используется как обычное имя типа

```cpp
int a = larger(3, 7);
double b = larger(2.5, 1.0);
```

Для первого вызова используется специализация `larger<int>`, для второго - `larger<double>`. Подстановка аргументов и создание необходимого определения называется инстанцированием, или instantiation

Шаблон относится к статическому полиморфизму из главы 06. Выбор специализации происходит при компиляции. Сами значения `left` и `right` могут поступить во время выполнения

## Вывод и явное указание типа

Template argument deduction выводит аргумент шаблона по типам аргументов вызова. В `larger(T, T)` оба аргумента должны дать согласованный `T`

```cpp
larger(2, 5);             // T = int
larger(2.0, 5.0);         // T = double
larger<double>(2, 5.5);   // T задан явно
// larger(2, 5.5);        // ошибка deduction
```

В последней строке первый аргумент предлагает `int`, второй - `double`. Явный `<double>` фиксирует тип, после чего обычные преобразования приводят аргументы к `double`

Тип переменной слева от `=` обычно остается за пределами deduction аргументов вызова:

```cpp
double value = larger(2, 5); // larger<int>, затем int -> double
```

Передача по значению копирует аргумент. У параметра `T` верхний `const` аргумента снимается, массив обычно преобразуется в указатель. Для чтения объекта без копирования подходит `const T&`

```cpp
template<class T>
void printValue(std::ostream &out, const T &value) {
  out << value;
}
```

Нужен `<ostream>`. Возврат по значению у `larger` создает самостоятельный результат. Возврат ссылки требует отдельной проверки lifetime исходных объектов

## Несколько параметров и тип результата

У каждого параметра шаблона собственный аргумент. Тип результата можно вывести через `auto`

```cpp
template<class Left, class Right>
auto add(Left left, Right right) {
  return left + right;
}

// Внутри функции:
auto result = add(2, 0.5); // double, 2.5
```

`auto` получает тип выражения `left + right` по обычным правилам языка. Для двух `int` результат остается `int`, поэтому допустимый диапазон арифметики остается частью контракта

Параметру шаблона можно задать значение по умолчанию:

```cpp
template<class T = double>
T zero() { return T{}; }

// Внутри функции:
auto a = zero();      // double
auto b = zero<int>(); // int
```

## Требования к операциям

Определение шаблона описывает операции над типом. `larger` требует доступного `<` и возможности вернуть значение. `printValue` требует выражения `out << value`

```cpp
struct Point { int x, y; };
// larger(Point{1, 2}, Point{3, 4}); // ошибка: у Point отсутствует operator<
```

Ошибки синтаксиса проверяются при чтении определения. Выражения, зависящие от параметров, дополнительно проверяются при подстановке конкретных типов. Constraints из главы 08 позволяют записать требования прямо в объявлении

## Обработка последовательности

Параметр типа может находиться внутри другого шаблонного типа. В этом примере `T` выводится из `std::vector<T>`

```cpp
template<class T>
std::size_t countValue(const std::vector<T> &values, const T &target) {
  std::size_t count = 0;
  for (const auto &value : values)
    if (value == target) count++;
  return count;
}
```

Нужны `<vector>` и `<cstddef>`. Пустая последовательность дает `0`. У элементов требуется сравнение на равенство

Для поиска результат может отсутствовать. `std::optional<T>` из `<optional>` хранит значение `T` или пустое состояние. `std::nullopt` обозначает пустое состояние

```cpp
template<class T>
std::optional<T> firstEqual(const std::vector<T> &values, const T &target) {
  for (const auto &value : values)
    if (value == target) return value;
  return std::nullopt;
}
```

```cpp
std::vector<int> values{3, 7, 3};
auto found = firstEqual(values, 7);
if (found) std::cout << *found << '\n';
```

`if (found)` проверяет наличие значения. `*found` обращается к значению после проверки. Возврат копии позволяет сохранить результат независимо от lifetime вектора

## Операция как параметр шаблона

Предикат - вызываемый объект, который отвечает на условие. Отдельный параметр типа позволяет передать такую операцию

```cpp
template<class T, class Predicate>
std::size_t countIf(const std::vector<T> &values, Predicate test) {
  std::size_t count = 0;
  for (const auto &value : values)
    if (test(value)) count++;
  return count;
}
```

```cpp
bool positive(int value) { return value > 0; }

// Внутри функции:
std::vector<int> values{-2, 0, 5};
auto count = countIf(values, positive); // 1
```

Тип `Predicate` здесь выводится как указатель на функцию. Через тот же механизм можно передать объект с `operator()`. Lambdas систематически рассматриваются в отдельной главе

## Шаблон и обычная перегрузка

Шаблонные и обычные функции могут иметь одно имя. Перегрузка выбирается по правилам главы 04. При одинаково хороших преобразованиях и прочих равных обычная функция имеет преимущество перед специализацией шаблона

```cpp
template<class T>
void show(const T &value) { std::cout << value << '\n'; }

inline void show(bool value) {
  std::cout << (value ? "yes" : "no") << '\n';
}
```

```cpp
show(42);         // шаблон, int
show(true);       // обычная перегрузка, yes
show<bool>(true); // явный выбор шаблона, 1 при обычных флагах cout
```

Нужен `<iostream>`. Обычная функция с другим типом параметра может проиграть шаблону из-за преобразований: при `show(42)` шаблон получает точное соответствие

Объявления перегрузок размещают до шаблона, из которого их вызывают. Для зависимых вызовов действуют правила поиска имен во время определения и инстанцирования. Такой порядок делает нужный набор перегрузок видимым в месте определения

## Определения в headers

Для обычного неявного инстанцирования определение шаблона должно быть доступно в translation unit, где требуется специализация. Размещение определения в header обеспечивает его доступность при подключении через `#include`

`larger.hpp`:

```cpp
#pragma once

template<class T>
T larger(T left, T right) {
  return left < right ? right : left;
}
```

`main.cpp`:

```cpp
#include "larger.hpp"
#include <iostream>

int main() {
  std::cout << larger(3, 7) << '\n';
}
```

Размещение только объявления в header и определения в отдельном `.cpp` часто дает ошибку линковки: нужная специализация отсутствует среди object files. Явное инстанцирование в `.cpp` позволяет управлять фиксированным набором типов, этот прием остается за рамками обязательной части

Одинаковые определения шаблонов допускаются в нескольких translation units при соблюдении ODR. Обычную функцию с телом в общем header объявляют `inline`, как перегрузку `show(bool)` выше. Здесь `inline` относится к правилам определений, фактическое встраивание вызова выбирает оптимизатор
