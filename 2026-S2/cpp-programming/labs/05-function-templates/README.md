# Лабораторная работа 5. Шаблоны функций

## Задание

Разработать программу для обработки суточных измерений метеостанции

Метеостанция каждые 30 минут фиксирует температуру воздуха, относительную влажность, атмосферное давление и скорость ветра

Исходные данные находятся в файле `weather_day.csv`. Первая строка содержит заголовок. Остальные строки содержат измерения за сутки:

```text
time,temperature,humidity,pressure,wind
00:00,18.7,74,1008.2,2.1
00:30,18.4,75,1008.5,2.4
01:00,18.1,77,1008.9,2.0
```

Поля имеют следующий смысл:

| Поле          | Значение                               | Рекомендуемый тип хранения |
| ------------- | -------------------------------------- | -------------------------- |
| `time`        | время измерения                        | `std::string`              |
| `temperature` | температура воздуха в градусах Цельсия | `double`                   |
| `humidity`    | относительная влажность в процентах    | `int`                      |
| `pressure`    | атмосферное давление в гектопаскалях   | `double`                   |
| `wind`        | скорость ветра в метрах в секунду      | `float`                    |

Формат строк можно считать корректным. Количество строк может быть меньше или больше 48

Для каждой числовой серии необходимо вычислить:

- минимальное значение
- максимальное значение
- размах значений
- количество значений, попадающих в нормальный диапазон
- первое значение вне нормального диапазона

Использовать следующие нормальные диапазоны:

| Серия       | Нижняя граница | Верхняя граница |
| ----------- | -------------- | --------------- |
| температура | 15.0           | 30.0            |
| влажность   | 40             | 80              |
| давление    | 990.0          | 1030.0          |
| ветер       | 0.0            | 12.0            |

Для каждой серии нужно сформировать очищенную версию данных. Значения ниже нижней границы заменяются на нижнюю границу. Значения выше верхней границы заменяются на верхнюю границу

Для каждой серии также нужно сформировать скорректированную версию данных:

| Серия       | Поправка |
| ----------- | -------- |
| температура | +0.2     |
| влажность   | -1       |
| давление    | +0.5     |
| ветер       | +0.1     |

Одинаковые операции над разными числовыми типами должны быть обобщены через шаблоны функций. Отдельные копии одной и той же логики для `int`, `float` и `double` писать нельзя

Программа должна использовать как обычный вывод template parameter из аргументов функции, так и хотя бы один вызов шаблонной функции с явным указанием template argument

В программе должна быть хотя бы одна перегрузка шаблонной функции для отдельного случая. Например, можно отдельно обработать вывод результата поиска аномального значения

Ожидаемый набор шаблонных функций:

| Имя функции       | Назначение                                     |
| ----------------- | ---------------------------------------------- |
| `minValue`        | найти минимальное значение серии               |
| `maxValue`        | найти максимальное значение серии              |
| `valueRange`      | вычислить размах значений                      |
| `isInRange`       | проверить попадание одного значения в диапазон |
| `countInRange`    | посчитать количество значений в диапазоне      |
| `firstOutOfRange` | найти первое значение вне диапазона            |
| `clampValue`      | ограничить одно значение границами диапазона   |
| `clampSeries`     | сформировать очищенную серию значений          |
| `applyCorrection` | сформировать серию значений с поправкой        |

Ожидаемый набор обычных функций:

| Имя функции         | Назначение                              |
| ------------------- | --------------------------------------- |
| `readWeatherData`   | прочитать файл измерений                |
| `printSeriesReport` | вывести отчет по одной числовой серии   |
| `printPreview`      | вывести первые несколько значений серии |

Полные сигнатуры функций определить самостоятельно. При необходимости можно добавить другие функции

После обработки файла программа должна вывести отчет:

- количество прочитанных измерений
- минимум, максимум и размах для каждой серии
- количество значений в нормальном диапазоне для каждой серии
- первое значение вне нормального диапазона для каждой серии или сообщение об отсутствии такого значения
- первые несколько значений очищенной версии каждой серии
- первые несколько значений скорректированной версии каждой серии

## Требования

- Названия переменных, функций, типов и других сущностей программы должны быть осмысленными и записываться на английском языке без транслитерации
- Программа должна читать данные из файла `weather_day.csv`
- Для хранения числовых серий должны использоваться разные числовые типы согласно таблице полей
- Общие операции над числовыми сериями должны быть реализованы через шаблоны функций из таблицы ожидаемых функций
- В программе должен быть пример вызова шаблонной функции с выводом template parameter из аргументов
- В программе должен быть пример вызова шаблонной функции с явным указанием template argument
- В программе должна быть хотя бы одна перегрузка шаблонной функции
- Дублировать одинаковую логику для разных числовых типов нельзя
- Программа должна быть грамотно разбита на модули и содержать как минимум один `.hpp` файл и два `.cpp` файла. Допускается использовать больше файлов
- Для заголовочных файлов использовать `#pragma once`
- Программа должна компилироваться и выполняться без ошибок
- Студент должен понимать написанный код, уметь обосновать свое решение и отвечать на вопросы во время защиты лабораторной работы

Минимальный набор функций:

- `maxValue`
- `valueRange`
- `isInRange`
- `countInRange`
- `firstOutOfRange`
- `clampValue`
- `clampSeries`
- `applyCorrection`
- `readWeatherData`
- `printSeriesReport`
- `printPreview`
