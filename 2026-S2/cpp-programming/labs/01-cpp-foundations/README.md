# Лабораторная работа 1. Основы C++ и модель компиляции

## Задание

Разработать программу для обработки данных сервиса проката электросамокатов

Исходные данные находятся в текстовом файле, каждая строка содержит:

```text
идентификатор модель заряд пробег неисправность
```

Например:

```text
SC001 NinebotG2 84 743.5 0
SC002 Xiaomi4Pro 18 312.7 0
SC003 NinebotF2 67 1642.1 0
SC004 Xiaomi4 91 428.3 1
```

Поле неисправности содержит `0`, если зарегистрированных неисправностей нет, и `1`, если неисправность есть

Для каждого самоката необходимо хранить:

- идентификатор
- модель
- заряд аккумулятора
- пробег
- наличие неисправности
- состояние

Данные одного самоката должны быть объединены в структуру. Типы полей подобрать самостоятельно

Для состояния использовать перечисление со следующими значениями:

```text
READY
CHARGE_REQUIRED
SERVICE_REQUIRED
```

Состояние определяется по правилам:

- если зарегистрирована неисправность -> `SERVICE_REQUIRED`
- если пробег не менее 1500 км -> `SERVICE_REQUIRED`
- если заряд меньше 30 процентов -> `CHARGE_REQUIRED`
- иначе -> `READY`

Порог заряда и пробега задать именованными константами

Определение состояния самоката вынести в отдельную функцию

Программа должна обработать весь входной файл и создать три файла:

```text
ready.txt
charge_required.txt
service_required.txt
```

Каждый самокат записывается в файл, соответствующий его состоянию

После обработки вывести:

- общее количество самокатов
- количество самокатов каждого состояния
- процент самокатов, готовых к аренде
- средний уровень заряда

Программа должна корректно обрабатывать невозможность открытия входного файла. Формат строк входного файла можно считать корректным

## Требования

- Названия переменных, функций, типов и других сущностей программы должны быть осмысленными и записываться на английском языке без транслитерации
- Программа должна быть грамотно разбита на модули и содержать как минимум один `.hpp` файл и два `.cpp` файла. Допускается использовать больше файлов
- Для заголовочных файлов использовать `#pragma once`
- Программа должна читать исходные данные из файла
- Программа должна формировать файлы `ready.txt`, `charge_required.txt` и `service_required.txt`
- Программа должна компилироваться и выполняться без ошибок
- Студент должен понимать написанный код, уметь обосновать свое решение и отвечать на вопросы во время защиты лабораторной работы

Минимальный набор функций:

- функция для определения состояния самоката по его характеристикам
- функция для чтения данных одного самоката из входного потока
- функция для записи данных самоката в выходной поток
- функция для вывода итоговой статистики обработки
