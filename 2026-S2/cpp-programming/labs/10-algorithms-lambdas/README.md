# Лабораторная работа 10. Алгоритмы и лямбды

## Задание

Разработать программу для поиска в медиатеке и составления списка просмотра. Пользователь хочет найти конкретное название, сравнить популярные релизы и получить короткую подборку по своим предпочтениям

Программа получает путь к файлу `titles.tsv` через аргумент командной строки. Результат сохранить в `watchlist.txt`

```bash
./watchlist titles.tsv
```

## Данные

Первая строка содержит имена полей. Каждая следующая строка описывает одно произведение. Разделитель - символ табуляции, пробелы и знаки препинания внутри названия являются частью поля

| Поле     | Содержание                                                |
| -------- | --------------------------------------------------------- |
| `id`     | Уникальный идентификатор IMDb                             |
| `title`  | Название для отображения                                  |
| `type`   | Тип записи IMDb, например `movie` или `tvSeries`          |
| `genres` | Жанры IMDb через запятую                                  |
| `tag`    | Дополнительная редакционная метка, поле может быть пустым |
| `year`   | Год выхода фильма или начала сериала                      |
| `rating` | Средневзвешенная оценка IMDb по шкале до 10               |
| `votes`  | Число пользовательских оценок                             |

Фрагмент каталога

```text
id	title	type	genres	tag	year	rating	votes
tt10919420	Squid Game	tvSeries	Action,Crime,Drama	Netflix	2021	7.9	783365
tt1825683	Black Panther	movie	Action,Adventure,Sci-Fi		2018	7.3	932996
```

Формат входных строк можно считать корректным. Рейтинг и число голосов зафиксированы на момент выгрузки. Для воспроизводимого отчета использовать значения из файла

## Отчет

1. Поиск. Вывести размер каталога. Найти запись с точным названием `Squid Game` и отдельно первую запись с оценкой от `8.5` и числом голосов от `100000`. Для каждого поиска вывести название, год и оценку. При отсутствии совпадения вывести сообщение
2. Два рейтинга. Построить топ-10 по числу голосов и отдельно топ-10 по оценке среди записей с числом голосов от `100000`. Основной показатель сортировать по убыванию, при равенстве использовать `id` по возрастанию. Для каждой позиции вывести название, оценку и число голосов
3. Счетчики. Вывести число полнометражных фильмов (`type == "movie"`) и число записей с годом выхода от `2020` и оценкой от `8.0`
4. Список просмотра. Задать в программе предпочтения пользователя отдельными переменными. Для проверки взять жанр `Drama`, начальный год `2020` и минимальную оценку `7.5`. Искать жанр среди отдельных значений поля `genres`. Включить записи, которые удовлетворяют всем трем условиям. Вывести размер выборки
5. Карточки. Из списка просмотра взять до десяти самых новых записей. При равенстве года первым идет меньший `id`. Преобразовать записи в объекты `Card` с полями `title`, `year` и `rating`, затем вывести карточки в порядке подборки

Для поиска первого совпадения использовать исходный порядок файла. Каждую сортировку выполнять в отдельной выборке или копии каталога. Если записей меньше заданного предела, вывести все доступные. Для пустой подборки вывести ее размер и пустой список карточек

## Требования

- Хранить каталог в коллекции объектов. Чтение, подготовку выборок и запись отчета оформить отдельными функциями
- Использовать `std::find_if` для поиска, `std::count_if` для подсчета, `std::sort` для рейтингов, `std::copy_if` для выборок и `std::transform` для карточек
- Условия отбора, правила сортировки и создание карточки выразить лямбдами. В предикате списка просмотра захватить переменные с предпочтениями
- Для чтения файла и вывода записей допустимы обычные циклы
- Обработать запуск без пути, ошибку открытия входного файла и ошибку записи отчета
- Разделить программу как минимум на один `.hpp` и два `.cpp` файла. Использовать `#pragma once` и осмысленные английские имена
