# Лабораторная работа 10. Algorithms и lambdas

## Задание

Разработать программу для формирования выборок из каталога кинофестиваля

Программа получает каталог фильмов, выполняет поиск, сортировку, подсчет, фильтрацию и преобразование записей для фестивальной программы

Путь к исходному файлу передается через аргумент командной строки

Пример запуска:

```text
./festival_catalog films.csv
```

Файл содержит каталог фильмов в CSV-формате. Первая строка содержит заголовок:

```text
title,country,year,genre,duration,age_rating,jury_score
The Silent Harbor,France,2022,Drama,104,16,8.7
Neon District,Japan,2024,Sci-Fi,118,12,9.1
Northern Lights,Canada,2021,Documentary,92,6,7.9
```

Поля имеют следующий смысл:

| Поле         | Значение                       |
| ------------ | ------------------------------ |
| `title`      | название фильма                |
| `country`    | страна                         |
| `year`       | год выпуска                    |
| `genre`      | жанр                           |
| `duration`   | длительность в минутах         |
| `age_rating` | возрастной рейтинг             |
| `jury_score` | оценка жюри от `0.0` до `10.0` |

Формат строк можно считать корректным. Каталог может содержать от 100 до 300 фильмов

Программа должна сформировать несколько фестивальных выборок:

- найти первый фильм с оценкой жюри не ниже `9.0`
- найти фильм с названием `Neon District`
- отсортировать копию каталога по оценке жюри по убыванию
- отсортировать копию каталога по году выпуска по возрастанию
- отсортировать копию каталога по длительности по возрастанию
- посчитать количество фильмов жанра `Documentary`
- посчитать количество фильмов с возрастным рейтингом не выше `12`
- выбрать фильмы для вечерней программы: длительность не больше 120 минут и оценка жюри не ниже `8.0`
- выбрать фильмы страны, заданной в программе отдельной переменной
- преобразовать полные записи фильмов в краткие записи расписания

Краткая запись расписания должна содержать:

- название фильма
- год
- жанр
- длительность
- оценку жюри

Операции над коллекциями должны быть выражены через standard algorithms. Ручные циклы допускаются для чтения файла и вывода результата. Для поиска, сортировки, подсчета, фильтрации и преобразования использовать algorithms

Lambdas должны использоваться как predicates, comparators и transformations. В программе должен быть пример lambda capture: например, страна для фильтрации задается переменной и захватывается в lambda

Программа должна сохранить итоговый отчет в файл `festival_program.txt`

Отчет должен содержать:

- количество фильмов в каталоге
- найденный фильм с оценкой не ниже `9.0` или сообщение об отсутствии такого фильма
- результат поиска фильма `Neon District`
- топ-10 фильмов по оценке жюри
- первые 10 фильмов после сортировки по году
- первые 10 фильмов после сортировки по длительности
- количество documentary-фильмов
- количество фильмов с возрастным рейтингом не выше `12`
- список фильмов вечерней программы
- список фильмов выбранной страны
- краткое расписание для первых 15 фильмов вечерней программы

Интерактивный CLI реализовывать не требуется. Достаточно обработать аргумент командной строки, прочитать файл и сформировать отчет

## Требования

- Названия переменных, функций, типов и других сущностей программы должны быть осмысленными и записываться на английском языке без транслитерации
- Программа должна читать путь к входному файлу из аргументов командной строки
- Программа должна обрабатывать запуск без аргумента командной строки
- Для хранения каталога фильмов должна использоваться коллекция объектов
- Для поиска использовать `std::find` или `std::find_if`
- Для сортировки использовать `std::sort`
- Для подсчета использовать `std::count` или `std::count_if`
- Для фильтрации использовать `std::copy_if`
- Для преобразования полной записи в краткую запись использовать `std::transform`
- Lambdas должны использоваться как predicate, comparator и transformation
- В программе должен быть пример lambda capture
- Одинаковые операции обработки коллекций нельзя реализовывать ручными циклами там, где естественно подходит standard algorithm
- Программа должна сохранять итоговый отчет в файл `festival_program.txt`
- Программа должна быть грамотно разбита на модули и содержать как минимум один `.hpp` файл и два `.cpp` файла. Допускается использовать больше файлов
- Для заголовочных файлов использовать `#pragma once`
- Программа должна компилироваться и выполняться без ошибок
- Студент должен понимать написанный код, уметь обосновать свое решение и отвечать на вопросы во время защиты лабораторной работы

Минимальный набор операций:

- чтение фильма из входного потока
- поиск фильма по условию
- сортировка фильмов по заданному критерию
- фильтрация фильмов по заданному predicate
- преобразование фильма в краткую запись расписания
- запись итогового отчета в выходной поток
