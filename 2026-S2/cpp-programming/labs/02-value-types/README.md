# Лабораторная работа 2. Классы и value types

## Задание

Разработать кассовую программу для работы с денежными суммами и небольшой корзиной товаров

Основная часть программы - пользовательский тип `Money`. Он должен хранить денежную сумму в минимальных денежных единицах, например в копейках. Использовать `double` как основное представление суммы нельзя

Денежная сумма должна поддерживать рубли и копейки. Объект `Money` должен всегда хранить корректное состояние: количество копеек внутри объекта не должно приводить к неоднозначному представлению одной и той же суммы

Программа работает с каталогом товаров. Для каждого товара необходимо хранить:

- название
- цену
- количество в корзине

Каталог товаров и корзину можно задать непосредственно в программе

Программа должна уметь:

- выводить цену товара в нормальном денежном формате
- считать стоимость позиции с учетом количества
- считать общую стоимость корзины
- применять скидку к общей стоимости
- сравнивать денежные суммы
- считать сдачу по внесенной покупателем сумме

Для скидки использовать целый процент. Если скидка составляет `15`, итоговая стоимость уменьшается на 15 процентов. Правило округления результата определить самостоятельно и применять одинаково во всей программе

Если внесенная покупателем сумма меньше итоговой стоимости покупки, программа должна вывести сообщение о недостаточной оплате

Тип `Money` должен вести себя как обычное значение. Объекты этого типа можно создавать, копировать, присваивать, складывать, вычитать, сравнивать и выводить в поток

Конструкторы должны обеспечивать корректное начальное состояние объекта. Некорректную сумму нельзя оставлять внутри объекта как допустимое состояние

Преобразование из числа в `Money` должно быть контролируемым. Случайные неявные преобразования из целых чисел в денежные суммы не должны происходить в выражениях программы. Класс `Money` должен предоставлять явное получение суммы в минимальных денежных единицах

После обработки корзины программа должна вывести:

- список товаров с ценой, количеством и стоимостью позиции
- общую стоимость без скидки
- размер скидки
- итоговую стоимость
- внесенную покупателем сумму
- сдачу или сообщение о недостаточной оплате

## Требования

- Названия переменных, функций, типов и других сущностей программы должны быть осмысленными и записываться на английском языке без транслитерации
- Для денежной суммы должен быть реализован отдельный класс `Money` с закрытым представлением данных
- Для `Money` должны быть реализованы конструкторы, операции сложения и вычитания, операции сравнения и вывод в поток
- Операции, которые не изменяют объект, должны быть доступны для константных объектов
- Программа должна демонстрировать контролируемое создание `Money` из числовых значений и явное получение числового значения из объекта `Money`
- Программа должна быть грамотно разбита на модули и содержать как минимум один `.hpp` файл и два `.cpp` файла. Допускается использовать больше файлов
- Для заголовочных файлов использовать `#pragma once`
- Программа должна компилироваться и выполняться без ошибок
- Студент должен понимать написанный код, уметь обосновать свое решение и отвечать на вопросы во время защиты лабораторной работы

Минимальный набор операций:

- создание денежной суммы из рублей и копеек
- расчет стоимости позиции корзины
- расчет итоговой стоимости корзины с учетом скидки
- расчет сдачи по внесенной покупателем сумме
