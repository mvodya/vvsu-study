# Лабораторная работа 12. Threads

## Задание

Разработать программу для поиска и статистики по коллекции электронных книг

Программа получает путь к каталогу книг через аргумент командной строки

Пример запуска:

```text
./book_analyzer books
```

Каталог содержит текстовые файлы с расширением `.txt`. Каждый файл считается отдельной книгой. Имя файла используется как название книги

Для каждой книги необходимо вычислить:

- количество строк
- количество слов
- количество байт в файле
- количество вхождений заданных слов
- длину самой длинной строки

Слова для поиска задать в программе отдельной коллекцией. Использовать не менее 5 слов

Словом считать непрерывную последовательность латинских букв `A-Z` и `a-z`. Остальные символы считать разделителями. При подсчете слова переводить в нижний регистр, поэтому `Book`, `book` и `BOOK` считаются одним словом. Апостроф, дефис, цифры и знаки пунктуации разделяют слова

Примеры разбиения текста на слова:

| Текст           | Слова              |
| --------------- | ------------------ |
| `Hello, world!` | `hello`, `world`   |
| `Don't stop`    | `don`, `t`, `stop` |
| `chapter-10`    | `chapter`          |
| `C++ and Java`  | `c`, `and`, `java` |

Для всей коллекции необходимо вычислить:

- общее количество книг
- общее количество строк
- общее количество слов
- общий объем файлов
- суммарное количество вхождений каждого заданного слова
- книгу с наибольшим количеством слов
- книгу с самой длинной строкой

Книги нужно распределить между несколькими worker threads. Каждый поток обрабатывает свою часть файлов и формирует локальную статистику. После завершения потоков локальные результаты объединяются в общий отчет

Количество worker threads задать в программе именованной константой или определить через количество доступных аппаратных потоков. Если книг меньше, чем потоков, лишние потоки создавать не требуется

Для многопоточной обработки использовать `std::thread` или `std::jthread`. Если используется `std::thread`, каждый созданный поток должен быть завершен через `join`

Основная многопоточная обработка не должна обновлять общий отчет одновременно из разных потоков. Общий результат формируется после завершения worker threads

Программа должна вывести:

- количество найденных книг
- список первых 10 книг
- итоговый отчет обработки коллекции
- статистику по первым 10 книгам
- количество созданных worker threads

Программа должна корректно обрабатывать:

- запуск без пути к каталогу
- невозможность прочитать каталог
- отсутствие `.txt` файлов в каталоге
- невозможность открыть отдельный файл

## Требования

- Названия переменных, функций, типов и других сущностей программы должны быть осмысленными и записываться на английском языке без транслитерации
- Программа должна читать путь к каталогу книг из аргументов командной строки
- Программа должна обрабатывать запуск без аргумента командной строки
- Программа должна искать в каталоге файлы с расширением `.txt`
- В программе должна быть многопоточная обработка коллекции книг с распределением файлов между worker threads
- В программе должны использоваться `std::thread` или `std::jthread`
- Для `std::thread` все созданные потоки должны завершаться через `join`
- Многопоточная обработка должна формировать локальные результаты потоков и объединять их после завершения потоков
- Программа должна быть грамотно разбита на модули и содержать как минимум один `.hpp` файл и два `.cpp` файла. Допускается использовать больше файлов
- Для заголовочных файлов использовать `#pragma once`
- Программа должна компилироваться и выполняться без ошибок
- Студент должен понимать написанный код, уметь обосновать свое решение и отвечать на вопросы во время защиты лабораторной работы

Минимальный набор операций:

- чтение списка `.txt` файлов из каталога
- подсчет статистики одной книги
- распределение книг между worker threads
- объединение локальных результатов потоков
- вывод итогового отчета обработки
