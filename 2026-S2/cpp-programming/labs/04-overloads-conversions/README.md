# Лабораторная работа 4. Перегрузка функций и преобразование типов

## Задание

Разработать программу для подготовки отчета по суточным измерениям метеостанции

Данные находятся в `weather_day.csv`. Первая строка содержит заголовок:

```text
time,temperature,humidity,pressure,wind
00:00,18.7,74,1008.2,2.1
00:30,18.4,75,1008.5,2.4
```

| Поле          | Смысл                        | Тип хранения  |
| ------------- | ---------------------------- | ------------- |
| `time`        | время измерения              | `std::string` |
| `temperature` | температура, градусы Цельсия | `double`      |
| `humidity`    | влажность, проценты          | `int`         |
| `pressure`    | давление, гПа                | `double`      |
| `wind`        | скорость ветра, м/с          | `float`       |

Формат строк считать корректным, значения - конечными и допустимыми для своих физических величин. Количество измерений может отличаться от 48. Пустой файл данных после заголовка должен давать сообщение об отсутствии измерений

Для каждой числовой серии вывести минимум, максимум и среднее. Среднее вычислять в вещественном типе, включая серию влажности. Операцию вывода одного значения реализовать перегрузками для `int`, `float` и `double`: целое выводить без дробной части, `float` - с одним знаком, `double` - с двумя знаками после точки. Использовать эти перегрузки при выводе исходных значений и границ серий

Для температуры создать отдельные типы значений в градусах Цельсия и Фаренгейта. Конструкторы из `double` должны быть `explicit`. Значение должно читаться через const метод. Одно общее имя функции преобразования должно принимать любой из этих двух типов и возвращать температуру в градусах Цельсия. Для аргумента в Цельсиях значение сохраняется

Преобразования единиц:

```text
F = C * 9.0 / 5.0 + 32.0
C = (F - 32.0) * 5.0 / 9.0
км/ч = м/с * 3.6
```

Для первых пяти измерений, либо всех при меньшем количестве, вывести температуру в обеих шкалах и скорость ветра в м/с и км/ч. На отдельном значении `68.0` градусов Фаренгейта показать получение `20.0` градусов Цельсия. Также вызвать перегрузку преобразования для значения в Цельсиях

Для одного измерения показать целую часть температуры через явное числовое преобразование. До него проверить, что температура входит в диапазон `int`. При выходе за диапазон вывести сообщение. Остальные расчеты должны сохранять дробную часть

## Требования

- Названия сущностей программы должны быть осмысленными и записываться на английском языке без транслитерации
- Соблюдать типы хранения из таблицы. Среднее целочисленной серии должно сохранять дробную часть
- Использовать обычные перегрузки вывода и преобразования температуры. Собственные шаблоны, наследование и virtual функции в этой работе не используются
- Использовать два типа температуры с `explicit` конструкторами и хотя бы одно проверенное преобразование через `static_cast`
- Минимальный набор операций: чтение измерений, расчет статистики серии, преобразование единиц и вывод отчета
- Разбить программу как минимум на один `.hpp` и два `.cpp` файла. Для headers использовать `#pragma once`
- Обработать ошибку открытия файла. Программа должна компилироваться и выполняться без ошибок
- Студент должен понимать код, обосновывать решение и отвечать на вопросы во время защиты
