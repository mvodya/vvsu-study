# Лабораторная работа 6. Шаблоны функций, классов и concepts

## Задание

Разработать универсальный двумерный контейнер `Grid<T>` и шаблонные функции для обработки карт автономного робота

Карты имеют размер `8` на `6` клеток. Координаты `x` и `y` начинаются с нуля

| Карта               | Тип клетки | Начальные данные                  |
| ------------------- | ---------- | --------------------------------- |
| препятствия         | `bool`     | не менее 8 занятых клеток         |
| расстояния          | `double`   | конечные неотрицательные значения |
| стоимость прохода   | `int`      | значения от 1 до 9                |
| вероятность проезда | `float`    | значения от 0 до 1                |

Подготовить данные непосредственно в программе. Для пустой карты определить допустимые размеры и поведение операций. Обращение по ошибочным координатам должно явно сообщать об ошибке

Сначала реализовать свободные шаблонные функции для проверки попадания значения в диапазон и ограничения значения границами диапазона. Применить их к `int`, `float` и `double`. Показать вывод параметра шаблона из аргументов и хотя бы один вызов с явным указанием типа

Затем создать `Grid<T>`, который хранит ширину, высоту и значения клеток. Контейнер должен позволять:

- запрашивать размеры, пустоту и допустимость координат
- читать и изменять клетку, заполнять всю карту одним значением
- выводить карту в поток
- считать клетки с заданным значением и находить первую такую клетку
- получать минимум, максимум и среднее числовой карты
- заменять значения ниже заданной границы

Общую логику обработки разных типов вынести в шаблоны. Для операций с диапазоном значений использовать ранее написанные свободные шаблонные функции

Операции поиска и подсчета должны быть ограничены требованием сравнения на равенство. Числовые операции должны быть ограничены числовыми типами, кроме `bool`. Ограничения выразить через concepts и `requires`. Для среднего использовать вещественный результат. Поведение минимума, максимума, среднего и поиска на пустой карте определить явно

Добавить обычную перегрузку шаблонной функции вывода значения для `bool`: занятая клетка печатается как `#`, свободная - как `.`. Использовать ее при выводе карты препятствий. Для других типов применяется общий шаблон вывода

Программа должна создать все четыре карты, изменить несколько клеток, вывести карты и статистику. Для карты препятствий вывести количество препятствий и координаты первого. Для вероятностей поднять значения ниже `0.25` до `0.25` и повторно вывести карту. Показать работу функций с выведенным и явно заданным типом

Definitions шаблонов должны быть доступны в headers. Дополнительно можно использовать `constexpr` и `if constexpr`, когда они соответствуют выбранным операциям

## Требования

- Названия сущностей программы должны быть осмысленными и записываться на английском языке без транслитерации
- Реализовать свободные function templates, class template `Grid<T>` и обычную перегрузку вывода для `bool`
- Создать `Grid<bool>`, `Grid<int>`, `Grid<float>` и `Grid<double>`. Общую логику реализовать один раз через шаблоны
- Ограничить операции сравнения и числовые операции через concepts и `requires`
- Показать вывод template argument из аргументов и явное указание template argument
- Минимальные группы операций: обработка диапазона значений, доступ к клеткам, поиск и статистика карты, вывод карты
- Разбить программу как минимум на один `.hpp` и два `.cpp` файла. Definitions шаблонов разместить в headers с `#pragma once`
- Программа должна компилироваться и выполняться без ошибок
- Студент должен понимать код, обосновывать решение и отвечать на вопросы во время защиты
