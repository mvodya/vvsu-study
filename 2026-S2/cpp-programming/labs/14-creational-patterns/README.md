# Лабораторная работа 14. Creational patterns

## Задание

Разработать программу для конфигурации персонального компьютера

Программа задает пользователю несколько вопросов с вариантами выбора, собирает конфигурацию ПК и выводит итоговый результат. После вывода результата программа завершается

Конфигурация должна включать обязательные компоненты:

- CPU
- motherboard
- RAM
- storage
- PSU

Конфигурация может включать необязательные компоненты:

- GPU
- cooling
- Wi-Fi adapter
- case fans

Каталог комплектующих задать в программе. Для каждой категории подготовить не менее трех вариантов

Для компонента необходимо хранить:

- название
- категорию
- цену
- потребляемую мощность
- набор характеристик, важных для совместимости

Программа должна задавать вопросы последовательно. Каждый вопрос показывает список вариантов и принимает номер выбранного варианта. Например:

```text
Choose CPU:
1. Intel Core i5-14400F
2. AMD Ryzen 5 7600
3. Intel Core i7-14700K
> 2
```

Обязательные вопросы:

- выбор CPU
- выбор motherboard
- выбор RAM
- выбор storage
- выбор PSU
- нужна ли отдельная GPU
- нужна ли дополнительная система охлаждения
- нужны ли дополнительные устройства

Для создания компонентов использовать Factory. Код, который обрабатывает ответы пользователя, не должен вручную заполнять все поля конкретных компонентов

Для сборки итоговой конфигурации использовать Builder. Builder должен пошагово принимать выбранные компоненты, проверять обязательные части и формировать готовую конфигурацию

Код программы разделить по ответственностям: каталог комплектующих, создание компонентов, сборка конфигурации, проверка совместимости и вывод отчета

После сборки программа должна проверить базовую совместимость:

- socket CPU должен совпадать с socket motherboard
- тип RAM должен поддерживаться motherboard
- суммарная потребляемая мощность должна быть меньше мощности PSU с запасом не менее 20 процентов
- если выбран мощный CPU, должна быть выбрана подходящая система охлаждения
- если выбранная motherboard не поддерживает Wi-Fi, Wi-Fi adapter должен быть отдельным компонентом

Если конфигурация несовместима, программа должна вывести список проблем. Если конфигурация корректна, программа должна вывести подтверждение совместимости

Итоговый отчет должен содержать:

- выбранные компоненты
- общую стоимость
- суммарную потребляемую мощность
- мощность PSU
- результат проверки совместимости
- список найденных проблем, если они есть

Ошибочный ввод номера варианта должен обрабатываться повторным запросом того же вопроса

## Требования

- Названия переменных, функций, типов и других сущностей программы должны быть осмысленными и записываться на английском языке без транслитерации
- Программа должна задавать вопросы с вариантами выбора и завершаться после вывода итоговой конфигурации
- Каталог комплектующих должен быть задан в программе
- Для каждой основной категории комплектующих должно быть не менее трех вариантов
- В программе должен быть Factory для создания компонентов по выбранному варианту
- В программе должен быть Builder для пошаговой сборки конфигурации ПК
- Builder должен проверять наличие обязательных компонентов перед созданием итоговой конфигурации
- В программе должны быть разделены ответственность за каталог, создание компонентов, сборку конфигурации и проверку совместимости
- Проверка совместимости должна учитывать socket CPU, тип RAM, мощность PSU, охлаждение и Wi-Fi
- Программа должна обрабатывать неверный номер варианта без аварийного завершения
- Программа должна быть грамотно разбита на модули и содержать как минимум один `.hpp` файл и два `.cpp` файла. Допускается использовать больше файлов
- Для заголовочных файлов использовать `#pragma once`
- Программа должна компилироваться и выполняться без ошибок
- Студент должен понимать написанный код, уметь обосновать свое решение и отвечать на вопросы во время защиты лабораторной работы

Минимальный набор операций:

- создание компонента через Factory
- добавление обязательного компонента в Builder
- добавление необязательного компонента в Builder
- проверка совместимости конфигурации
- формирование итогового отчета
