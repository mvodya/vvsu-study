# Основные алгоритмы

## Линейный поиск

При линейном поиске элементы проверяют по порядку, например когда ищут первую доску, длины которой хватит для полки

```python
def first_fit(lengths, required):
    for index, length in enumerate(lengths):
        if length >= required:
            return index
    return None


boards = [80, 120, 95, 140]
print(first_fit(boards, 100)) # 1
print(first_fit(boards, 150)) # None
```

Если нужен индекс последней подходящей доски, перед циклом задают `last = None`, при каждом совпадении записывают `last = index` и возвращают результат после обхода

В том же цикле можно посчитать подходящие доски, прибавляя единицу к счетчику при каждом совпадении

Для полки длиной `100` подходят две доски, последняя имеет индекс `3`

Для списка из `n` элементов в худшем случае потребуется `n` проверок, поэтому у линейного поиска сложность по времени `O(n)`

Обращение к элементу списка по известному индексу занимает постоянное время - `O(1)`

Так же оценивают дополнительную память, если для обхода списка любой длины достаточно фиксированного числа индексов и счетчиков

## Минимум и максимум за один проход

В непустом списке за начальный максимум берут первый элемент и обновляют максимум всякий раз, когда встречают большее значение

```python
temperatures = [-8, -3, -6, -3]
warmest = temperatures[0]
warmest_index = 0

for index in range(1, len(temperatures)):
    if temperatures[index] > warmest:
        warmest = temperatures[index]
        warmest_index = index

print(warmest, warmest_index) # -3 1
```

При строгом сравнении `>` сохраняется индекс первого максимума

Если заменить `>` на `>=`, индекс обновится и при равенстве, поэтому для тех же температур результатом будет индекс `3`

Для поиска минимума достаточно заменить `>` на `<`

Если нужны оба экстремума, за одну итерацию сравнивают новый элемент и с текущим минимумом, и с текущим максимумом

Если на вход может прийти пустой список, этот случай обрабатывают до обращения к элементу с индексом `0`

## Соседние элементы и серии

В строке `"AABAAA"` три серии одинаковых букв подряд - `AA`, `B` и `AAA`

У первого символа длина текущей серии равна единице

Начиная с индекса `1` сравнивают соседние символы `text[index - 1]` и `text[index]`

При совпадении длина увеличивается на единицу, при смене буквы начинается серия длины `1`

| Индекс | Буква | Длина текущей серии | Наибольшая длина с начала строки |
| -----: | :---: | ------------------: | -------------------------------: |
|      0 |   A   |                   1 |                                1 |
|      1 |   A   |                   2 |                                2 |
|      2 |   B   |                   1 |                                2 |
|      3 |   A   |                   1 |                                2 |
|      4 |   A   |                   2 |                                2 |
|      5 |   A   |                   3 |                                3 |

Сравнение длин на каждом шаге позволяет учесть серию, которая доходит до конца строки

В примере последняя серия имеет длину `3` и заканчивается на индексе `5`, поэтому индекс ее начала равен `5 - 3 + 1 = 3`

## Сортировка выбором

При сортировке выбором на каждую позицию слева направо ставят наименьший элемент из оставшейся части списка

Если текущая позиция `i`, а минимум найден на позиции `j`, элементы можно поменять местами одним присваиванием `values[i], values[j] = values[j], values[i]`

| Позиция | Элементы, среди которых ищем минимум | Действие                 | Весь список после шага |
| ------: | ------------------------------------ | ------------------------ | ---------------------- |
|       0 | `[6, 4, 2, 5]`                       | Меняем местами `6` и `2` | `[2, 4, 6, 5]`         |
|       1 | `[4, 6, 5]`                          | Оставляем `4` на месте   | `[2, 4, 6, 5]`         |
|       2 | `[6, 5]`                             | Меняем местами `6` и `5` | `[2, 4, 5, 6]`         |

В примере поиск минимума потребовал `3 + 2 + 1 = 6` сравнений, а для перестановки элементов хватило двух обменов

Для списка длины `n` на первом шаге нужно `n - 1` сравнений, затем `n - 2` и так до одного

У сортировки выбором квадратичная сложность по времени - `O(n^2)`, поэтому при удвоении длины большого списка сравнений станет примерно в четыре раза больше

## Сортировка средствами Python

Функция `sorted()` возвращает новый отсортированный список

Параметр `key` принимает функцию, которая по элементу вычисляет значение для сравнения, например число страниц для каждой книги

```python
def page_count(book):
    title, pages = book
    return pages


books = [("Атлас", 80), ("Письма", 48), ("Сказки", 80)]
by_size = sorted(books, key=page_count)
print(by_size) # [('Письма', 48), ('Атлас', 80), ('Сказки', 80)]
```

Сортировка вызывает `page_count` для каждой книги и сохраняет исходный порядок записей с равными ключами, поэтому "Атлас" остается перед "Сказками"

Метод списка `sort()` упорядочивает сам список и возвращает `None`

Обеим операциям можно передать `reverse=True` для сортировки по убыванию, например `books.sort(key=page_count, reverse=True)`

## Бинарный поиск

Бинарный поиск позволяет найти число в списке, заранее отсортированном по возрастанию

Границы `left` и `right` задают первую и последнюю позиции, на которых еще может находиться искомое число

В начале поиск охватывает весь список, поэтому `left = 0` и `right = len(values) - 1`

Пока `left <= right`, выбирают средний индекс `middle = (left + right) // 2` и сравнивают `values[middle]` с искомым числом

- При равенстве возвращают `middle` (при повторах это индекс одного из вхождений)
- Если значение в середине меньше искомого, поиск продолжают справа с `left = middle + 1`
- Если значение больше искомого, поиск продолжают слева с `right = middle - 1`

Проследим поиск числа `22` в списке `[7, 12, 18, 24, 31, 45]`

| `left` | `right` | `middle` | Значение в середине | Следующий шаг |
| -----: | ------: | -------: | ------------------: | ------------- |
|      0 |       5 |        2 |                  18 | `left = 3`    |
|      3 |       5 |        4 |                  31 | `right = 3`   |
|      3 |       3 |        3 |                  24 | `right = 2`   |

Когда `left > right`, диапазон пуст и искомое число отсутствует

После каждой неудачной проверки в диапазоне остается максимум половина элементов, поэтому даже для `1000` чисел хватит десяти проверок середины

При удвоении длины списка достаточно одной дополнительной проверки, поэтому у бинарного поиска логарифмическая сложность по времени - `O(log n)`

## Математические функции

Модуль `math` входит в стандартную библиотеку Python и содержит математические функции

Инструкция `import math` подключает модуль, после чего к его функциям обращаются через имя модуля и точку

Функция `math.log10(x)` возвращает десятичный логарифм положительного числа `x`, результат имеет тип `float` [Документация Python](https://docs.python.org/3/library/math.html#math.log10)

```python
import math

print(math.log10(1000)) # 3.0
print(math.log10(1))    # 0.0
```
