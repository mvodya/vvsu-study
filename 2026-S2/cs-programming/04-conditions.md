# Условия в Python

## Операторы сравнения

Сравнение возвращает логическое значение `True` или `False`

| Оператор | Проверка                                 |
| -------- | ---------------------------------------- |
| `==`     | Значения равны                           |
| `!=`     | Значения не равны                        |
| `<`      | Первое значение меньше второго           |
| `>`      | Первое значение больше второго           |
| `<=`     | Первое значение меньше или равно второму |
| `>=`     | Первое значение больше или равно второму |

Оператор присваивания `=` изменяет значение переменной, оператор сравнения `==` проверяет равенство

Python позволяет объединить две границы диапазона в одно сравнение

```python
value = 15

print(10 <= value <= 20) # True
```

Строки сравниваются посимвольно с учетом регистра

```python
print("Python" == "python") # False
```

## Истинность значений

В условии можно использовать значение не только типа `bool`. Его истинность определяется по тем же правилам, что и результат `bool()`

Среди значений типов `bool`, `int`, `float` и `str` ложными считаются `False`, числовой ноль и пустая строка. Остальные значения этих типов считаются истинными

```python
print(bool(0))        # False
print(bool(0.0))      # False
print(bool(""))       # False
print(bool(12))       # True
print(bool("Python")) # True
```

## Условие if

Конструкция `if` выполняет блок кода, когда значение условия считается истинным

```python
number = int(input())

if number < 0:
    print("Отрицательное число")
```

После условия ставится `:`, а инструкции блока записываются с одинаковым отступом. В Python принято использовать четыре пробела

Если значение условия считается ложным, блок пропускается

## Ветвление if-else

Блок `else` выполняется, когда условие `if` считается ложным

```python
number = int(input())

if number % 2 == 0:
    print("Четное")
else:
    print("Нечетное")
```

В одной конструкции выполняется только одна из двух ветвей

## Несколько вариантов

Конструкция `elif` добавляет следующую проверку, если предыдущие условия оказались ложными

```python
file_size = int(input())

if file_size < 0:
    print("Некорректный размер")
elif file_size == 0:
    print("Пустой файл")
elif file_size < 1024:
    print("Маленький файл")
else:
    print("Большой файл")
```

Условия проверяются сверху вниз. После выполнения первой подходящей ветви остальные ветви этой конструкции пропускаются

Порядок важен, если диапазоны пересекаются

```python
score = 92

if score >= 90:
    grade = 5
elif score >= 75:
    grade = 4
elif score >= 60:
    grade = 3
else:
    grade = 2
```

Проверка начинается с наиболее строгой нижней границы, поэтому значение `92` не попадет в ветвь `score >= 75`

## Логические операции

Операции `and`, `or` и `not` позволяют объединять и изменять условия

| Операция  | Результат                                           |
| --------- | --------------------------------------------------- |
| `a and b` | `a`, если оно ложное, иначе `b`                     |
| `a or b`  | `a`, если оно истинное, иначе `b`                   |
| `not a`   | Логическое значение, противоположное истинности `a` |

Если оба операнда имеют тип `bool`, `and` и `or` работают как обычные логические операции

```python
print(True and False) # False
print(True or False)  # True
```

```python
name = ""
display_name = name or "Неизвестный пользователь"

print(display_name) # Неизвестный пользователь
```

```python
age = 19
has_document = True

if age >= 18 and has_document:
    print("Доступ разрешен")
```

```python
day = "Saturday"

if day == "Saturday" or day == "Sunday":
    print("Выходной")
```

```python
is_blocked = False

if not is_blocked:
    print("Учетная запись активна")
```

Приоритет операций

1. Сравнения
2. `not`
3. `and`
4. `or`

Скобки позволяют явно показать требуемый порядок

```python
is_admin = True
is_moderator = False
is_blocked = False

if (is_admin or is_moderator) and not is_blocked:
    print("Доступ к панели разрешен")
```

## Короткое вычисление

Python прекращает вычисление логического выражения, когда результат уже известен

В выражении с `and` правая часть не вычисляется, если левая часть считается ложной

```python
divider = 0

if divider != 0 and 100 / divider > 5:
    print("Условие выполнено")
```

В выражении с `or` правая часть не вычисляется, если левая часть считается истинной

## Вложенные условия

Внутри одной ветви можно записать другую условную конструкцию

```python
role = input()
is_active = input() == "yes"

if is_active:
    if role == "admin":
        print("Полный доступ")
    else:
        print("Обычный доступ")
else:
    print("Доступ закрыт")
```

Вложенность полезна, когда вторую проверку имеет смысл выполнять только после первой. Если условия равноправны, выражение с `and` обычно короче и понятнее

## Проверка входных данных

До основного вычисления нужно проверить ограничения, указанные в задаче

```python
month = int(input())

if month < 1 or month > 12:
    print("Некорректный номер месяца")
else:
    print("Номер месяца принят")
```

## Условное выражение (тернарный оператор)

Python позволяет выбрать одно из двух значений внутри выражения

```python
number = int(input())
kind = "положительное" if number > 0 else "неположительное"

print(kind)
```

Условное выражение подходит для короткого выбора значения. Для нескольких действий или сложных проверок следует использовать обычный `if`
