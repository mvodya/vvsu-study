# Списки и таблицы в Python

## Создание списка

Список имеет тип `list` и хранит упорядоченную последовательность элементов. Его записывают в квадратных скобках, разделяя элементы запятыми

```python
colors = ["red", "green", "blue"]
measurements = [12.5, 11.8, 13.0]
empty = []

print(colors) # ['red', 'green', 'blue']
```

Элементы могут иметь разные типы. При обработке однотипных данных удобно хранить в списке значения одного типа

Функция `list()` создает список из перебираемого объекта

```python
letters = list("cat")
numbers = list(range(2, 8, 2))

print(letters) # ['c', 'a', 't']
print(numbers) # [2, 4, 6]
```

## Доступ к элементам

Индексы и срезы записываются по тем же правилам, что и для строк. `len()` возвращает количество элементов

```python
colors = ["red", "green", "blue"]

print(colors[0])  # red
print(colors[-1]) # blue
print(colors[1:]) # ['green', 'blue']
print(len(colors)) # 3
```

Обращение к элементу по индексу за пределами списка вызывает `IndexError`

Операторы `in` и `not in` проверяют наличие и отсутствие элемента

```python
colors = ["red", "green", "blue"]

print("green" in colors)  # True
print("yellow" in colors) # False
```

В условии пустой список считается ложным, список с элементами - истинным

## Изменение списка

Присваивание по индексу заменяет элемент

```python
colors = ["red", "green", "blue"]
colors[1] = "yellow"

print(colors) # ['red', 'yellow', 'blue']
```

Основные методы изменения

| Метод                  | Действие                                            |
| ---------------------- | --------------------------------------------------- |
| `append(value)`        | Добавляет один элемент в конец                      |
| `extend(values)`       | Добавляет элементы из перебираемого объекта в конец |
| `insert(index, value)` | Вставляет элемент перед указанной позицией          |
| `remove(value)`        | Удаляет первое вхождение значения                   |
| `pop(index)`           | Удаляет и возвращает элемент по индексу             |
| `clear()`              | Удаляет все элементы                                |
| `reverse()`            | Меняет порядок элементов на обратный                |

У `pop()` индекс можно опустить, тогда удаляется последний элемент. Для пустого списка вызов `pop()` вызывает `IndexError`. При отсутствии указанного значения `remove()` вызывает `ValueError`

```python
colors = ["red"]
colors.append("green")
colors.extend(["blue", "white"])
last_color = colors.pop()

print(colors)     # ['red', 'green', 'blue']
print(last_color) # white
```

Методы `append()`, `extend()`, `insert()`, `remove()`, `clear()` и `reverse()` изменяют список и возвращают `None` - специальное значение, обозначающее отсутствие результата

Для удаления элемента или среза также используется инструкция `del`

```python
numbers = [10, 20, 30, 40]
del numbers[1:3]

print(numbers) # [10, 40]
```

## Поиск и подсчет

Метод `index(value)` возвращает индекс первого вхождения элемента. Если элемент отсутствует, возникает `ValueError`

Метод `count(value)` возвращает количество элементов, равных указанному значению

```python
codes = [12, 7, 12, 4]

print(codes.index(12)) # 0
print(codes.count(12)) # 2
print(codes.count(9))  # 0
```

## Обход значений и индексов

В цикле `for` переменная получает очередной элемент списка

```python
colors = ["red", "green"]

for color in colors:
    print(color.upper())
```

Результат

```text
RED
GREEN
```

Для изменения элементов по их позициям можно перебирать индексы через `range(len(...))`

```python
prices = [100, 200, 300]

for index in range(len(prices)):
    prices[index] = prices[index] + 10

print(prices) # [110, 210, 310]
```

Функция `enumerate()` при обходе выдает пары из номера и элемента. Их можно распаковать в две переменные в заголовке цикла. Начальный номер задается параметром `start`, по умолчанию он равен `0`

```python
colors = ["red", "green"]

for number, color in enumerate(colors, start=1):
    print(number, color)
```

Результат

```text
1 red
2 green
```

Добавление и удаление элементов во время обхода меняет их позиции и может привести к пропускам или повторной обработке. Для отбора элементов удобно создавать отдельный список

## Списковые включения

Списковое включение создает список по выражению и перебираемым значениям

```python
numbers = [2, 5, 8]
doubled = [number * 2 for number in numbers]

print(doubled) # [4, 10, 16]
```

После перебора можно добавить условие отбора

```python
names = ["Anna", "Bo", "Alex"]
long_names = [name for name in names if len(name) >= 4]

print(long_names) # ['Anna', 'Alex']
```

Для каждого элемента сначала проверяется условие. При истинном результате вычисляется выражение и его значение добавляется в новый список

## Ввод списка чисел

Если числа вводятся одной строкой через пробелы, результат `split()` можно преобразовать списковым включением

```python
numbers = [int(part) for part in input().split()]
print(numbers)
```

Для ввода `7 -2 0` результат равен `[7, -2, 0]`

Для чтения заданного количества строк используется накопление через `append()`

```python
count = int(input())
words = []

for index in range(count):
    words.append(input())

print(words)
```

Для ввода

```text
2
north
south
```

результат равен `['north', 'south']`

## Копирование списка

При присваивании списка другой переменной оба имени ссылаются на один объект

```python
original = [10, 20]
alias = original
alias[0] = 99

print(original) # [99, 20]
```

Метод `copy()` создает отдельный список с теми же элементами. Полный срез `[:]` также создает такую копию

```python
original = [10, 20]
copy = original.copy()
copy[0] = 99

print(original) # [10, 20]
print(copy)     # [99, 20]
```

## Кортежи

Кортеж имеет тип `tuple` и хранит упорядоченную последовательность с фиксированным набором элементов. Присваивание по индексу и удаление элементов кортежа вызывают `TypeError`

Кортеж создается перечислением значений через запятую. Круглые скобки помогают выделить его границы в выражении

```python
point = (3, 7)
single = (5,)
empty = ()

x, y = point

print(x)         # 3
print(y)         # 7
print(single[0]) # 5
```

В кортеже из одного элемента после значения ставится запятая

Для кортежей доступны индексы, срезы, `len()`, `in`, `count()` и `index()`. Функция `tuple()` создает кортеж из перебираемого объекта

Если элементом кортежа является список, содержимое этого списка можно изменять

```python
record = ("sensor", [10, 20])
record[1].append(30)

print(record) # ('sensor', [10, 20, 30])
```

## Двумерные таблицы

Прямоугольную таблицу удобно хранить как список строк одинаковой длины. Каждая строка также является списком

```python
table = [[2, 4, 6], [1, 3, 5]]

print(table[1])    # [1, 3, 5]
print(table[1][2]) # 5
```

В записи `table[row][column]` сначала выбирается строка, затем элемент этой строки

Количество строк равно `len(table)`. Для таблицы с хотя бы одной строкой количество столбцов равно `len(table[0])`

Ячейку можно изменить присваиванием

```python
table = [[2, 4, 6], [1, 3, 5]]
table[0][1] = 9

print(table) # [[2, 9, 6], [1, 3, 5]]
```

## Создание и копирование строк таблицы

Оператор `*` повторяет элементы списка. Например, `[0] * 3` создает список из трех нулей

Для создания таблицы каждая строка формируется отдельно

```python
row_count = 2
column_count = 3
table = [[0] * column_count for row in range(row_count)]
table[0][0] = 1

print(table) # [[1, 0, 0], [0, 0, 0]]
```

При повторении вложенного списка через `*` получаются ссылки на одну строку: в записи `[[0] * 3] * 2` изменение ячейки одной строки будет видно в обеих

Копирование через `copy()` и срез является поверхностным: вложенные объекты сохраняют общие ссылки. Для независимого изменения ячеек числовой таблицы нужно копировать каждую строку

```python
table = [[2, 4], [6, 8]]
copy = [row.copy() for row in table]
copy[0][0] = 99

print(table) # [[2, 4], [6, 8]]
print(copy)  # [[99, 4], [6, 8]]
```

## Обход таблицы

Внешний цикл перебирает строки, внутренний - элементы выбранной строки

```python
table = [[2, 4], [6, 8]]

for row in table:
    for value in row:
        print(value)
```

Результат

```text
2
4
6
8
```

Для обращения к ячейкам по координатам используются два индекса

```python
table = [[2, 4], [6, 8]]

for row in range(len(table)):
    for column in range(len(table[row])):
        table[row][column] += 1

print(table) # [[3, 5], [7, 9]]
```

Столбец с индексом `column` состоит из элементов `table[row][column]` при переборе строк. Для выбора прямоугольной области задают отдельные диапазоны индексов строк и столбцов
