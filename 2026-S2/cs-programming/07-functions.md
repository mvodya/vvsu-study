# Функции в Python

## Определение и вызов

Функция объединяет инструкции под одним именем. Ее определение начинается с `def`, за которым следуют имя, круглые скобки и двоеточие. Тело функции записывается с отступом

```python
def show_title():
    print("Каталог книг")

show_title()
```

Результат

```text
Каталог книг
```

Инструкция `def` создает функцию. Ее тело выполняется при вызове: после имени записываются круглые скобки

Определение должно быть выполнено до вызова функции. Имена функций принято записывать в стиле `snake_case`

## Параметры и аргументы

Параметры перечисляются в определении функции и получают значения при вызове. Передаваемые значения называются аргументами

```python
def show_label(name, number):
    print(f"{name}: {number}")

show_label("Полка", 3)
show_label("Шкаф", 8)
```

Результат

```text
Полка: 3
Шкаф: 8
```

При позиционной передаче аргументы сопоставляются с параметрами слева направо. Именованные аргументы указывают имя параметра явно

```python
def show_label(name, number):
    print(f"{name}: {number}")

show_label(number=5, name="Полка") # Полка: 5
```

Позиционные аргументы записываются перед именованными. Каждый параметр получает значение один раз. Отсутствие обязательного аргумента, лишний аргумент или неизвестное имя параметра вызывает `TypeError`

## Возвращаемый результат

Инструкция `return` завершает вызов функции и передает значение вызывающему коду. Результат можно сохранить в переменной, передать другой функции или использовать в выражении

```python
def rectangle_area(width, height):
    return width * height

area = rectangle_area(4, 6)
print(area) # 24
print(rectangle_area(2, 3) + 1) # 7
```

Если выполнение дошло до конца тела или встретился `return` без значения, результатом вызова будет `None`

```python
def show_message(message):
    print(message)

result = show_message("Готово")
print(result)
```

Результат

```text
Готово
None
```

Проверить этот результат можно выражением `result is None`

### Ранний возврат

В функции может быть несколько инструкций `return`. Выполнение завершается на первой достигнутой инструкции возврата

```python
def describe_text(text):
    if text == "":
        return "Пустая строка"
    return f"Символов: {len(text)}"

print(describe_text(""))    # Пустая строка
print(describe_text("cat")) # Символов: 3
```

`return` внутри цикла завершает весь вызов функции

### Несколько значений

Несколько значений можно вернуть кортежем и распаковать при вызове. Порядок элементов задается в `return`

```python
def swap_pair(left, right):
    return right, left

first, second = swap_pair("A", "B")
print(first, second) # B A
```

## Значения по умолчанию

Параметру можно задать значение через `=` в определении функции. Оно используется при вызове с пропущенным аргументом

```python
def wrap_text(text, left="[", right="]"):
    return left + text + right

print(wrap_text("note"))                 # [note]
print(wrap_text("note", "(", ")"))       # (note)
print(wrap_text("note", right="!"))      # [note!
```

В такой записи обязательные параметры располагаются перед параметрами со значениями по умолчанию

Значения по умолчанию вычисляются при выполнении `def`. Для изменяемых объектов, например списков, один объект будет использоваться всеми вызовами с пропущенным аргументом

## Локальные имена и передача данных

Параметры и переменные, которым присваиваются значения внутри функции, являются локальными для ее вызова. При каждом вызове создаются новые локальные имена

```python
def add_fee(amount):
    amount += 10
    return amount

amount = 100
updated_amount = add_fee(amount)

print(amount)         # 100
print(updated_amount) # 110
```

Аргумент передает ссылку на объект. Изменение переданного списка через его методы или присваивание по индексу будет видно вызывающему коду

```python
def append_marker(items):
    items.append("done")

labels = ["new"]
append_marker(labels)
print(labels) # ['new', 'done']
```

Имена, определенные на уровне файла, являются глобальными для этого модуля. Функция может читать такое имя, если оно доступно к моменту обращения и не перекрыто локальным именем

Данные, необходимые функции для работы, удобно передавать через параметры. Обновленные значения возвращаются вызывающему коду

## Функции-предикаты

Предикат - функция, которая возвращает `True` или `False`. Его результат можно использовать в условии, логическом выражении или другой функции

```python
def is_markdown(filename):
    return filename.endswith(".md")

print(is_markdown("notes.md"))  # True
print(is_markdown("photo.png")) # False
```

Имена предикатов часто начинаются с `is_`, `has_` или `can_` и описывают проверяемое свойство

## Контракт функции

Контракт описывает, какие данные принимает функция и какой результат она обещает вернуть

Для функции нужно определить типы и допустимые значения аргументов, тип и смысл результата, поведение на граничных значениях и возможное изменение переданных объектов

Например, контракт `make_label(name, number)` может задавать следующие условия: `name` - непустая строка, `number` - положительное целое число, результат - строка вида `Полка: 5`

Если проверка входных данных вынесена в отдельную функцию, вызывающий код должен выполнить ее до передачи данных в вычисления с соответствующими ограничениями

## Декомпозиция и main

При декомпозиции каждой функции поручают одну законченную операцию: проверку, вычисление или формирование текста. Функции могут вызывать друг друга

Функция `main()` организует работу программы: получает исходные данные, вызывает обработку и выводит результат. Ее имя является соглашением; запуск выполняется явным вызовом

```python
def repeat_text(text, count):
    return text * count


def make_banner(text, width):
    border = repeat_text("=", width)
    return f"{border}\n{text}\n{border}"


def main():
    text = input()
    banner = make_banner(text, len(text))
    print(banner)


main()
```

Для ввода `HELLO` программа выведет

```text
=====
HELLO
=====
```

В этой структуре ввод и вывод сосредоточены в `main()`. Функции обработки получают аргументы и возвращают результаты, поэтому их можно отдельно вызывать с разными данными для проверки
