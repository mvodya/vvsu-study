# Основы Python

## Программа и интерпретатор

Программа на Python представляет собой последовательность инструкций. Интерпретатор читает их сверху вниз и выполняет по очереди

Файл с исходным кодом Python обычно имеет расширение `.py`. Запустить файл из терминала можно командой:

```bash
python main.py
```

В некоторых системах команда называется `python3`:

```bash
python3 main.py
```

Регистр символов имеет значение: `name`, `Name` и `NAME` являются разными именами

Однострочный комментарий начинается с `#`. Интерпретатор не выполняет текст комментария

```python
# Температура воздуха в градусах Цельсия
temperature = 23.5
```

## Значения и типы данных

У каждого значения есть тип, который определяет допустимые операции над ним

| Тип     | Примеры                  | Назначение          |
| ------- | ------------------------ | ------------------- |
| `int`   | `42`, `0`, `-7`          | Целые числа         |
| `float` | `3.14`, `-0.5`           | Вещественные числа  |
| `str`   | `"Python"`, `'БИС-26-1'` | Текст               |
| `bool`  | `True`, `False`          | Логические значения |

Функция `type()` возвращает тип значения:

```python
print(type(42))       # <class 'int'>
print(type(3.14))     # <class 'float'>
print(type("Python")) # <class 'str'>
print(type(True))     # <class 'bool'>
```

В Python тип принадлежит значению, а переменная связывает имя с этим значением. Тип не указывается при создании переменной и может измениться после нового присваивания

```python
result = 10
result = 2.5
```

Такое поведение называется динамической типизацией. Без необходимости менять назначение переменной и тип хранимого значения не следует

## Переменные

Оператор `=` связывает имя переменной со значением справа

```python
student_count = 28
average_score = 4.35
group_name = "БИС-26-1"
is_active = True
```

Имя переменной может содержать латинские буквы, цифры и `_`, но не может начинаться с цифры. В Python составные имена принято записывать в стиле `snake_case`:

```python
lesson_count = 15
ticket_price = 1250.0
```

Имена `lc`, `x1` и `data2` синтаксически допустимы, но обычно хуже передают назначение значения

Некоторые слова зарезервированы самим языком. Например, нельзя использовать `if`, `for`, `True` или `class` как имена переменных

## Вывод данных

Функция `print()` выводит значения в консоль

```python
course_name = "Информатика"
lesson_count = 15

print(course_name)
print("Количество пар:", lesson_count)
```

Несколько аргументов `print()` по умолчанию разделяются пробелом:

```python
day = 12
month = 9
year = 2026

print(day, month, year) # 12 9 2026
```

Параметр `sep` задает другой разделитель:

```python
print(day, month, year, sep=".") # 12.9.2026
```

## F-строки

F-строка позволяет вставить значение выражения внутрь текста. Перед открывающей кавычкой ставится `f`, а выражение записывается в фигурных скобках

```python
product = "Клавиатура"
price = 2490

print(f"Товар: {product}, цена: {price} руб")
```

После `:` можно указать формат числа. Запись `.2f` оставляет две цифры после десятичной точки:

```python
weight = 7 / 3
print(f"Масса: {weight:.2f} кг") # Масса: 2.33 кг
```

Запись `02d` выводит целое число минимум двумя цифрами и добавляет ведущий ноль при необходимости:

```python
hours = 8
minutes = 5
print(f"{hours:02d}:{minutes:02d}") # 08:05
```

Форматирование меняет только представление числа в строке, но не само значение переменной

## Ввод данных

Функция `input()` читает одну строку из консоли

```python
name = input()
print(f"Студент: {name}")
```

В `input()` можно передать приглашение к вводу:

```python
name = input("Введите имя: ")
```

Результат `input()` всегда имеет тип `str`, даже если пользователь ввел цифры

```python
value = input()
print(type(value)) # <class 'str'>
```

Для вычислений строку нужно преобразовать в числовой тип:

```python
student_count = int(input())
temperature = float(input())
```

| Функция        | Результат           | Пример                    |
| -------------- | ------------------- | ------------------------- |
| `int(value)`   | Целое число         | `int("25")` дает `25`     |
| `float(value)` | Вещественное число  | `float("2.5")` дает `2.5` |
| `str(value)`   | Строка              | `str(25)` дает `"25"`     |
| `bool(value)`  | Логическое значение | `bool(0)` дает `False`    |

Десятичная часть вещественного числа в исходном коде и при вводе отделяется точкой: `12.5`, а не `12,5`

## Арифметические операции

| Оператор | Операция              | Пример   | Результат  |
| -------- | --------------------- | -------- | ---------- |
| `+`      | Сложение              | `7 + 3`  | `10`       |
| `-`      | Вычитание             | `7 - 3`  | `4`        |
| `*`      | Умножение             | `7 * 3`  | `21`       |
| `/`      | Обычное деление       | `7 / 3`  | `2.333...` |
| `//`     | Целочисленное деление | `7 // 3` | `2`        |
| `%`      | Остаток от деления    | `7 % 3`  | `1`        |
| `**`     | Возведение в степень  | `7 ** 3` | `343`      |

Оператор `/` возвращает `float`, даже если числа делятся без остатка:

```python
print(8 / 2) # 4.0
```

Целочисленное деление и остаток позволяют разделить количество на полные группы и оставшиеся элементы:

```python
item_count = 38
box_capacity = 6

full_boxes = item_count // box_capacity
remaining_items = item_count % box_capacity

print(full_boxes)     # 6
print(remaining_items) # 2
```

Операции выполняются в следующем порядке:

1. Выражения в скобках
2. Возведение в степень
3. Умножение, деление и остаток
4. Сложение и вычитание

Если порядок вычислений может быть понят неправильно, следует использовать скобки

```python
without_parentheses = 2 + 3 * 4
with_parentheses = (2 + 3) * 4

print(without_parentheses) # 14
print(with_parentheses)    # 20
```

## Полная программа

Программа запрашивает цену товара и количество единиц, затем вычисляет стоимость покупки

```python
price = float(input())
quantity = int(input())

total = price * quantity

print(f"Стоимость: {total:.2f} руб")
```

Для входных данных

```text
149.9
3
```

программа выведет

```text
Стоимость: 449.70 руб
```

## Ошибки выполнения

Сообщение об ошибке содержит тип ошибки и строку, на которой она обнаружена

| Ошибка              | Причина                                          |
| ------------------- | ------------------------------------------------ |
| `SyntaxError`       | Нарушен синтаксис Python                         |
| `NameError`         | Использовано неизвестное имя                     |
| `TypeError`         | Операция не поддерживается для указанных типов   |
| `ValueError`        | Значение нельзя преобразовать требуемым способом |
| `ZeroDivisionError` | Выполнено деление на ноль                        |

Например, `int("12.5")` вызывает `ValueError`, потому что строка содержит не целое число. Для такого значения нужно использовать `float("12.5")`
