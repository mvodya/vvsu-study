# Циклы в Python

## Цикл for

Цикл повторяет блок инструкций, который называется телом цикла. Одно выполнение тела называется итерацией

Цикл `for` по очереди получает значения из перебираемого объекта и присваивает их переменной цикла. Например, при переборе строки значениями будут ее символы

```python
for symbol in "ABC":
    print(symbol)
```

Результат

```text
A
B
C
```

После перебора всех значений выполняется код за пределами цикла. Если значений нет, тело не выполняется ни разу

## Диапазон range

Для перебора целых чисел используется `range()`. Он задает начало, границу и шаг диапазона

| Запись                     | Значения                                                          |
| -------------------------- | ----------------------------------------------------------------- |
| `range(stop)`              | От `0` до `stop`, не включая `stop`, с шагом `1`                  |
| `range(start, stop)`       | От `start` до `stop`, не включая `stop`, с шагом `1`              |
| `range(start, stop, step)` | От `start` в сторону `stop`, не включая `stop`, с указанным шагом |

Аргументы должны быть целыми числами, шаг не может быть равен нулю

```python
for number in range(2, 9, 3):
    print(number)
```

Результат

```text
2
5
8
```

При отрицательном шаге значения убывают. Если шаг направлен в противоположную сторону от границы или границы совпадают, диапазон пустой

| Диапазон          | Значения при переборе |
| ----------------- | --------------------- |
| `range(3)`        | `0`, `1`, `2`         |
| `range(8, 1, -3)` | `8`, `5`, `2`         |
| `range(4, 4)`     | Нет значений          |
| `range(4, 1)`     | Нет значений          |

Если действие нужно повторить заданное количество раз, можно перебирать `range()` с этим количеством в качестве единственного аргумента

```python
for attempt in range(3):
    print("Проверка соединения")
```

## Цикл while

Цикл `while` проверяет условие перед каждой итерацией и выполняет тело, пока условие истинно. Если оно ложно уже при первой проверке, тело не выполняется

`while` удобен, когда продолжение зависит от изменяющегося состояния

```python
capacity = 1

while capacity < 10:
    capacity = capacity * 2

print(capacity) # 16
```

Условие проверяется между итерациями, поэтому последнее изменение может вывести значение за указанную границу

Для завершения такого цикла его тело должно изменять данные, от которых зависит условие. Если убрать строку обновления `capacity`, условие останется истинным и цикл станет бесконечным

## Счетчики и накопители

Счетчик хранит количество обработанных значений или событий. Накопитель хранит результат последовательного применения операции

Для числовых переменных запись `count += 1` означает то же обновление, что и `count = count + 1`. Аналогично используются `-=`, `*=` и `//=`

| Назначение   | Начальное значение | Обновление         |
| ------------ | ------------------ | ------------------ |
| Количество   | `count = 0`        | `count += 1`       |
| Сумма        | `total = 0`        | `total += value`   |
| Произведение | `product = 1`      | `product *= value` |

Начальное значение задается до цикла. Если присваивать его заново на каждой итерации, предыдущий результат будет теряться

Для подсчета по условию счетчик изменяется только при выполнении этого условия

```python
text = "v1.2.0"
dot_count = 0

for symbol in text:
    if symbol == ".":
        dot_count += 1

print(dot_count) # 2
```

Отступ определяет, относится ли инструкция к циклу. Вывод внутри тела выполняется на каждой итерации. Вывод после цикла выполняется один раз

Если из накопленных значений вычисляется среднее, деление выполняют после обработки данных и только при ненулевом количестве

## Досрочное завершение break

Оператор `break` немедленно завершает цикл, даже если еще остались значения для перебора или условие `while` истинно

```python
for symbol in "room#12":
    if symbol == "#":
        break
    print(symbol)

print("Готово")
```

Результат

```text
r
o
o
m
Готово
```

## Пропуск итерации continue

Оператор `continue` пропускает оставшуюся часть текущей итерации. В `for` начинается обработка следующего значения, в `while` снова проверяется условие

```python
for symbol in "A B C":
    if symbol == " ":
        continue
    print(symbol)
```

Результат

```text
A
B
C
```

В `while` обновление переменных должно происходить и на пути, который ведет к `continue`, иначе программа может бесконечно повторять одну проверку

## Ввод до команды завершения

Если количество строк заранее неизвестно, можно использовать `while True` и завершать цикл через `break` при получении специальной команды

Программа читает названия разделов и выводит их в верхнем регистре до команды `exit`

```python
while True:
    section = input()
    if section == "exit":
        break
    print(section.upper())
```

Пример входных данных

```text
news
sport
exit
```

Пример результата

```text
NEWS
SPORT
```

Если строки содержат числа или команду, сначала проверяют команду и только затем преобразуют строку в число

## Вложенные циклы

В теле цикла можно разместить другой цикл. Для каждой итерации внешнего цикла внутренний запускается заново

```python
for floor in range(1, 3):
    for wing in "AB":
        print(f"{floor}{wing}")
```

Результат

```text
1A
1B
2A
2B
```

Если внешний цикл выполняет `n` итераций и на каждой из них внутренний выполняет `m` итераций, тело внутреннего цикла выполнится `n * m` раз

`break` и `continue` действуют только на ближайший содержащий их цикл. После выхода из внутреннего цикла через `break` выполнение продолжается со следующей за ним инструкции

## Вывод без переноса строки

Параметр `end` функции `print()` задает текст после последнего выводимого значения. По умолчанию это перенос строки. Значение `end=""` позволяет продолжить вывод на той же строке

```python
print("Код: ", end="")
print("AB", end="")
print(12)
```

Результат

```text
Код: AB12
```

Вызов `print()` без аргументов выводит только перенос строки

## Для знакомых с другими языками

В Python `for` по смыслу соответствует `foreach`: он перебирает элементы объекта, в том числе числа из `range()`

Классический `for` в C, C++ и JavaScript задает начальное состояние, условие продолжения и действие после итерации

| Язык       | Перебор чисел от 0 до 2               |
| ---------- | ------------------------------------- |
| Python     | `for i in range(3):`                  |
| C / C++    | `for (int i = 0; i < 3; i++) { ... }` |
| JavaScript | `for (let i = 0; i < 3; i++) { ... }` |
