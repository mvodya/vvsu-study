# Лабораторная работа 7. Обработка списков и таблиц

## Ввод списков

В заданиях 1-3 пользователь вводит список целых чисел одной строкой через пробелы. Пустая строка задает пустой список

## Задание 1. Корректировка остатков

Элементы введенного списка обозначают остатки товаров

Создать копию списка и заменить в ней все отрицательные значения нулями с помощью присваивания по индексу. Исходный список сохранить

Вывести исходный и исправленный списки

Пример входных данных

```text
12 -3 0 7 -1
```

Пример результата

```text
Исходные остатки: [12, -3, 0, 7, -1]
Исправленные остатки: [12, 0, 0, 7, 0]
```

## Задание 2. Отбор значений

С помощью спискового включения создать список квадратов положительных нечетных чисел из ввода. Сохранить порядок следования и повторения выбранных элементов

Если подходящих значений нет, результатом будет пустой список

Пример входных данных

```text
-3 5 0 2 1 5
```

Пример результата

```text
Квадраты: [25, 1, 25]
```

## Задание 3. Индексы совпадений

После списка пользователь вводит искомое целое число на следующей строке

Создать список индексов всех элементов, равных искомому числу, в порядке возрастания индексов. Использовать `enumerate()` с нумерацией от `0`

При отсутствии совпадений вывести пустой список

Пример входных данных

```text
4 7 4 4 9
4
```

Пример результата

```text
Индексы: [0, 2, 3]
```

## Ввод таблиц

В заданиях 4 и 5 первая строка содержит два положительных целых числа через пробел: количество строк `r` и количество столбцов `c`

Далее следуют `r` строк, в каждой из которых записано ровно `c` целых чисел через пробелы. Сохранить таблицу как список списков

## Задание 4. Суммы строк и столбцов

Для введенной таблицы сформировать два списка: суммы элементов каждой строки и суммы элементов каждого столбца. Порядок сумм должен соответствовать порядку строк и столбцов таблицы

Вычислить суммы накоплением в циклах

Пример входных данных

```text
2 3
3 -1 4
0 5 2
```

Пример результата

```text
Суммы строк: [6, 7]
Суммы столбцов: [3, 4, 6]
```

## Задание 5. Поиск в области таблицы

После таблицы пользователь вводит отдельной строкой четыре целых числа через пробел: `row_start`, `row_end`, `column_start`, `column_end`. Они задают прямоугольную область с включенными границами

Индексы строк и столбцов отсчитываются от `0`. Гарантируется, что `0 <= row_start <= row_end < r` и `0 <= column_start <= column_end < c`

На следующей строке пользователь вводит искомое целое число

Найти все ячейки с этим значением внутри заданной области. Для каждой вывести индекс строки и индекс столбца через пробел на отдельной строке. Обходить область сверху вниз, внутри строки - слева направо

При отсутствии совпадений вывести только `Не найдено`

Пример входных данных

```text
3 4
5 1 5 0
2 5 3 5
5 4 5 6
0 2 1 3
5
```

Пример результата

```text
0 2
1 1
1 3
2 2
```

## Требования

- Каждое задание оформить в отдельном файле
- Считать входные данные соответствующими условиям, проверка корректности ввода не требуется
- Использовать `input()` без приглашения к вводу и выводить результаты в формате примеров
- Использовать списки для хранения и обработки данных
