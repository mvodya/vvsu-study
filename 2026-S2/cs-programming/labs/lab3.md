# Лабораторная работа 3. Обработка строк

## Задание 1. Разбор кода документа

Пользователь вводит код документа в формате `AAA-NNNN-NNNN`, где первая часть - три заглавные латинские буквы категории, вторая - четыре цифры года, третья - четыре цифры номера

Извлечь категорию, год и номер с помощью срезов, сохранив ведущие нули. Дополнительно вывести номер в обратном порядке

Пример входных данных

```text
RUS-2026-0042
```

Пример результата

```text
Категория: RUS
Год: 2026
Номер: 0042
Обратный номер: 2400
```

## Задание 2. Форматирование имени

Пользователь вводит фамилию, имя и отчество одной строкой с произвольным регистром букв. Каждая часть состоит только из букв, между частями может быть один или несколько пробелов, по краям строки также возможны пробелы

Вывести фамилию с первой буквой в верхнем регистре и остальными буквами в нижнем, затем инициалы имени и отчества в верхнем регистре

Пример входных данных

```text
  иВАНОВ иВАН иВАНОВИЧ
```

Пример результата

```text
Иванов И. И.
```

## Задание 3. Очистка номера телефона

Пользователь вводит номер телефона в формате `+7 (NNN) NNN-NN-NN`, где каждый символ `N` обозначает цифру от `0` до `9`

Удалить символы `+`, пробелы, круглые скобки и дефисы

Пример входных данных

```text
+7 (924) 123-45-67
```

Пример результата

```text
79241234567
```

## Задание 4. Разбор записи о поезде

Пользователь вводит данные о поезде одной строкой в формате `номер;откуда;куда;время;цена`

Все пять полей непустые и не содержат `;` или пробелов по краям, внутри названий городов пробелы допустимы. Время задано в формате `HH:MM`, цена - неотрицательное число с точкой в качестве десятичного разделителя

Разделить строку на отдельные значения и вывести оформленную запись. Цену вывести с двумя цифрами после десятичной точки

Пример входных данных

```text
T-18;Владивосток;Хабаровск;08:45;1850.5
```

Пример результата

```text
Поезд: T-18
Маршрут: Владивосток - Хабаровск
Отправление: 08:45
Цена: 1850.50 руб
```

## Задание 5. Проверка идентификатора

Пользователь вводит идентификатор одной строкой, которая может быть пустой или содержать пробелы. Проверять исходную строку без удаления или замены символов

Вывести длину строки и результаты проверок: строка состоит только из букв, только из цифр, является буквенно-цифровой, содержит дефис

Строка считается буквенно-цифровой, если она не пустая и каждый ее символ является буквенным или числовым

Использовать методы `isalpha()`, `isdigit()` и `isalnum()` для первых трех проверок. Для пустой строки длина равна `0`, а все четыре проверки дают `False`

Пример входных данных

```text
AB-204
```

Пример результата

```text
Длина: 6
Только буквы: False
Только цифры: False
Буквенно-цифровая: False
Содержит дефис: True
```

## Задание 6. Формирование пути

Пользователь вводит ровно три непустые части пути через запятую без пробелов. Части не содержат символов `/` и `\`

Разделить строку методом `split()` и соединить полученные части символом `/` с помощью `join()`

Пример входных данных

```text
projects,python,lab3
```

Пример результата

```text
projects/python/lab3
```

## Требования

- Каждое задание оформить в отдельном файле
- Получать строку через `input()` без приглашения к вводу и выводить результат в формате соответствующего примера
- Считать входные данные соответствующими условию, проверка форматов не требуется
- Использовать строковые операции и методы, соответствующие назначению задания
- Не использовать условия и циклы
