# Лабораторная работа 1. Основы Python

## Задание 1. Работа с переменными

Создать четыре переменные со следующими значениями

| Переменная | Значение |
| --- | --- |
| `station_name` | `"Ocean"` |
| `active_sensors` | `18` |
| `average_temperature` | `21.6` |
| `is_online` | `True` |

Вывести значение и тип каждой переменной в указанном порядке

```text
Ocean <class 'str'>
18 <class 'int'>
21.6 <class 'float'>
True <class 'bool'>
```

## Задание 2. Вычисление выражения

Создать переменные `a`, `b` и `c` со значениями `7`, `4` и `3`

Вычислить выражение

```text
(a + b) * c^2 - a div b + a mod b
```

В записи программы использовать операторы Python для возведения в степень, целочисленного деления и остатка от деления

Вывести результат в формате

```text
Результат: 101
```

## Задание 3. Расчет параметров площадки

Пользователь вводит длину и ширину площадки в метрах как два вещественных числа на отдельных строках

Вычислить площадь и периметр площадки

Пример входных данных

```text
5.5
3
```

Пример результата

```text
Площадь: 16.5
Периметр: 17.0
```

## Задание 4. Перевод времени

Пользователь вводит продолжительность поездки в секундах как неотрицательное целое число

Перевести значение в часы, минуты и секунды без использования готовых функций работы со временем

Результат вывести в формате `HH:MM:SS`, дополняя каждую часть ведущим нулем до двух цифр

Пример входных данных

```text
7384
```

Пример результата

```text
02:03:04
```

## Задание 5. Расчет стоимости поездки

Пользователь последовательно вводит расстояние в километрах, расход топлива в литрах на 100 километров и стоимость одного литра топлива

Вычислить необходимое количество топлива и его полную стоимость

Оба результата вывести с двумя цифрами после десятичной точки

Пример входных данных

```text
250
7.5
60
```

Пример результата

```text
Топливо: 18.75 л
Стоимость: 1125.00 руб
```

## Требования

- Каждое задание оформить в отдельном файле
- Использовать осмысленные имена переменных в стиле `snake_case`
- Получать через `input()` только те значения, для которых это указано в задании
- Не передавать приглашение к вводу в `input()`, чтобы вывод совпадал с примерами
- Не использовать условия, циклы и коллекции
