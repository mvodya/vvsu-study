# Лабораторная работа 5. Обработка последовательностей

## Задание 1. Обратный отсчет

Пользователь вводит неотрицательное целое число `n`

С помощью цикла `while` вывести все целые числа от `n` до `0` включительно в порядке убывания, каждое на отдельной строке

Пример входных данных

```text
3
```

Пример результата

```text
3
2
1
0
```

## Задание 2. Сумма и произведение

Пользователь вводит целые числа `a` и `b` на отдельных строках, причем `a <= b`

Вычислить сумму и произведение всех целых чисел от `a` до `b` включительно с помощью цикла `for`

Пример входных данных

```text
2
5
```

Пример результата

```text
Сумма: 14
Произведение: 120
```

## Задание 3. Подсчет измерений

Пользователь вводит неотрицательное целое число `n`, затем `n` значений температуры как вещественные числа, каждое на отдельной строке

Подсчитать количество измерений ниже нуля, равных нулю и выше нуля. Если `n` равно `0`, все три количества равны нулю

Пример входных данных

```text
5
-2.5
0
3.1
-1
0
```

Пример результата

```text
Ниже нуля: 2
Равны нулю: 2
Выше нуля: 1
```

## Задание 4. Таблица умножения

Пользователь вводит целое число `n` от `1` до `9` включительно

Вывести таблицу умножения этого числа на целые числа от `1` до `10` включительно в порядке возрастания второго множителя

Пример входных данных

```text
3
```

Пример результата

```text
3 * 1 = 3
3 * 2 = 6
3 * 3 = 9
3 * 4 = 12
3 * 5 = 15
3 * 6 = 18
3 * 7 = 21
3 * 8 = 24
3 * 9 = 27
3 * 10 = 30
```

## Задание 5. Учет покупок

Пользователь последовательно вводит стоимость каждой покупки в целых рублях на отдельной строке. Стоимость является положительным целым числом, количество покупок заранее неизвестно

Ввод завершается строкой `stop`, записанной строчными латинскими буквами без пробелов. Эта строка не является покупкой

Вывести количество покупок, общую стоимость и среднюю стоимость покупки. Среднюю стоимость вывести с двумя цифрами после десятичной точки

Если команда `stop` введена до первой покупки, вывести только `Нет покупок`

Пример входных данных

```text
120
85
200
stop
```

Пример результата

```text
Покупок: 3
Общая стоимость: 405 руб
Средняя стоимость: 135.00 руб
```

## Задание 6. Треугольник Паскаля

Пользователь вводит количество строк `n` как целое число от `1` до `15` включительно

Вывести первые `n` строк треугольника Паскаля, начиная с вершины

Использовать вложенные циклы и целочисленные вычисления, без готовых функций вычисления биномиальных коэффициентов и факториалов

Каждую строку начинать с первого столбца, числа разделять одним пробелом без пробелов в конце строки. После треугольника вывести количество нечетных элементов во всех выведенных строках, учитывая каждое вхождение числа отдельно

Пример входных данных

```text
5
```

Пример результата

```text
1
1 1
1 2 1
1 3 3 1
1 4 6 4 1
Нечетных элементов: 11
```

### Математическая справка

Треугольник Паскаля состоит из строк целых чисел. На вершине и по краям стоят единицы, а каждый внутренний элемент равен сумме двух элементов над ним

```text
      1
     1 1
    1 2 1
   1 3 3 1
```

Номера строк и позиций в строке отсчитываются от `0`. В строке с номером `r` находится `r + 1` элементов

Элемент `C(r, k)` показывает, сколько существует способов выбрать `k` объектов из `r` различных объектов без учета порядка. Например, из четырех человек можно выбрать пару шестью способами: `C(4, 2) = 6`. Такие числа называются биномиальными коэффициентами

Чтобы вычислять элементы одной строки без хранения предыдущей, используется соотношение

```text
C(r, 0) = 1
C(r, k + 1) = C(r, k) * (r - k) / (k + 1), где 0 <= k < r
```

Здесь `/` обозначает математическое деление. В программе сначала выполняют умножение, затем целочисленное деление `//`: произведение делится на знаменатель без остатка. Если разделить множители по отдельности до умножения, целочисленное деление может отбросить часть результата

Подробнее: [треугольник Паскаля](https://ru.wikipedia.org/wiki/Треугольник_Паскаля) и [вычисление отдельной строки](https://en.wikipedia.org/wiki/Pascal%27s_triangle#Calculating_a_row_or_diagonal_by_itself) в Википедии
