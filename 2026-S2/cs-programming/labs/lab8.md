# Лабораторная работа 8. Посадка лунного модуля

## Задание

Разработать консольную игру, в которой пользователь управляет двигателем лунного модуля. Цель - посадить модуль с безопасной скоростью, распределяя ограниченный запас топлива между шагами полета

## Варианты

Выполнить один вариант по назначению преподавателя. Его параметры задать локальными переменными в `main()`

Полет проходит по шагам. Все величины измеряются в условных единицах и хранятся как целые числа

Состояние модуля описывается высотой `height`, скоростью снижения `speed` и остатком топлива `fuel`. Параметр `gravity` задает прибавку к скорости за шаг, `thrust_step` - уменьшение скорости на единицу мощности двигателя

| Вариант | Начальная высота `height` | Начальная скорость `speed` | Начальное топливо `fuel` | `gravity` | `thrust_step` |
| ------: | ------------------------: | -------------------------: | -----------------------: | --------: | ------------: |
|       1 |                        20 |                          2 |                        8 |         2 |             2 |
|       2 |                        24 |                          3 |                        8 |         2 |             3 |
|       3 |                        30 |                          2 |                       12 |         3 |             2 |
|       4 |                        28 |                          4 |                       10 |         3 |             3 |
|       5 |                        36 |                          3 |                       10 |         3 |             4 |
|       6 |                        40 |                          4 |                       14 |         4 |             3 |
|       7 |                        44 |                          5 |                       12 |         4 |             4 |
|       8 |                        48 |                          6 |                       12 |         4 |             5 |

## Команды управления

На каждом шаге пользователь вводит одну из команд

| Команда | Действие                                           |
| ------- | -------------------------------------------------- |
| `0`     | Шаг с выключенным двигателем, мощность `power = 0` |
| `1`     | Шаг с малой тягой, мощность `power = 1`            |
| `2`     | Шаг с полной тягой, мощность `power = 2`           |
| `exit`  | Завершение игры с сообщением `Полет прерван`       |

Команды записываются точно в указанном виде. Для любой другой строки, включая пустую строку и команды с пробелами, вывести `Ошибка команды`

Если для выбранной мощности топлива недостаточно, вывести `Недостаточно топлива`

После отклоненной команды состояние сохраняется и программа ожидает новый ввод

## Один шаг полета

Для принятой команды мощности последовательно выполнить следующие действия

1. Уменьшить запас топлива на `power`
2. Вычислить новую скорость по формуле `speed + gravity - thrust_step * power`. Отрицательный результат заменить нулем
3. Вычислить новую высоту, вычтя новую скорость из текущей высоты. Отрицательный результат заменить нулем

При нулевой скорости модуль сохраняет высоту на этом шаге

## Завершение полета

После шага определить состояние модуля по таблице

| Условие                                                    | Состояние         |
| ---------------------------------------------------------- | ----------------- |
| Высота положительная                                       | `В полете`        |
| Высота равна нулю, скорость не превышает безопасный предел | `Посадка успешна` |
| Высота равна нулю, скорость превышает безопасный предел    | `Авария`          |

Безопасный предел скорости по умолчанию равен `2`. При касании поверхности использовать скорость, полученную на последнем шаге

## Функции

Реализовать следующие функции и использовать их в программе

| Функция                                                           | Контракт                                                                                                                                                                                                       |
| ----------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `is_valid_command(command)`                                       | Принимает строку и возвращает `True` для команды из таблицы управления, иначе `False`                                                                                                                          |
| `can_burn(power, fuel)`                                           | Принимает допустимую мощность и неотрицательный остаток топлива, возвращает `True`, если топлива достаточно для шага, иначе `False`                                                                            |
| `simulate_step(height, speed, fuel, power, gravity, thrust_step)` | Принимает состояние модуля в полете, допустимую мощность при достаточном запасе топлива и параметры движения своего варианта. Возвращает кортеж новых значений `(height, speed, fuel)` по правилам одного шага |
| `get_status(height, speed, safe_speed=2)`                         | Принимает неотрицательные высоту, скорость и безопасный предел. Возвращает строку состояния из таблицы завершения полета                                                                                       |
| `format_state(height, speed, fuel)`                               | Возвращает строку состояния в формате примеров ниже                                                                                                                                                            |
| `main()`                                                          | Хранит текущее состояние, читает команды, вызывает функции проверки и обработки, выводит результат. Вызывается один раз после определений функций                                                              |

Функции обработки получают данные через параметры и передают результат через `return`. Ввод и вывод выполнять только в `main()`. Глобальные переменные для передачи состояния между функциями не использовать

## Порядок вывода
