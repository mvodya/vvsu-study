# Лабораторная работа 4. Проверка условий

## Задание 1. Управление кондиционером

Пользователь вводит текущую и желаемую температуру как два вещественных числа на отдельных строках

Вывести режим работы по следующим правилам

| Условие                           | Результат    |
| --------------------------------- | ------------ |
| Текущая температура выше желаемой | `Охлаждение` |
| Текущая температура ниже желаемой | `Нагрев`     |
| Температуры равны                 | `Выключен`   |

Пример входных данных

```text
27.5
23
```

Пример результата

```text
Охлаждение
```

## Задание 2. Расчет стоимости билета

Пользователь вводит базовую стоимость билета как вещественное число и возраст пассажира как целое число на отдельных строках

Стоимость должна быть положительной, возраст должен находиться в диапазоне от `0` до `120` включительно. При нарушении ограничения вывести `Ошибка`

Для корректных данных рассчитать цену по таблице

| Возраст          | Доля базовой стоимости |
| ---------------- | ---------------------: |
| От 0 до 5 лет    |                     0% |
| От 6 до 17 лет   |                    50% |
| От 18 до 59 лет  |                   100% |
| От 60 до 120 лет |                    70% |

Результат вывести с двумя цифрами после десятичной точки

Пример входных данных

```text
1800
16
```

Пример результата

```text
Стоимость: 900.00 руб
```

## Задание 3. Определение положения точки

Пользователь вводит координаты `x` и `y` как два вещественных числа на отдельных строках

Определить положение точки по таблице

| Условие                              | Результат          |
| ------------------------------------ | ------------------ |
| Обе координаты равны нулю            | `Начало координат` |
| Только `y` равен нулю                | `Ось X`            |
| Только `x` равен нулю                | `Ось Y`            |
| `x` и `y` положительные              | `I четверть`       |
| `x` отрицательный, `y` положительный | `II четверть`      |
| `x` и `y` отрицательные              | `III четверть`     |
| `x` положительный, `y` отрицательный | `IV четверть`      |

Пример входных данных

```text
-4
7
```

Пример результата

```text
II четверть
```

## Задание 4. Проверка треугольника

Пользователь вводит длины трех сторон как целые числа на отдельных строках

Если хотя бы одна сторона неположительная или найдутся две стороны, сумма которых не больше третьей, вывести `Треугольник не существует`

Для существующего треугольника: если все стороны равны, вывести `Равносторонний`. Если равны ровно две стороны, вывести `Равнобедренный`. В остальных случаях вывести `Разносторонний`

Пример входных данных

```text
5
5
8
```

Пример результата

```text
Равнобедренный
```

## Задание 5. Определение високосного года

Пользователь вводит номер года как целое число

Если год не входит в диапазон от `1` до `9999`, вывести `Ошибка`

Год является високосным, если он делится на `400` или одновременно делится на `4` и не делится на `100`

Для корректного значения вывести `Високосный` или `Невисокосный`

Пример входных данных

```text
2100
```

Пример результата

```text
Невисокосный
```

## Требования

- Каждое задание оформить в отдельном файле
- Считать, что ввод содержит числа указанных типов, проверять только ограничения значений из условий заданий
- Использовать `input()` без приглашения к вводу и выводить ровно один результат в указанном формате
- Для выбора взаимоисключающих результатов использовать одну цепочку `if-elif-else`
- Не использовать циклы, коллекции и исключения
