# Лабораторная работа 6. Реализация численных алгоритмов

## Задание 1. Наибольший общий делитель

Пользователь вводит два целых числа `a` и `b` на отдельных строках

Если хотя бы одно число отрицательное или оба числа равны нулю, вывести `Ошибка`

Для остальных значений найти наибольший общий делитель алгоритмом Евклида

НОД - наибольшее положительное целое число, на которое оба исходных числа делятся без остатка. Для положительного `a` значение НОД(`a`, `0`) равно `a`

Алгоритм Евклида использует равенство НОД(`a`, `b`) = НОД(`b`, `a mod b`) при `b > 0`. Пару чисел последовательно заменяют по этому правилу, пока второе число не станет нулем. Первое число полученной пары является результатом

Пример входных данных

```text
84
30
```

Пример результата

```text
НОД: 6
```

## Задание 2. Проверка числа на простоту

Пользователь вводит целое число `n`

Вывести `Простое` или `Не простое`

Простое число - целое число больше `1`, которое имеет ровно два положительных делителя: `1` и само число. Все значения меньше `2` дают результат `Не простое`

Для проверки перебрать возможные делители начиная с `2`. Проверку завершить при нахождении делителя или когда квадрат проверяемого делителя превысит `n`

Такая граница достаточна: если `n = a * b`, то хотя бы один из множителей `a` и `b` не превосходит квадратного корня из `n`

Пример входных данных

```text
49
```

Пример результата

```text
Не простое
```

## Задание 3. Разложение на простые множители

Пользователь вводит целое число `n`. Если `n < 2`, вывести `Ошибка`

Разложить допустимое число на простые множители и вывести их в порядке неубывания на одной строке через один пробел, без пробела в конце. Повторяющиеся множители выводить столько раз, сколько они входят в разложение

Разложение представляет исходное число как произведение простых чисел. Например, `18 = 2 * 3 * 3`

Использовать последовательное деление: перебирать делители от `2`, при делении без остатка уменьшать оставшееся число и повторно проверять тот же делитель. Продолжать до полного разложения

Пример входных данных

```text
60
```

Пример результата

```text
2 2 3 5
```

## Задание 4. Цифры числа

Пользователь вводит целое число `n`. Если число отрицательное, вывести `Ошибка`

Для допустимого значения определить количество цифр и их сумму, последовательно выделяя последнюю цифру остатком от деления на `10` и удаляя ее целочисленным делением на `10`

Работать с числовым значением, без преобразования числа в строку. У числа `0` одна цифра и сумма цифр равна `0`. Ведущие нули исходной записи не учитываются

Пример входных данных

```text
4050
```

Пример результата

```text
Цифр: 4
Сумма цифр: 9
```

## Задание 5. Таблица расстояний

Пользователь вводит целое число `n` от `1` до `10` включительно. При выходе за этот диапазон вывести `Ошибка`

На прямой расположены точки с целочисленными координатами от `0` до `n - 1`. Построить таблицу расстояний между каждой парой точек

В строке с номером `i` и столбце с номером `j` должно находиться расстояние между точками `i` и `j`. Оно равно большей координате минус меньшая

Использовать вложенные циклы и условие для выбора порядка вычитания. Строки и столбцы выводить в порядке возрастания координат, без заголовков. Элементы строки разделять одним пробелом без пробела в конце

Пример входных данных

```text
4
```

Пример результата

```text
0 1 2 3
1 0 1 2
2 1 0 1
3 2 1 0
```
