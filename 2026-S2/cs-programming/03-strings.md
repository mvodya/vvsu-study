# Строки в Python

## Создание строк

Строка имеет тип `str` и хранит последовательность символов

Строковый литерал можно записать в одинарных или двойных кавычках

```python
language = "Python"
group = 'БИН-26-1'
```

Кавычки одного вида можно использовать внутри строки, ограниченной кавычками другого вида

```python
message = "Команда 'start' запустит программу"
```

Обратная косая черта начинает специальную (escape) последовательность

| Последовательность | Значение             |
| ------------------ | -------------------- |
| `\n`               | Перенос строки       |
| `\t`               | Табуляция            |
| `\\`               | Обратная косая черта |
| `\"`               | Двойная кавычка      |
| `\'`               | Одинарная кавычка    |

```python
message = "Первая строка\nВторая строка"
print(message)
```

Тройные кавычки позволяют записать многострочный текст

```python
description = """Первая строка
Вторая строка
Третья строка"""
```

## Длина и индексы

Функция `len()` возвращает количество символов строки. Пустая строка записывается как `""` и имеет длину `0`, пробелы учитываются как отдельные символы

```python
word = "algorithm"
print(len(word)) # 9
```

Каждый символ имеет индекс. Нумерация слева направо начинается с `0`

```text
Строка:  P  y  t  h  o  n
Индекс:  0  1  2  3  4  5
```

Символ получается по индексу в квадратных скобках

```python
language = "Python"

print(language[0]) # P
print(language[3]) # h
```

Отрицательные индексы отсчитываются от конца строки. Последний символ имеет индекс `-1`

```python
print(language[-1]) # n
print(language[-2]) # o
```

Обращение к несуществующему индексу вызывает `IndexError`

## Срезы

Срез извлекает часть строки и записывается как `string[start:stop:step]`

Символ с индексом `start` входит в результат, символ с индексом `stop` не входит

```python
text = "computer"

print(text[0:3]) # com
print(text[3:6]) # put
```

При положительном шаге пропущенное начало означает начало строки, а пропущенный конец - ее конец

```python
print(text[:4])  # comp
print(text[4:])  # uter
```

Третий параметр задает шаг, по умолчанию он равен `1`. Нулевой шаг вызывает `ValueError`

```python
print(text[::2]) # cmue
print(text[1::2]) # optr
```

Для обратного порядка используется отрицательный шаг

```python
print(text[::-1]) # retupmoc
```

Срез с границами за пределами строки не вызывает ошибку

```python
print(text[:100]) # computer
```

Отрицательные границы отсчитываются от конца строки так же, как отрицательные индексы

```python
print(text[-4:]) # uter
print(text[4:2]) # пустая строка
```

Если в указанном направлении между границами нет символов, результатом будет пустая строка

## Операции со строками

Оператор `+` соединяет строки

```python
first = "data"
second = "base"
result = first + second

print(result) # database
```

Оператор `*` повторяет строку заданное количество раз

```python
print("ab" * 3) # ababab
```

Оператор `in` проверяет наличие подстроки и возвращает `bool`

```python
filename = "report.pdf"

print("report" in filename) # True
print("image" in filename)  # False
```

Оператор `not in` проверяет отсутствие подстроки. Поиск учитывает регистр: `"Report" in filename` вернет `False`

## Неизменяемость строк

Отдельный символ существующей строки нельзя заменить присваиванием

```python
word = "cat"
word[0] = "b" # TypeError
```

Строковые операции создают новое значение. Чтобы сохранить результат, его нужно присвоить переменной

```python
word = "cat"
word = "b" + word[1:]

print(word) # bat
```

## Регистр и пробелы

Метод - операция, связанная со значением. Для вызова после строки или ее переменной записывают точку, имя метода и круглые скобки с аргументами или без них

| Метод          | Результат                                                      |
| -------------- | -------------------------------------------------------------- |
| `lower()`      | Все буквы в нижнем регистре                                    |
| `upper()`      | Все буквы в верхнем регистре                                   |
| `capitalize()` | Первый символ в верхнем регистре, остальные буквы в нижнем     |
| `title()`      | Первые буквы слов в верхнем регистре, остальные буквы в нижнем |
| `strip()`      | Удаление пробельных символов с обоих краев                     |
| `lstrip()`     | Удаление пробельных символов слева                             |
| `rstrip()`     | Удаление пробельных символов справа                            |

```python
text = "  pYtHoN course  "

print(text.strip())         # pYtHoN course
print(text.lower())         #   python course
print(text.strip().title()) # Python Course
```

Последовательный вызов нескольких методов называется цепочкой методов. Каждый следующий метод обрабатывает результат предыдущего

## Поиск и замена

Метод `find()` возвращает индекс первого вхождения подстроки или `-1`, если подстрока не найдена

```python
text = "red green blue green"

print(text.find("green")) # 4
print(text.find("black")) # -1
```

Метод `count()` возвращает количество непересекающихся вхождений

```python
print(text.count("green")) # 2
```

Метод `replace()` заменяет все найденные вхождения и возвращает новую строку

```python
source = "12-34-56"
result = source.replace("-", ":")

print(result) # 12:34:56
```

Третий аргумент ограничивает количество замен

```python
print("one one one".replace("one", "two", 2)) # two two one
```

## Разделение строки

Метод `split()` разделяет строку на части и возвращает список - упорядоченную последовательность значений. При выводе списка его элементы записываются в квадратных скобках через запятую, строки отображаются в кавычках

```python
record = "red|green|blue"
parts = record.split("|")

print(parts) # ['red', 'green', 'blue']
```

Элементы результата можно сразу присвоить нескольким переменным, если их количество известно

```python
left, center, right = record.split("|")

print(left)   # red
print(center) # green
print(right)  # blue
```

Такое присваивание называется распаковкой. Если количество частей не совпадает с количеством переменных, возникает `ValueError`

Без аргумента `split()` разделяет строку по последовательностям пробельных символов

```python
text = "red   green blue"
print(text.split()) # ['red', 'green', 'blue']
```

При таком разделении пробелы по краям не создают дополнительных частей, а пустая строка или строка из одних пробелов дает пустой список `[]`

При явно заданном разделителе каждое его вхождение разделяет части, в том числе пустые

```python
print("red||blue|".split("|")) # ['red', '', 'blue', '']
```

Метод `join()` соединяет строки из последовательности и вставляет между ними строку-разделитель

```python
symbols = "ABC"
result = "-".join(symbols)

print(result) # A-B-C
```

Разделитель является строкой, у которой вызывается `join()`. В аргумент можно передать и список строк, например результат `split()`. Все соединяемые элементы должны быть строками, иначе возникает `TypeError`

## Проверка содержимого

Методы проверки возвращают `True` или `False`

| Метод               | Условие результата `True`                                       |
| ------------------- | --------------------------------------------------------------- |
| `isdigit()`         | Строка не пустая и содержит только цифры                        |
| `isalpha()`         | Строка не пустая и содержит только буквы                        |
| `isalnum()`         | Строка не пустая, каждый символ является буквенным или числовым |
| `isspace()`         | Строка не пустая и содержит только пробельные символы           |
| `startswith(value)` | Строка начинается с `value`                                     |
| `endswith(value)`   | Строка заканчивается на `value`                                 |

```python
print("2048".isdigit())       # True
print("group26".isalnum())    # True
print("report.md".endswith(".md")) # True
```
